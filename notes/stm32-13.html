[6-1] TIM定时中断 — 学习笔记

一句话结论

定时器本质就是计数器：喂一个已知频率的基准时钟，数到设定值就产生中断，计数即计时。时基单元 = PSC + CNT + ARR 三个 16 位寄存器，溢出频率 72MHz/(PSC+1)/(ARR+1)，最大定时 59.65s。

  • 全片结构：01:36–03:00 两个现成工程的现象演示 → 03:00–49:37 PPT 理论（简介 → 类型 → 三个结构图 → 定时中断基本结构 → 时序图 → RCC 时钟树）→ 结尾参考手册导读。
  • 本集没有新建工程、没有写代码、也没有讲 TIM 库函数：TIM_TimeBaseInit、TIM_ITConfig、NVIC 的配置都在 [6-2]。
  • 片头两个工程是现成的（Keil 工程目录名分别是 6-1 定时器定时中断 和 6-2 定时器外部时钟），那张 main.c 截图只是让你看清现象怎么来的，不是本集讲过的写法。
  • 全片只在讲时钟树时提了一句「这就是程序里写 RCC_APB1/2PeriphClockCmd 作用的地方」，那只是指作用位置，不是用法讲解。

1. 片头两个现象

1.1 程序 1：定时器定时中断（工程 6-1 定时器定时中断）

  • 面包板上一块 STM32 最小系统板加一个 OLED 屏。
  • 用的是定时中断功能：定时器用内部时钟定了一个 1 秒的时间，每隔 1 秒申请一次中断，在中断函数里执行 Num++，最后在 OLED 上显示 Num。
  • 画面里 OLED 显示 Num:00009，说明程序已经跑了 9 秒多，数字每秒自己加 1，主程序什么都不用做。
  • 这个工程的 main.c 很能说明用法：OLED_Init()、Timer_Init() 之后死循环里只做一件事 OLED_ShowNum(1, 5, Num, 5)，计数的活全交给定时器的中断函数（本集不写这段，[6-2] 才写）。

图 2：现象①工程的 main.c——主循环只刷新 OLED，计数值由中断函数维护

1.2 程序 2：定时器外部时钟（工程 6-2 定时器外部时钟）

  • 这个程序使用外部时钟来驱动定时器：在定时器指定的外部引脚上输入一个方波信号，用它来提供定时器计数的时钟。
  • 演示时暂时用对射式红外传感器手动模拟外部时钟：拿挡光片依次遮挡、移开、遮挡、移开，就提供了一个方波。
  • OLED 上除了 Num 还多显示一个 CNT，CNT 就是定时器里计数器的值：每遮挡、移开一次计数器加 1，计到 9 之后自动清 0，同时申请一次中断执行 Num++。
  • 所以外部时钟有两个用途：一是提供一段更加精准的时钟来计时；二是把外部时钟当做一个计数器，统计引脚上电平翻转的次数——毕竟定时器本质就是一个计数器。

2. TIM 简介

2.1 定时器就是计数器

  • TIM 是英文 Timer 的缩写，意思是定时器。
  • 基本功能：定时器可以对输入的时钟进行计数，并在计数值达到设定值时触发中断，也就是「定时触发中断」。
  • 由此可以看出：定时器就是一个计数器，当它的输入是一个准确可靠的基准时钟时，对它计数的过程实际上就是计时的过程。
  • 换算举例（STM32 里定时器的基准时钟一般都是主频 72MHz）：对 72MHz 计 72 个数就是 1MHz、也就是 1μs；计 72000 个数就是 1kHz、也就是 1ms。

2.2 时基单元与最大定时时间 59.65s

  • STM32 的定时器拥有 16 位计数器、预分频器、自动重装寄存器组成的时基单元，在 72MHz 计数时钟下可以实现最大 59.65s 的定时。
  • 三个都是 16 位，2¹⁶ = 65536：预分频器设置最大、自动重装也设置最大，最大定时就是 65536 × 65536 / 72MHz ≈ 59.65s（把溢出频率取倒数得到），接近一分钟。
  • 嫌不够长还能级联：一个定时器的输出当做另一个定时器的输入。级联两个最大定时是 59.65s × 65536 × 65536，大约 8000 多年；再级联一个又乘一次 65536 × 65536，大约 34 万亿年，属于指数爆炸。

2.3 定时器不只会定时

  • STM32 的定时器不仅具备基本的定时中断功能，还包含内外时钟源选择、输入捕获、输出比较、编码器接口、主从触发模式等多种功能。
  • 原因是定时器的基本结构非常通用，很多模块电路都能用到，STM32 就在它上面扩展了很多功能；本大节的四部分就是把这几块功能拆开讲。

3. 定时器类型与芯片资源

3.1 三种类型对照表

STM32 的定时器按复杂度和应用场景分为高级、通用、基本三种：高级最复杂，通用中等复杂且最常用，基本最简单；课程主要讲通用定时器。

类型 编号 总线 功能
高级定时器 TIM1、TIM8 APB2 拥有通用定时器全部功能，并额外具有重复计数器、死区生成、互补输出、刹车输入等功能
通用定时器 TIM2、TIM3、TIM4、TIM5 APB1 拥有基本定时器全部功能，并额外具有内外时钟源选择、输入捕获、输出比较、编码器接口、主从触发模式等功能
基本定时器 TIM6、TIM7 APB1 拥有定时中断、主模式触发 DAC的功能
  • 编号和类型的对应关系要熟悉：TIM1、TIM8 是高级定时器，TIM2、TIM3、TIM4、TIM5 是通用定时器，TIM6、TIM7 是基本定时器。
  • 总线要记住：高级定时器接性能更高的 APB2，通用和基本定时器接 APB1，RCC 开启时钟时要注意。
  • 功能是向下兼容的：高级拥有通用的全部功能，通用拥有基本的全部功能，学会通用再看高级和基本就没问题了。

图 5：三种定时器的编号、总线与功能差异

3.2 F103C8T6 的定时器资源

  • 对 STM32F103C8T6 来说，内部定时器资源是 TIM1 到 TIM4，也就是一个高级定时器加三个通用定时器，没有基本定时器。
  • 不同型号的定时器数量不同，用这个外设之前一定要查一下芯片有没有，别操作不存在的外设，那样不会起作用。

3.3 高级定时器的结构升级

对比通用定时器的结构，左上那一大部分都没有变化，主要改动在右边这几块：

  • 重复次数计数器：在申请中断的地方增加了一个重复次数计数器，可以实现每隔几个计数周期才发生一次更新事件和更新中断，相当于对更新信号又做了一次分频；前面算的 59 秒多在这里还要再乘一个 65536，定时时间又提升很多。
  • 输出比较模块的升级：DTG（Dead Time Generate）是死区生成电路，右边输出引脚由一个变两个互补输出，可以输出一对互补的 PWM 波。
  • 这样设计是为了驱动三相无刷电机：三相无刷电机比较常用，四轴飞行器、电动车的后轮、电钻里都可能是它。驱动电路一般需要 3 个桥臂、每个桥臂 2 个大功率开关管，总共 6 个，所以输出 PWM 引脚的前三路变为互补输出，第四路没什么变化，因为三相电机只需要三路。
  • 死区的作用：防止互补 PWM 驱动桥臂时，开关切换瞬间因器件不理想造成短暂的直通，死区生成电路会在切换瞬间产生一定时长的死区，让桥臂上下管全都关断。
  • 刹车输入（BKIN，Break In）：为电机驱动提供安全保障，外部引脚 BKIN 产生刹车信号、或内部时钟失效产生故障时，控制电路会自动切断电机输出（后面讲 RCC 会看到它也接了 CSS 时钟安全系统）。
  • 这些功能主要为三相无刷电机驱动设计，本课程暂时不涉及，简单说一下、有个印象就行。

4. 时基单元与基本定时器结构

先看最简单的基本定时器（手册图 144 基本定时器框图）：它能完成定时中断和主模式触发 DAC 两件事。

4.1 三个最重要的寄存器组成时基单元

  • 图中第一部分有三个最重要的寄存器：预分频器（PSC）、计数器（CNT）、自动重装寄存器（ARR），它们构成最基本的计数计时电路，所以叫时基单元。
  • 预分频器之前连接的就是基准计数时钟的输入；基本定时器只能选内部时钟，可以认为这根线直接连到内部时钟 CK_INT，它的来源是 RCC TIMxCLK，频率一般就是系统主频 72MHz。

4.2 预分频器 PSC：实际分频系数 = 值 + 1

  • 预分频器可以对 72MHz 的计数时钟进行预分频：写 0 不分频（1 分频），输出频率 72MHz；写 1 是 2 分频，输出 36MHz；写 2 是 3 分频，以此类推。
  • 所以预分频器的值和实际分频系数相差 1：实际分频系数 = 预分频器的值 + 1。
  • 预分频器是 16 位的，最大值可以写 65535，也就是 65536 分频。

4.3 计数器 CNT 与自动重装寄存器 ARR

  • 计数时钟每来一个上升沿，计数器的值就加 1；计数器也是 16 位，值可以从 0 加到 65535，再加就回到 0 重新开始，所以它的值在计时过程中会不断自增运行。
  • 自增到目标值时产生中断就完成了定时任务，所以还需要一个存储目标值的寄存器，那就是自动重装寄存器 ARR。
  • ARR 也是 16 位，存的就是我们写入的计数目标值；运行过程中计数值不断自增、自动重装值固定，当计数值等于自动重装值时（计时时间到），就产生一个中断信号并清零计数器，自动开始下一次计数。
  • 图上那个向上的折线箭头就代表这里会产生产生中断信号。

4.4 更新中断与更新事件

  • 「计数值等于自动重装值产生的中断」一般叫做更新中断，它之后通往 NVIC，配好 NVIC 的定时器通道，更新中断就能得到 CPU 的响应。
  • 图上向下的箭头代表这里会产生一个事件，叫更新事件；更新事件不会触发中断，但可以触发内部其它电路的工作。
  • 以上就是定时器定时中断的全部流程：基准时钟 → 预分频器 → 计数器；计数器自增的同时不断与自动重装寄存器比较；两者相等（计时时间到）时产生一个更新中断和更新事件；CPU 响应更新中断，完成定时中断的任务。

图 6：手册图 144 基本定时器框图，红圈是时基单元，标出 U 与 UI

图 7：CNT = ARR 的时刻同时产生更新中断（UI）与更新事件（U）

4.5 主模式触发 DAC（TRGO）

  • 主从触发模式是 STM32 定时器的一大特色，它能让内部硬件不受程序控制自动运行，掌握好了在某些情景下能极大减轻 CPU 负担。
  • 基本定时器的主模式触发 DAC 有什么用：用 DAC 输出波形时，正常思路是定时器产生中断、在中断里触发 DAC 转换，但这样主程序会频繁被中断，影响其它中断的响应。
  • 所以定时器设计了一个主模式：把更新事件映射到触发输出 TRGO（Trigger Out），TRGO 直接接到 DAC 的触发转换引脚，整个过程不需要软件参与，实现硬件自动化。
  • 除了主模式，还有更多硬件自动化的设计，后续再讲。

5. 计数模式

前面解释时用的都是向上计数：计数器从 0 开始向上自增，计到重装值清零并申请中断，然后开始下一轮，依次循环。

计数模式 工作过程 谁支持
向上计数 从 0 开始向上自增，计到 ARR 时清零并申请中断，循环 基本 / 通用 / 高级
向下计数 从重装值开始向下自减，减到 0 时回到重装值并申请中断，循环 通用 / 高级
中央对齐 从 0 开始向上自增，计到重装值申请一次中断；再向下自减，减到 0 再申请中断，循环 通用 / 高级
  • 基本定时器仅支持向上计数这一种模式，通用和高级支持向上、向下、中央对齐三种。
  • 模式虽多，最常用的还是向上计数，其它两种了解一下、主要掌握向上计数。

6.2 外部时钟模式 2：ETR 引脚

  • 基本定时器只能选内部时钟（系统频率 72MHz），通用定时器不仅可选内部 72MHz，还可以选外部时钟。
  • ETR（External）引脚的位置可以查引脚定义表：表里 PA0 这一行写着 TIM2_CH1_ETR，意思是 TIM2 的 CH1 和 ETR 都复用在了 PA0 上。
  • 于是可以在 TIM2 的 ETR 引脚（PA0）上接一个外部方波时钟，经内部的极性选择、边沿检测、预分频电路，再配置输入滤波电路——外部信号难免有毛刺，这些电路可以对输入波形滤波，同时选择极性和预分频。
  • 滤波后的信号兵分两路：上面一路 ETRF 进入触发控制器，紧接着就可以作为时基单元的时钟；这一路在 STM32 里叫做外部时钟模式 2，想用引脚给时钟、或把定时器当计数器计数 ETR 时钟时就走这一路。

6.3 外部时钟模式 1：TRGI（触发输入）

  • 除了 ETR 引脚，还有一路可以提供时钟，就是 TRGI（Trigger In）：它主要用作触发输入、可以触发定时器的从模式，本小节讲的是把它当外部时钟用，暂且就把它当外部时钟输入。
  • 通过这一路进来的外部时钟有这些来源：
    1. ETR 引脚的信号：ETR 既可以从上面那一路当时钟，也可以从下面这一路当时钟，两种情况对时钟输入是等价的，只不过下面这一路会占用触发输入的通道。
    2. ITRx 来自其它定时器（级联用）：主模式的 TRGO 通向其它定时器时，就接到其它定时器的 ITRx 上，比如 TIM2 的 ITR0 是接在 TIM1 的 TRGO 上的。先初始化 TIM3 选 TRGO 输出更新事件，再初始化 TIM2 选 ITR2（对应 TIM3 的 TRGO）、时钟选外部时钟模式 1，TIM3 的更新事件就能驱动 TIM2 的时基单元。
    3. TI1F_ED：连接输入捕获单元的 CH1 引脚，后缀 ED（Edge）是边沿，通过这一路输入的时钟上升沿和下降沿均有效。
    4. TI1FP1 是 CH1 引脚的时钟，TI2FP2 是 CH2 引脚的时钟。
  • 设置这么复杂的输入，不只为了扩大时钟输入范围，更多是为了某些特殊场景（如定时器级联）；这些电路了解一下就行，对时钟输入而言最常用的还是内部 72MHz。

6.4 编码器模式

  • 除了上面几种，还有编码器模式——这是编码器独用的模式，普通的时钟用不到。

6.5 主模式输出与捕获/比较电路

  • 右边是定时器的主模式输出：可以把内部一些事件映射过来，用于触发其它定时器、DAC 或 ADC，所以触发输出的范围比基本定时器更广（基本定时器只有 TRGO 到 DAC）。
  • 下面这部分包含两块电路：右边是输出比较，总共 4 个通道对应 CH1 到 CH4，可输出 PWM 波形、驱动电机；左边是输入捕获，也是 4 个通道对应 CH1 到 CH4，可测输入方波的频率。
  • 中间是捕获/比较寄存器，输入捕获和输出比较共用——因为两者不能同时使用，所以寄存器和引脚都是共用的。

7. 定时中断基本结构

图 11：定时中断基本结构简化图，左时钟源、中时基单元、右中断输出

  • 这张图把无关的东西都去掉了，另外加了一些定时器框图里没体现出来的东西，专门用来讲本小节的两个任务：定时中断和内外时钟源选择。
  • 中间最重要的还是时基单元：PSC 预分频器、CNT 计数器、ARR 自动重装器。
  • 下面是运行控制，就是控制寄存器的一些位，比如启动/停止、向上或向下计数，操作这些寄存器就能控制时基单元。
  • 左边是给时基单元提供时钟的部分：可选 RCC 内部时钟，也可选 ETR 引脚的外部时钟模式 2；本小节程序一用的就是内部时钟，程序二用的是外部时钟模式 2。
  • 此外还有 TRGI 对应的一路（外部时钟模式 1），包括 ETR 外部时钟、ITRx 其它定时器、TIx 输入捕获通道，这些就是所有可选的时钟源，最后还有一个编码器模式。
  • 右边是「计时时间到、产生更新中断后」的信号去向：高级定时器这里还会多一个重复计数器（暂不考虑）；中断信号先在状态寄存器置一个中断标志位，再通过中断输出控制到 NVIC 申请中断。
  • 为什么要有中断输出控制：这个模块很多地方都要申请中断——更新要申请，触发信号也会申请，输入捕获和输出比较匹配时也会申请，需要就允许、不需要就禁止，所以它就是一个中断输出的允许位。

8. 时序与公式

8.1 预分频器时序（手册图 99：参数从 1 变到 2）

  • 第一行 CK_PSC 是预分频器的输入时钟，就是前面选内部时钟那个位置，一般是 72MHz，一直在运行。
  • 下面 CNT_EN 是计数器使能：高电平计数器运行，低电平停止。
  • 再下面 CK_CNT 是计数器时钟：开始时未使能、时钟不运行，使能之后才开始跑；后半段预分频系数变成 2，能看到 CK_CNT 频率减半。
  • 在计数器时钟驱动下，计数器寄存器跟着上升沿不断自增；中间某个位置之后计数值变为 0，由图可推断 ARR 自动重装值就是 FC（计到 FC 的下一个时钟就归零）；计到和重装值相等且下一个时钟来临时才清零，同时产生一个更新事件。
  • 最下面三行描述预分频寄存器的缓冲机制：预分频控制寄存器供读写、不直接决定分频系数；预分频缓冲器（影子寄存器）才是真正起作用的寄存器；预分频计数器说明内部靠计数分频，PSC=0 时一直为 0 直接输出，PSC=1 时计 0、1，回到 0 时输出一个脉冲，即 2 分频。
  • 为什么要影子寄存器：假如计数到一半把分频值由 0 改成 1，若立刻生效计数频率会突变；有了缓冲，中途改的值不会立刻生效，要等本次计数周期结束、产生更新事件时才传递到缓冲寄存器，所以本轮频率不变、下一轮才用新值。

8.2 影子（缓冲）寄存器

  • 结构图里带一个黑色阴影的寄存器都有影子寄存器这样的缓冲机制：预分频器、自动重装寄存器，以及下面的捕获/比较寄存器。
  • 所以 ARR 也有一个缓冲寄存器，并且用不用是可以自己设置的（靠 ARPE 位）。

8.3 计数器时序（手册图 102）与溢出频率

  • 条件是内部时钟分频因子为 2：第一行内部时钟 72MHz，第二行时钟使能高电平启动，第三行计数器时钟频率是它的一半。
  • 计数器在这个时钟每个上升沿自增，增到 0036 时发生溢出——再来一个上升沿计数器清零，产生一个更新事件脉冲，另外还会置一个更新中断标志位 UIF。
  • UIF 只要置 1 就会去申请中断，中断响应后需要在中断程序里手动清零。
  • 公式：CK_CNT_OV = CK_CNT / (ARR + 1)，ARR 的值也要加 1；把 CK_CNT = CK_PSC / (PSC + 1) 代入，得到 CK_CNT_OV = CK_PSC / (PSC + 1) / (ARR + 1)，即溢出频率 72MHz/(PSC+1)/(ARR+1)，算溢出时间再取个倒数。

8.4 ARR 预装（ARPE）时序

  • 无预装（ARPE=0）：计数中途把自动重装寄存器由 FF 改成 36，目标值立刻变 36，所以计到 36 就直接更新、开始下一轮。
  • 有预装（ARPE=1）：中途把目标由 F5 改成 36，下面的影子寄存器仍是 F5，本轮还是计到 F5 才产生更新事件，同时改后的 36 被传递到影子寄存器，下一个计数周期才有效。
  • 引入影子寄存器的目的是同步：让值的变化和更新事件同步发生，防止运行途中更改造成错误。
  • 反例：若不用影子寄存器，F5 改成 36 立刻生效，而计数值已到 F1——F1 只能往上加，目标却比它还小，那就要加到 FFF 回 0 再加到 36 才产生更新，会造成小问题。

9. RCC 时钟树与「所有定时器都是 72MHz」的由来

9.1 时钟树是什么

  • RCC 时钟树是 STM32 中用来产生和配置时钟、并把配置好的时钟发送到各外设的系统；时钟是所有外设运行的基础，所以最先需要配置。
  • 主函数之前还会执行一个 SystemInit 函数，它就是配置时钟树的；结构看上去复杂，但 ST 已经帮我们写好了。
  • 时钟树可以从中间划一条界线：左边是时钟的产生电路，右边是分配电路，中间的 SYSCLK 就是系统时钟 72MHz。
  • 时钟产生电路有四个振荡源：HSI 内部 8MHz 高速 RC 振荡器；HSE 外部 4–16MHz 高速石英晶振，一般接 8MHz；LSE 外部 32.768kHz 低速晶振，一般给 RTC 提供时钟；LSI 内部 40kHz 低速 RC 振荡器，给独立看门狗 IWDG 提供时钟。
  • 上面两个高速晶振用来提供系统时钟，AHB、APB2、APB1 的时钟都来源于它们；内外都有 8MHz 可用，但外部石英晶振比内部 RC 稳定，一般用外部；系统简单、不需要精确时钟时可用内部 RC，省下晶振电路。

图 15：RCC 时钟树，左侧振荡源与 PLL，右侧总线分配

9.2 SystemInit 里 ST 的配置流程

  1. 先启动内部时钟 HSI，选择内部 8MHz 为系统时钟，暂时以内部 8MHz 运行；
  2. 再启动外部时钟 HSE，配置它走 PLL 这一路，进入锁相环倍频，8MHz 倍频 9 倍得到 72MHz；
  3. 等锁相环输出稳定后，选择锁相环输出为系统时钟，系统时钟就从 8MHz 切换成了 72MHz。

9.3 晶振故障与 CSS 时钟安全系统

  • 分析时钟树可以解决一个实际问题：外部晶振出问题会出现程序时钟慢大概 10 倍的现象，比如定 1s 的时间，结果大概 10s 才进中断。
  • 原因是晶振出问题就切不到 72MHz，只能以内部 8MHz 运行，8M 比 72M 大概慢 9 倍（视频说约 10 倍）；作者就遇到过晶振两个引脚被焊短路，分开后时钟就回到 72M。
  • CSS（Clock Security System，时钟安全系统）负责切换时钟：它监测外部时钟运行状态，一旦失效就自动切回内部时钟，保证系统时钟运行，防止程序卡死造成事故。
  • 高级定时器的刹车输入这里也有 CSS 的身影：CSS 检测到外部时钟失效，通过或门立刻反应到输出比较部分，让电机立刻停止。

9.4 总线分频与定时器时钟 ×2

  • 时钟分配电路：72MHz 进 AHB，AHB 预分频系数为 1，所以 AHB 时钟就是 72MHz；再进 APB1，分频系数是 2，所以 APB1 时钟为 72MHz/2 = 36MHz。
  • 问题来了：通用和基本定时器挂在 APB1 上，按理该是 36MHz，可前面一直说所有定时器都是 72MHz。
  • 原因在图下那条支路：如果 APB1 预分频系数 = 1 则频率不变，否则频率 ×2；这一路单独为定时器 2～7 开通，这里预分频系数给的是 2，所以频率再 ×2，通向定时器 2～7 的时钟又回到 72MHz。
  • 结论：无论高级、通用还是基本定时器，内部基准时钟都是 72MHz——前提是不乱改 SystemInit 里的默认配置，改了还得另行分析。
  • APB2 的分频系数为 1，所以 APB2 和 AHB 一样是 72MHz；高级定时器也单独升了一路，但 APB2 分频系数就是 1，频率不变，定时器 1 和 8 的时钟就是 72MHz。
  • 这些时钟输出处都有一个与门做输出控制，控制位写的是外设时钟使能——这就是程序里写 RCC_APB1/2PeriphClockCmd 作用的地方，打开时钟就是在这里写 1，让左边的时钟通过与门输出给外设。

坑与易错点

  1. 预分频器实际分频系数 = 值 + 1，写 0 是 1 分频不是 0 分频；ARR 同理，算溢出频率要用 (ARR+1)。
  2. 「所有定时器都是 72MHz」的前提是不改 SystemInit 默认配置，改了时钟树就要重算。
  3. APB1 是 36MHz 但定时器是 72MHz：靠「预分频系数 ≠ 1 就 ×2」的支路单独供时钟。
  4. 更新事件不等于更新中断：事件不触发中断，要进中断还得过中断输出控制这个允许位。
  5. UIF 置位就会申请中断，中断响应后要在中断程序里手动清零。
  6. ARR 在 ARPE=1 时走影子寄存器，本次更新事件后才生效；ARPE=0 才立刻生效，PSC 同理。
  7. 基本定时器只能向上计数、只能内部时钟；F103C8T6 上根本没有 TIM6/TIM7。
  8. 用外设前先查型号有没有这个外设，操作不存在的外设不会起作用。
  9. ETR 直接进来是外部时钟模式 2，从 TRGI 进来是模式 1（占用触发输入通道）。
  10. 外部晶振坏了时钟慢约 10 倍（定 1s 要 10s），实际是退回内部 8MHz，先查晶振。
  11. 本集没有代码也没有 TIM 库函数，TIM_TimeBaseInit、TIM_ITConfig、NVIC 在 [6-2]。
