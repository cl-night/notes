[7-1] ADC模数转换器 — 学习笔记

一句话结论

ADC 把引脚上连续的模拟电压转成数字量，本质是个电压表：12 位逐次逼近、1us（1MHz）、0～3.3V 对应 0～4095、18 通道（16 外部 + 2 内部）；规则组最多 16 通道却只有 1 个数据寄存器。代码在 P22。

本集定位

  • 模块 7（ADC）的理论课：00:12–03:22 只演示两个成品工程，03:24 起全是 PPT + 参考手册翻页，48:46 前没有一行代码。
  • 片头两个工程：7-1 AD单通道（电位器 → PA0）、7-2 AD多通道（再加光敏、热敏、反射红外 → PA1、PA2、PA3）。
  • 片尾 48:42「我们下一小节来开始写代码」——配置与库函数全在 P22 [7-2]。
  • 本集不出现初始化结构体、库函数、寄存器写入演示，只做寄存器章节导读；涉及写法一律注明「在 P22」。

1. 片头现象：AD 单通道与 AD 多通道

1.1 AD 单通道：电位器 → PA0

  • 电位器产生 0～3.3V 连续可调的模拟电压，接到 PA0；OLED 第一行显示 AD 原始值 ADValue:00000，第二行显示换算后的电压 Voltage:0.00V。
  • 往左拧：AD 值减小、电压减小，最小 0 对应 0V；往右拧：两者一起变大。
  • STM32 的 ADC 是 12 位，结果最大 4095（2^12-1），对应 3.3V。

图 1：AD 单通道——电位器接 PA0，OLED 显示 ADValue:00000 与 Voltage:0.00V

1.2 AD 多通道：4 路传感器

  • 光敏电阻、热敏电阻、反射红外模块的 AO 分别接 PA1、PA2、PA3，加上电位器共 4 路，屏幕显示 AD0～AD3。
  • 电位器看 AD0：左拧减小、右拧增大，与单通道一致。
  • 光敏电阻看 AD1：遮挡 → 光线减弱 → AD 增大；移开 → 光线增强 → AD 减小。
  • 热敏电阻看 AD2：手焐一下 → 温度升高 → AD 减小；移开 → 温度降低 → AD 增大。
  • 反射红外看 AD3：手靠近 → 有反光 → AD 减小；移开 → 无反光 → AD 增大。

图 2：AD 多通道——OLED 同时显示 AD0:4095、AD1:1487、AD2:1968、AD3:0993

1.3 ADC 的意义：GPIO 只能读高低电平

  • GPIO 只有高、低两个值；用了 ADC 就能对两者之间的任意电压量化，用一个变量表示。
  • 读这个变量即知引脚实际电压，所以说 ADC 就是一个电压表。

2. ADC 简介

2.1 定义与桥梁作用

  • ADC（Analog-Digital Converter）模拟-数字转换器，简称模数转换器，也叫 AD 转换器。
  • 「ADC 可以将引脚上连续变化的模拟电压转换为内存中存储的数字变量，建立模拟电路到数字电路的桥梁。」
  • 原因：STM32 主要是数字电路，没有「几 V」的概念；ADC 测出电压存进寄存器，读到变量里就能显示、判断、记录。

图 3：PPT「ADC简介」——12 位逐次逼近型、1us、0～3.3V↔0～4095、18 通道、规则组/注入组、模拟看门狗；C8T6 只有 ADC1、ADC2 与 10 个外部通道

2.2 与 DAC / PWM 的对比

  • DAC 是反方向的桥梁：把数字变量转成模拟电压。
  • PWM 用占空比等效模拟量，全开/全关都没有功率损耗，大功率调速场合比 DAC 更好，电路也更简单常用。
  • 所以 PWM 挤占了 DAC 的应用空间，DAC 现在主要做波形生成（信号发生器、音频解码芯片）。

2.3 关键参数逐条看

  • 12 位、逐次逼近、1us：量化范围 0～4095，位数越高分辨率越高；转换时间 1us 对应转换频率 1MHz，是 STM32 ADC 的最快速度，信号频率低时完全够用。
  • 输入 0～3.3V ↔ 结果 0～4095：输入只能在芯片供电负极到正极之间，0V→0、3.3V→4095，中间线性对应，换算只是乘除一个系数。
  • 18 通道 = 16 外部 + 2 内部：外部就是 16 个 GPIO，直接接信号、不需额外电路；内部是温度传感器（测 CPU 温度）和内部参考电压 VREFINT（约 1.2V，不随外部供电变化，可用来校正）。
  • 规则组 / 注入组：不必「启动一次读一次」，可以列一组、一次启动、连续转换多个值——规则组日常用，注入组应对突发事件。
  • 模拟看门狗：监测指定通道，AD 值高于上阈值或低于下阈值就申请中断，省掉主循环里不断读值 + if 判断。
  • C8T6 资源：只有 ADC1、ADC2 两个 ADC；16 个外部通道是系列上限，本芯片引脚少，只有 10 个，要更多就选引脚更多的型号。

3. 逐次逼近型 ADC 的原理（ADC0809）

STM32 手册只画一个框表示 ADC，不讲内部结构，所以借结构完整的 ADC0809（经典 8 位逐次逼近型）讲原理——STM32 的 ADC 原理与它一致。

3.1 结构：多路开关 + 比较器 + DAC + SAR

  • 早年单片机性能弱，要外挂 ADC 芯片；现在多数单片机已内置，引脚直接测电压。
  • 左侧 IN0～IN7 是 8 路输入，经通道选择开关选一路送入转换电路。
  • 地址锁存和译码：通道号放 ADDA/ADDB/ADDC，再用 ALE 锁存，相当于一个可通过模拟信号的数据选择器；转换只要几个 us，所以一个 AD 转换器 + 一个多路开关就够。
  • ADC0809 只有 8 通道，STM32 内部是 18 通道，对应过来就是一个 18 路输入的多路开关。

图 4：ADC0809 结构——IN0～IN7 → 通道选择开关；ADDA/ADDB/ADDC + ALE 译码；比较器、SAR、DAC；8 位三态锁存缓冲器 D0～D7；CLOCK/START、EOC、VREF+/VREF-

3.2 逐次逼近的过程：从最高位开始试

  • 电压比较器判断两个输入谁大（输出高低电平），一端是待测电压，另一端是 DAC 输出。
  • DAC 是数模转换器：给一个数据就输出对应电压（内部是加权电阻网络）。
  • 于是「未知编码的待测电压」和「已知编码的 DAC 电压」进比较器：DAC 输出偏小就增大数据，直到两者近似相等，此时 DAC 的输入数据就是待测电压的编码。
  • 调节由逐次逼近寄存器 SAR 完成：8 位编码 0～255，第一次试一半即 128，DAC 大了就减半试 64，再大试 32……最快逼近未知电压。
  • 128、64、32 正是二进制各位的位权，过程等于从高位到低位逐位判断 1 还是 0，这就是「逐次逼近」；12 位 ADC 判断 12 次。

图 5：同一张结构图上红圈标出比较器与 DAC，字幕「直到DAC输出的电压和外部通道输入的电压近似相等」

3.3 外围信号：EOC / START / CLOCK / VREF

  • 输出：8 位就 8 根线、12 位就 12 根线，配三态锁存缓冲器与 OE 控制。
  • EOC（End Of Convert）是转换结束信号；START 给一个脉冲即开始；CLOCK 是 ADC 时钟，逐次判断要靠它推动。
  • VREF+/VREF- 是 DAC 的参考电压，同一数据对应 5V 还是 3.3V 由它决定，它也就决定了 ADC 的输入范围。
  • VCC/GND 是整芯片供电；通常 VREF+ 与 VCC、VREF- 与 GND 接在一起。

4. STM32 的 ADC 框图

手册每个外设最前面都有整体结构图，这张图非常重要，要多花时间看。

图 6：ADC 框图全貌——IN0～IN15 + 温度传感器 + VREFINT → 模拟多路开关 → 模数转换器（规则/注入）→ 数据寄存器；EXTSEL/JEXTSEL 触发、ADCCLK、DMA 请求、模拟看门狗、EOC/JEOC 到 NVIC、开关控制

4.1 输入与转换部分

  • ADCx_IN0～IN15 共 16 个外部通道，加内部温度传感器和 VREFINT 两个内部通道，都进模拟多路开关，选一路送模数转换器。
  • 模数转换器做的正是前面的逐次比较，结果存入数据寄存器。

4.2 规则组与注入组的数据寄存器

  • 规则组可一次选中最多 16 个通道，却只有 1 个数据寄存器：连上 16 个菜，前 15 个都被挤掉，只剩最后一个。
  • 解决靠 DMA 数据转运：每转换完一个就挪走一个，避免覆盖（DMA 下一节讲）。
  • 注入组最多 4 个通道、有 4 个数据寄存器，不用担心覆盖；一般用规则组 + DMA 就够，注入组涉及不多。

图 7：红圈标出「注入通道数据寄存器（4×16 位）」「规则通道数据寄存器（16 位）」与「最多 4 通道」「最多 16 通道」，另有 JEXTSEL/EXTSEL 2:0 位、DMA 请求

4.3 触发转换：软件触发与硬件触发

  • 框图左下角的触发部分就是 START 信号，分软件触发（控制位）和硬件触发（框图里的触发源）。
  • 触发源主要是定时器：上面一组给注入组，下面一组给规则组。
  • 为什么用定时器触发：若要每隔 1ms 转换一次，用定时中断手动启动会频繁打断主程序，还可能因优先级导致响应不及时；给 TIM3 定 1ms 并把更新事件选为 TRGO 输出触发 ADC，全程不进中断。
  • 也可以选外部中断引脚触发，都在程序里配置。

4.4 参考电压与供电

  • VREF+/VREF- 是参考电压，决定输入范围；VDDA/VSSA 是 ADC 供电引脚。
  • 一般 VREF+ 接 VDDA、VREF- 接 VSSA；本芯片没有这两个引脚，内部已与 VDDA/VSSA 相连。
  • VDDA/VSSA 供的是内部模拟部分（ADC、RC 振荡器、锁相环等），本板 VDDA 接 3.3V、VSSA 接 GND，所以输入范围就是 0～3.3V。

4.5 ADCCLK：ADC 时钟

  • ADCCLK 驱动内部逐次比较（相当于 ADC0809 的 CLOCK），来自 ADC 预分频器，源头是 RCC：APB2 72MHz → ADC 预分频器 → ADCCLK。
  • ADCCLK 最大 14MHz，可选 2、4、6、8 分频：2 分频 36M、4 分频 18M 都超限，实际只能选 6 分频（12M）或 8 分频（9M）。

图 8：红圈「ADC 预分频器 /2、/4、/6、/8」→「ADCCLK 最大 14MHz」，上方是 APB2 预分频器与 72MHz 的 PCLK2

4.6 数据寄存器、看门狗、中断与开关

  • 两个数据寄存器存结果；模拟看门狗可设阈值高限与低限，超范围就申请中断（通向 NVIC）。
  • EOC（规则组完成）与 JEOC（注入组完成）会在状态寄存器置标志，也能通向 NVIC 申请中断。
  • 右下角是开关控制（给 ADC 上电），库函数写法在 P22。

4.7 简化结构图

  • 输入通道（16 个 GPIO + 2 个内部）→ AD 转换器（规则组最多 16、注入组最多 4）→ 数据寄存器（规则组 1 个、注入组 4 个）。
  • 下方触发控制给 START（软件/硬件，硬件主要来自定时器或外部中断引脚）；右侧 RCC 提供 CLOCK。
  • 上方模拟看门狗测结果范围，经中断输出控制向 NVIC 申请中断；EOC 同样可申请中断；右下角开关控制上电。

图 9：作者总结的「ADC基本结构」——GPIO（16）、温度传感器、VREFINT 汇入多路开关；AD 转换器含规则组（最多 16）与注入组（最多 4）；寄存器「规则组结果×1」「注入组结果×4」

6. 规则组的 4 种转换模式

初始化结构体里两个参数——单次/连续、扫描/非扫描，组合出 4 种模式。

6.1 单次转换、非扫描模式

  • 规则组有菜单列表：序列 1～序列 16 共 16 个空位，填要转换的通道。
  • 非扫描时「同时选一组」退化为「只选一个」：只在序列 1 填通道（比如通道 2）。
  • 触发后完成转换，结果进数据寄存器并置 EOC，判断标志位即可读结果；想再转就再触发，想换通道就在触发前改序列 1。

图 11：左右两张序列列表（序列 1～序列 16），序列 1 填「通道 2」，触发箭头指向通道 2 再到 EOC

6.2 连续转换、非扫描模式

  • 一次转换结束不停止，自动开始下一次，只需最开始触发一次。
  • 好处：不用等启动、不用判断结束，想读值直接从数据寄存器取，拿到的总是最新值。

6.3 单次转换、扫描模式

  • 单次：每触发一次，转换完就停，下次再触发。
  • 扫描：用满菜单列表，序列 1、2……分别填通道 2、5……可任意指定、也可重复。
  • 位置可能用不完，所以还要给**「通道数目」**参数：指定 7 就只看前 7 个位置（序列 1～7 = 通道 2、5、4、1、0、3、6），每次触发依次转换这 7 个。
  • 结果都进同一个数据寄存器，必须靠 DMA 及时挪走防覆盖；7 个都转完产生 EOC，再触发就是新一轮。

图 12：蓝色括号标出「通道数目：7」，序列 1～7 依次填通道 2、5、4、1、0、3、6，转换完指向 EOC

6.4 连续转换、扫描模式；间断模式

  • 连续 + 扫描：在 6.3 基础上，一次转换完成后立刻开始下一次，仍是「单次 vs 连续」那一套。
  • 间断模式（了解）：扫描模式下每转换几个通道就暂停，需再次触发才继续。

8. 数据对齐

  • 结果是 12 位、寄存器是 16 位，于是有对齐问题。
  • 右对齐：12 位靠右、高位补 0（0 0 0 0 D11…D0），读出来就是结果。
  • 左对齐：12 位靠左（D11…D0 0 0 0 0），等于左移 4 位（×16），直接读会大 16 倍；取高 8 位可当 8 位 ADC 用。
  • 一般用右对齐。

图 14：16 位数据寄存器示意——右对齐 0 0 0 0 D11 D10 … D1 D0，左对齐 D11 D10 … D1 D0 0 0 0 0

9. 转换时间与采样时间

  • 步骤：采样、保持、量化、编码。
  • TCONV = 采样时间 + 12.5 个 ADC 周期：12 位量化占 12 个周期，另 0.5 个周期本集未给权威解释。
  • 例：ADCCLK = 14MHz、采样 1.5 个周期时，TCONV = 1.5 + 12.5 = 14 个 ADC 周期 = 1us，这就是 1us 的来历。
  • 采样时间越长越抗毛刺、但更慢；不需要高速时转换时间可忽略；ADCCLK 超 14MHz 属超频，更快但不保证稳定。
  • 采样保持电路 = 采样开关 + 电容：采样阶段把电压存到电容上，量化期间保持不变。

10. 校准与硬件电路

10.1 校准

  • ADC 内置自校准，用于减小内部电容组误差，建议每次上电后校准一次。
  • 启动校准前，ADC 必须关电至少两个 ADC 时钟周期（手册要求，写法在 P22）。

10.2 三种常见硬件电路

  1. 电位器分压：RP1 = 10K 两端接 3V3 与 GND，滑动端输出 0～3.3V 到 PA0；阻值别太小，至少 KΩ 级，否则耗电大、发热。
  2. 传感器 + 固定电阻分压：等效可变电阻 N1 与 R1 = 10K 串联，中点接 PA1；传感器阻值小则输出低、大则输出高；固定电阻取与传感器相近的阻值，两者互换则输出极性相反。
  3. 电阻分压测更高电压：VIN 0～5V 经 R1 = 17k、R2 = 33k 分压，中点得 0～3.3V 送 PA2（分压比约 33/50）；再高就必须加隔离。

图 16：①3V3—RP1 10K—GND，滑动端出 PA0；②3V3—R1 10K—N1（传感器）—GND，中点出 PA1；③VIN 0～5V—R1 17k—节点 0～3.3V→PA2—R2 33k—GND

坑与易错点

  1. 输入不能超出 VSSA～VDDA：即 0～3.3V，超了测不准还可能损坏引脚，更高电压先分压或隔离。
  2. 12 位最大值是 4095 不是 4096：2^12 = 4096 个刻度，最大 2^12-1 = 4095，对应 3.3V。
  3. 换算关系是线性的：电压 = AD 值 / 4095 × 3.3V，反向 AD 值 = 电压 / 3.3 × 4095。
  4. 本芯片只有 10 个外部通道：16 个是系列上限，C8T6 只有 ADC12_IN0～ADC12_IN9（PA0～PB1）。
  5. 通道 16/17 只有 ADC1 有：16 = 温度传感器、17 = 内部参考电压（约 1.2V），ADC2 没有。
  6. 规则组只有 1 个数据寄存器：多通道扫描会互相覆盖，只剩最后一个，要么配 DMA、要么及时读走。
  7. ADCCLK 最大 14MHz：72MHz 下 2 分频 36M、4 分频 18M 都超限，只能 6 分频（12M）或 8 分频（9M）。
  8. 转换时间要算采样时间：TCONV = 采样时间 + 12.5 个 ADC 周期，1us 只是 ADCCLK=14MHz、采样 1.5 周期那个特例。
  9. 左对齐会让读数大 16 倍：左对齐等于左移 4 位，读出来要除以 16；一般用右对齐。
  10. 扫描模式必须给「通道数目」：不指定会按 16 个位置全转，多出来的通道读到无效值。
  11. 单次/连续、扫描/非扫描是两组独立参数：4 种组合对应 4 种模式，不存在单独的「连续扫描模式」开关。
  12. 模拟看门狗是硬件窗口比较：只负责超限报警、不等于结果准确，目的是省掉主循环不断判断。
  13. 分压电阻要选对量级：太小耗电发热，太大又受 ADC 输入阻抗影响；固定电阻尽量与传感器阻值相近。
  14. 本集没有代码：ADC_Cmd 上电、校准、序列、触发源、对齐、ADCCLK 分频的写法全在 P22。
