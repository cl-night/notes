[3-2] LED闪烁 / LED流水灯 / 蜂鸣器 — 学习笔记

一句话结论

把 [3-1] 的理论落成代码：重建标准库工程，写 LED 闪烁（RCC → GPIO_Init → 输出函数 + Delay）、流水灯（GPIO_Write 写 ODR，低电平点亮要取反）、蜂鸣器（PB12 低电平触发），附查库函数方法。

本集定位

  • GPIO 输出模块第 2 集（[3-2]），本集是代码课：GPIO 理论在 [3-1]，这里落成三个程序。
  • 三个程序：LED 闪烁（RCC → GPIO_Init → 输出函数 + Delay）、LED 流水灯（GPIO_Write 写 ODR）、蜂鸣器（PB12 低电平触发）。
  • 顺带演示查库函数的方法与取反点灯写法。

0. 三个程序与硬件

程序 硬件连接 现象
3-1 LED闪烁 1 个 LED：长脚（正极）→ 正极供电孔，短脚 → PA0（低电平点亮；为简化不接限流电阻） LED 每 500ms 闪烁
3-2 LED流水灯 8 个 LED：正极接正极供电孔，负极分别接 PA0～PA7 8 个 LED 依次流水点亮
3-3 蜂鸣器 有源蜂鸣器：VCC → 正极排、GND → 负极排、控制极 → PB12（低电平触发响） 蜂鸣器“滴滴”鸣响
  • 面包板红线（正极）朝上，最小系统板跨凹槽插；GND 用蓝跳线接负极排，3.3V 用红跳线接正极排。

1. 快速搭一个标准库工程

原理见 [2-2] 新建工程，本集只快速演示：

  1. Project → New Project 选总文件夹，Ctrl+Shift+N 建工程文件夹（如 3-1 LED闪烁）；工程名 Project，芯片 STM32F103C8，关掉 Manage Run-Time Environment。
  2. 建三个文件夹并复制固件库文件：
    • Start：启动文件（全复制，Keil 分组只加 md.s）、stm32f10x.h、system 两文件、core_cm3 两文件；
    • Library：src 全部 .c、inc 全部 .h；
    • User：Project\...\Template 的 main.c、stm32f10x_conf.h、stm32f10x_it.c/h。
  3. Keil 删掉默认组，建 Start、Library、User 三组，Add Files 加文件。
  4. 魔术棒 → C/C++：Include Paths 加 ..\Start、..\Library、..\User，Define 填 USE_STDPERIPH_DRIVER。
  5. Debug 选 ST-Link Debugger，Settings → Flash Download 勾 Reset and Run。
  6. 清空 main.c，编译 0 Error(s), 0 Warning(s)，下载正常。
  • 工程清理：STM32Project 里 1-2 keilkill批处理 的 keilkill.bat 复制到工程文件夹双击，删掉 Listings、Objects 等中间文件，20MB 缩到 2MB 左右。

2. 库函数地图（RCC 与 GPIO）

  • stm32f10x_rcc.h 末尾：RCC_AHBPeriphClockCmd、RCC_APB2PeriphClockCmd、RCC_APB1PeriphClockCmd 分别开 AHB / APB2 / APB1 时钟，参数“外设枚举 + ENABLE/DISABLE”；GPIO 挂 APB2，所以用 RCC_APB2PeriphClockCmd。
  • stm32f10x_gpio.h：GPIO_DeInit（复位）、GPIO_Init（结构体初始化）、GPIO_StructInit（赋默认值）；4 读 GPIO_ReadInputDataBit / GPIO_ReadInputData / GPIO_ReadOutputDataBit / GPIO_ReadOutputData；4 写 GPIO_SetBits / GPIO_ResetBits / GPIO_WriteBit / GPIO_Write。

3. LED 闪烁（3-1）

点灯三步：① RCC 开 GPIO 时钟 → ② GPIO_Init 初始化 → ③ 输出函数控制引脚。

#include "stm32f10x.h"
#include "Delay.h"

int main(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);   // ① 开 GPIOA 时钟

	GPIO_InitTypeDef GPIO_InitStructure;                     // ② 初始化 GPIO
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;         // 推挽输出
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;                // PA0
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOA, &GPIO_InitStructure);

	while (1)                                                // ③ 输出函数控制
	{
		GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_RESET);         // 低电平 → 点亮
		Delay_ms(500);
		GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_SET);           // 高电平 → 熄灭
		Delay_ms(500);
	}
}
  • 输出函数：GPIO_SetBits 置高、GPIO_ResetBits 置低、GPIO_WriteBit 按位写、GPIO_Write 写整个端口。
  • GPIO_WriteBit 第三参数是枚举 BitAction（Bit_RESET / Bit_SET）；直接写 0/1 要强转 (BitAction)0 / (BitAction)1。
  • Delay 模块：资料 1-3 Delay函数模块 复制到 System 文件夹，Keil 加 System 组，#include "Delay.h" 后可用 Delay_us / Delay_ms / Delay_s。
  • 现象：LED 每 500ms 闪烁；500 改成 100 明显变快。

推挽 vs 开漏实验（LED 反接成高电平点亮：长脚接 PA0、短脚接 GND）：

模式 高电平 低电平 LED（高电平点亮接法）
推挽输出（Out_PP） 上管导通、有驱动 下管导通、有驱动 正常闪烁
开漏输出（Out_OD） 高阻态、无驱动 下管导通、有驱动 高电平点不亮；把 LED 接回低电平点亮接法时低电平能点亮
  • 一般输出都选推挽，开漏只在特殊场合用（外接上拉输出 5V、I2C 多机通信）；改用开漏只需把 GPIO_Mode 改成 GPIO_Mode_Out_OD。

4. LED 流水灯（3-2）

  • 复制 3-1 LED闪烁 改名 3-2 LED流水灯，双击 .uvprojx 打开。
  • 硬件：8 个 LED 正极接正极供电孔，负极分别接 PA0～PA7（低电平点亮）。
  • 初始化用按位或选多引脚：GPIO_Pin_0 | GPIO_Pin_1 | … | GPIO_Pin_7，或用 GPIO_Pin_All。
  • GPIO_Write(GPIOA, PortVal) 一次写整个 ODR；LED 低电平点亮，想让 0 号灯亮其余灭，数据要取反：~0x0001。
while (1)
{
	GPIO_Write(GPIOA, 0xFFFE);   // 0x0001 = 0000 0000 0000 0001，取反 → 只有 PA0 低电平
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFFFD);   // 0x0002 = 0000 0000 0000 0010，取反
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFFFB);   // 0x0004 取反
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFFF7);   // 0x0008 取反
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFFEF);   // 0x0010 取反
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFFDF);   // 0x0020 取反
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFFBF);   // 0x0040 取反
	Delay_ms(500);
	GPIO_Write(GPIOA, 0xFF7F);   // 0x0080 取反
	Delay_ms(500);
}
  • 0x0001、0x0002、0x0004、0x0008、0x0010、0x0020、0x0040、0x0080 逐位为 1，取反即 0xFFFE～0xFF7F（代码直接写反码），对应引脚输出低电平点亮。
  • 也可改成数组查表：显示数据放数组循环取用。
  • 现象：8 个 LED 以 500ms 间隔流水点亮。

图 12：流水灯完整代码——写 0x0001～0x0080 的反码，编译 0 Error/0 Warning

5. 蜂鸣器（3-3）

  • 接线：有源蜂鸣器 VCC → 正极供电排、GND → 负极供电排、控制极 → PB12。
  • 避开 PA15 / PB3 / PB4：默认是 JTAG 调试口（JTDI/JTDO/NJTRST），当普通 IO 不会输出，必须做引脚重映射；PB12 没这问题。
  • 复制 3-1 LED闪烁 改名 3-3 蜂鸣器；初始化 GPIOA 改 GPIOB、GPIO_Pin_0 改 GPIO_Pin_12。
  • 主循环写“响-停-响-停”（有源蜂鸣器低电平触发）：
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_12;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOB, &GPIO_InitStructure);
while (1)
{
	GPIO_ResetBits(GPIOB, GPIO_Pin_12);   // 低电平 → 响
	Delay_ms(100);
	GPIO_SetBits(GPIOB, GPIO_Pin_12);     // 高电平 → 停
	Delay_ms(100);
	GPIO_ResetBits(GPIOB, GPIO_Pin_12);   // 响
	Delay_ms(100);
	GPIO_SetBits(GPIOB, GPIO_Pin_12);     // 停
	Delay_ms(700);
}
  • 现象：蜂鸣器“滴—滴——”有节奏地响。

6. 怎么查库函数

  1. 看 .h 末尾：声明一般在头文件最后（rcc.h、gpio.h）；右键 → Go To Definition 看参数（F12 是 Keil 快捷键）。
  2. 中文库函数用户手册：《STM32F103xx 固件函数库用户手册》每个函数带说明和例程，可直接复制；是旧版本，与 V3.5.0 可能有出入。
  3. 英文 CHM：V3.5.0 无官方中文手册，压缩包附带英文 CHM（STM32F10x Standard Peripherals Firmware Library），可按函数/结构体索引查。
  4. 网上例程：搜“STM32 GPIO 初始化程序”等参考（注意甄别），配合有道词典看英文注释。
  • 小坑：清理中间文件后“跳转到定义”可能提示没信息，重新编译一次即可。

图 15：资料里的中文库函数用户手册——每个函数带说明和例程

坑与易错点

  1. ST-LINK 接线别插错：引脚不按顺序排，按丝印一一对应（3.3V/SWDIO/SWCLK/GND）。
  2. PA15/PB3/PB4 默认 JTAG：直接配成普通输出不生效，要换引脚或做重映射。
  3. 推挽 vs 开漏：推挽高低电平均有驱动；开漏高电平是高阻态、无驱动，一般输出用推挽。
  4. GPIO_WriteBit 第三参数是枚举：Bit_RESET/Bit_SET，直接写 0/1 要加 (BitAction) 强转。
  5. Delay 模块要加进工程：System 组 + 文件 + Include Paths，否则 #include "Delay.h" 报错。
  6. 老编译器要求局部变量定义放开头（C89 风格），新编译器一般不受限。
  7. 工程中间文件很大：Listings、Objects 占 20MB，分享前用清理工具删掉（约 2MB）。
  8. 低电平点亮：流水灯写 ODR 要取反（~），不然是“逐个熄灭”而不是“逐个点亮”。
  9. 面包板接线：红线朝上、板子跨凹槽插；省了限流电阻，实际电路要加。
  10. 新建工程步骤与 [2-2] 一样：本集只是快速演示，以后复制旧工程改名。
