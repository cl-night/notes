[4-2] OLED显示屏 — 学习笔记

  • 课程：江协科技《STM32入门教程-2023版 细致讲解 中文字幕》
  • 视频：BV1th411z7sn?p=10，19:55
  • 素材：239 帧关键帧（每 5 秒，宽 1280px）+ PP-OCRv4 画面硬字幕 OCR（246 段）；关键截图 11 张随笔记收录（源图在 vidsum_out/stm32_p10/frames/，站内图片在 assets/images/stm32-10/）
  • 字幕情况：该集 B 站没有 CC/AI 字幕，文本由画面烧录的中文字幕 OCR 得到（source=subtitle-ocr），偶有错字已按画面校正。

一句话结论

本集把 [4-1] 的 OLED 驱动模块真正用起来：接线（4 针 I2C：SCL→PB8、SDA→PB9）→ 把驱动三件套加进工程（OLED.c/OLED.h/OLED_Font.h，只改“引脚配置”和 OLED_I2C_Init 两处）→ 用 8 个显示函数显示字符/字符串/数字/进制；后半段完整介绍 Keil 调试模式（单步、断点、变量观察、外设寄存器实时查看），以后调复杂程序时非常有用。

0. 接线与现象

  • 4 针 OLED 固定在面包板右下角（以后一直插在这里，不占地方）；
  • GND → 负极供电孔、VCC → 正极供电孔（3.3V）；SCL → PB8、SDA → PB9；
  • 注意：OLED 下方的两个供电孔同时连到了 STM32 的 PB6、PB7——只要程序里不初始化这两个引脚，它们上电后默认是浮空输入，不会输出电平，没有影响；也可以用 GPIO 给 OLED 供电（PB6 输出低、PB7 输出高），但不规范，实际项目还是用电源供电。

现象：OLED 依次显示字符 A、字符串 HelloWorld!、数字 12345、有符号数 -66、十六进制 AA55、二进制 1010101001010101，最后调用 OLED_Clear() 清屏。

图 1：「4-1 OLED显示屏」接线图——OLED 插在面包板右下角，4 针 GND/VCC/SCL/SDA

图 2：面包板插线演示——电源引到 PB6/PB7（随后把 OLED 插到 PB6～PB9）

1. 搭工程、加入 OLED 驱动模块

  1. 复制 [3-4] 的「按键控制LED」工程文件夹，改名 4-1 OLED显示屏，打开工程，把原来 main.c 里的代码删掉、关掉多余标签页；
  2. 源码目录里有两个版本：4 针 I2C 版和 7 针 SPI 版；本课用 4 针版；
  3. 把 4 针版里的 3 个文件（OLED.c、OLED.h、OLED_Font.h）复制到工程的 Hardware 文件夹；
  4. Keil 里 Hardware 组右键 → Add Existing Files，选这 3 个文件加入工程。

三个文件的作用：

  • OLED.c：函数主体代码——引脚配置、引脚初始化、I2C 通信基本时序、用户调用的显示函数；
  • OLED.h：外部可调用函数的声明；
  • OLED_Font.h：字库点阵数据。OLED 显示屏本身不带字库，想显示字符/图形必须先把字符点阵数据定义好，这个文件就是字库，不需要修改。

只需要改两处（其余代码都不用动）：

  1. 引脚配置：SCL、SDA 接在哪个端口就改成哪个——默认 SCL = GPIOB / GPIO_Pin_8、SDA = GPIOB / GPIO_Pin_9；换端口要同时改这两行；
  2. OLED_I2C_Init 初始化函数：用 RCC 开启所用 GPIO 的时钟，并把 SCL、SDA 两个引脚初始化为开漏输出（GPIO_Mode_Out_OD），并分别初始化 Pin_8、Pin_9。

图 3：OLED.c 里的引脚配置——SCL/SDA 默认 GPIOB 的 Pin_8 / Pin_9（接线不同时要改这里）

图 4：OLED_I2C_Init——开 GPIOB 时钟，把 Pin_8/Pin_9 初始化为开漏输出（Out_OD）

2. 用显示函数（本集重点）

main.c 里先 #include "OLED.h"，然后在主循环之前调用 OLED_Init() 初始化，之后就能用各显示函数：

函数 作用 示例 现象
OLED_Init() 初始化 使用前必须调用 屏幕准备好
OLED_Clear() 清屏 最后调用 屏幕全空
OLED_ShowChar(行, 列, 字符) 显示一个字符（单引号） OLED_ShowChar(1, 1, 'A') 1 行 1 列显示 A
OLED_ShowString(行, 列, 字符串) 显示字符串（双引号） OLED_ShowString(1, 3, "HelloWorld!") 1 行 3 列开始显示 HelloWorld!
OLED_ShowNum(行, 列, 数字, 长度) 显示无符号十进制数 OLED_ShowNum(2, 1, 12345, 5) 2 行 1 列显示 12345
OLED_ShowSignedNum(行, 列, 数字, 长度) 显示有符号十进制数（带正负号） OLED_ShowSignedNum(2, 7, -66, 2) 显示 -66
OLED_ShowHexNum(行, 列, 数字, 长度) 显示十六进制 OLED_ShowHexNum(3, 1, 0xAA55, 4) 显示 AA55
OLED_ShowBinNum(行, 列, 数字, 长度) 显示二进制 OLED_ShowBinNum(4, 1, 0xAA55, 16) 显示 1010101001010101
  • 坐标：4 行 × 16 列，行/列都从 1 开始。
  • 长度参数（ShowNum 等）：长度比数字实际位数大时，前面补 0（如 12345 长度给 6 → 显示 012345）；长度比数字位数小时，会把高位切掉（如长度给 4 → 显示 2345）。
  • 显示字符串/数字时先算好坐标 + 长度，不要超出屏幕。
  • C 语言不支持直接写二进制数，所以 ShowBinNum 的入参用十六进制（如 0xAA55）代替，函数内部再按二进制显示。
  • 只想清掉部分字符：在对应位置调用 ShowString 显示空格字符串即可，不必全屏清空。

主函数示例（依次显示六种内容，最后清屏）：

#include "stm32f10x.h"
#include "Delay.h"
#include "OLED.h"

int main(void)
{
	OLED_Init();

	OLED_ShowChar(1, 1, 'A');
	OLED_ShowString(1, 3, "HelloWorld!");
	OLED_ShowNum(2, 1, 12345, 5);
	OLED_ShowSignedNum(2, 7, -66, 2);
	OLED_ShowHexNum(3, 1, 0xAA55, 4);
	OLED_ShowBinNum(4, 1, 0xAA55, 16);
	OLED_Clear();

	while (1)
	{
	}
}

3. Keil 调试模式（后半段）

这是本集后半部分，作者说“教程里用得少，但确实非常强大”，调复杂程序时很有用。

3.1 配置与进入

  • 工程选项 → Debug 页：默认选右侧硬件在线仿真（需要 ST-Link 和 STM32 都连好）；也可以选左侧仿真器，用电脑模拟 STM32 运行（不接硬件）。
  • 先编译确保工程没问题，再点工具栏里放大镜带 d 的图标进入调试模式。

3.2 调试界面

  • 主窗口：C 语言程序（黄色箭头指示下一条将要执行的代码）；
  • 上方窗口：C 语言翻译成的汇编程序；
  • 左侧窗口：寄存器组和状态标志位（汇编编程才需要关注，用 C 语言可以不管）；
  • 下方/右下：Call Stack & Locals（调用栈和局部变量）。

3.3 运行控制

  • 复位：让程序回到最开始；
  • 全速运行 / 停止全速运行；
  • 单步运行、跳过当前行、跳出当前函数、运行到光标指定行；
  • 断点：在代码左侧深灰色区域点击设置；全速运行会一直跑到断点处停下；没有断点就只能手动点停止；
  • 复位后程序从启动文件的复位中断函数开始，先跳 SystemInit，再执行 main（单步可以清楚看到这个过程）。

3.4 变量与寄存器观察

  • 命令窗口、反汇编窗口、符号窗口：符号窗口里可以查看程序里的所有变量；找到 GPIO_InitStructure 结构体，展开可看各成员；右键可以把变量/结构体添加到 Watch1 窗口实时观察，单步时能看到值的变化。
  • 还有串口、逻辑分析仪等工具（功能强大，视频未逐一演示）。
  • 外设菜单 → 系统资源查看：能看到所有外设的寄存器；例如选 GPIOA，右侧就显示 GPIOA 的全部寄存器；程序在翻转 PA0 时，看 ODR 寄存器的 ODR0 位会实时变化，同时面包板上 PA0 的 LED 也在同步闪烁——在线调试时 STM32 实时执行、Keil 实时显示外设寄存器。

3.5 注意事项

  • 调试模式下不能直接修改程序：要改程序必须先退出调试模式 → 重新编译 → 再进入调试。
  • 更多功能可以翻 Keil 的官方帮助文档（Help → 第一项），是对软件最权威细致的介绍。

4. 坑与易错点

  1. 先 OLED_Init() 再显示，否则屏幕不亮。
  2. 改引脚要改两处：OLED.c 顶部的引脚配置（OLED_W_SCL/OLED_W_SDA 宏）和 OLED_I2C_Init 里的时钟/引脚初始化，只改一处会不显示。
  3. SCL/SDA 必须初始化为开漏输出（GPIO_Mode_Out_OD），这是 GPIO 模拟 I2C 的必要条件。
  4. 字符用单引号、字符串用双引号；坐标 4 行×16 列，别越界。
  5. 长度参数要算好：比数字长补 0、比数字短则把高位丢掉（不是把整个数字完整显示出来）。
  6. C 语言不能直接写二进制字面量，用十六进制代替。
  7. OLED 不带字库：OLED_Font.h 必须复制进工程，否则字符显示不出来。
  8. PB6/PB7 不要配置成输出：它们借给 OLED 当供电孔，默认浮空输入不输出电平；除非刻意用 GPIO 给 OLED 供电，否则别把它们初始化成输出。
  9. 部分清屏用 ShowString 显示空格即可，不必 OLED_Clear。
  10. Keil 调试模式不能边调边改代码：改完要退出调试、重新编译再进。
