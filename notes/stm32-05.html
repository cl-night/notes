[3-1] GPIO输出 — 学习笔记

一句话结论

本集是 GPIO 的理论课：基本结构（APB2 → 寄存器 + 驱动器）、位结构（输入保护二极管/上下拉/施密特触发器，输出 ODR/BSRR + MOS 管）、8 种工作模式、LED 与蜂鸣器驱动电路、面包板；代码在下一集。

0. 本集定位与现象

  • 属“GPIO 输出”理论部分：GPIO 模块 4 小节依次是 [3-1] 输出理论、[3-2] 输出程序、[3-3] 输入理论、[3-4] 输入程序；第二部分还补结构体、指针、枚举等 C 语言知识。
  • 开场用现成程序演示三个现象（代码下一集讲）：LED 闪烁（1 个 LED 不断闪）、LED 流水灯（8 个 LED 循环流水）、蜂鸣器（有源蜂鸣器滴滴响）。

图 1：在面包板上演示 LED 闪烁现象（左：面包板上的 LED；右：对应的 LED闪烁 工程代码）

1. GPIO 是什么

  • GPIO = General Purpose Input Output，通用输入输出口，即平时说的“IO 口”；可配置成 8 种输入输出模式。
  • 引脚电平 0V～3.3V：数据 0 = 低电平 0V，数据 1 = 高电平 3.3V。
  • 部分引脚可容忍 5V 输入（带 FT（Five Tolerate） 标记，查 [1-2] 的引脚定义表），但输出最大只有 3.3V。
  • 输出模式：驱动 LED、控制蜂鸣器、模拟通信协议输出时序；驱动大功率设备再加驱动电路。
  • 输入模式：按键输入、外接模块电平信号、ADC 电压采集、通信协议接收数据。

图 2：GPIO 简介——定义、8 种模式、电平范围与输入/输出用途

图 3：STM32F103C8T6 引脚定义表（FT 列 = 可容忍 5V 输入的引脚）

2. GPIO 基本结构

  • 所有 GPIO 都挂在 APB2 外设总线上；按 GPIOA、GPIOB、GPIOC…… 命名，每个端口 16 个引脚（0～15），即 PA0～PA15、PB0～PB15。
  • 模块内部主要是 寄存器 + 驱动器：
    • 寄存器：特殊的存储器，内核经 APB2 总线读写；每一位对应一个引脚——输出寄存器写 1 对应引脚高电平、写 0 低电平，输入寄存器读 1 表示高电平、读 0 表示低电平。STM32 是 32 位机、寄存器 32 位，但端口只有 16 位，只用低 16 位。
    • 驱动器：增加信号驱动能力；寄存器只存数据，真正点灯要靠驱动器提供电流。

图 4：GPIO 基本结构——APB2 总线连接 GPIOA/GPIOB 的寄存器和驱动器，每端口 16 个引脚

3. GPIO 位结构（本集重点）

参考手册**「I/O 端口位的基本结构」图（手册图 13）：左边三个寄存器，中间驱动器，右边某一个 IO 引脚；分成输入部分**（上）和输出部分（下）。

图 5：GPIO 位结构总图（左：寄存器；中：输入/输出驱动器；右：IO 引脚与保护二极管）

3.1 输入部分

  • 保护二极管：对输入电压限幅——高于 3.3V 时上管导通、电流流入 VDD 不进内部电路；低于 0V 时下管导通、电流从 VSS 流出；0～3.3V 之间都不导通，故不影响电路。
  • FT 引脚的额外保护：容忍 5V 的引脚上方二极管电源标为 VDD_FT（与普通 VDD 不同）；否则接 VDD 3.3V、外部又接 5V 时上管会开启并产生较大电流。
  • 上拉/下拉电阻：上拉接 VDD、下拉接 VSS，开关可由程序配置——上拉通下拉断 = 上拉输入（悬空默认高电平）；上拉断下拉通 = 下拉输入（悬空默认低电平）；都断开 = 浮空输入（电平不确定）。阻值都比较大的弱上拉/弱下拉，目的是给悬空引脚一个默认电平、又不影响正常输入。浮空输入必须接连续驱动源，不能悬空。
  • 施密特触发器：高于上限阈值输出变高、低于下限阈值输出变低，处于上下限之间时保持原输出（滞回），避免信号波动误判；中文手册译作“肖特基触发器”是翻译错误。
  • 输入数据寄存器（IDR）：读某一位即知对应端口的输入电平。
  • 两路“旁路”：模拟输入接 ADC（在施密特触发器之前，因为 ADC 要采模拟量）；复用功能输入接其他需要读端口的外设（在触发器之后，如串口输入引脚）。

3.2 输出部分

  • 数字部分由输出数据寄存器（ODR）或片上外设经数据选择器控制：选 ODR = 普通 IO 输出，选片上外设 = 复用功能输出。
  • ODR 同时控 16 个端口且只能整体读写，单独改一位有三种办法：
    1. 先读 ODR，用按位与/按位或改某一位再写回；
    2. BSRR：低 16 位写 1 置位（高电平）、高 16 位写 1 清除（低电平），其余位写 0 无影响，一步到位；清位也可用 BRR（低 16 位写 1 清除）；
    3. 读写位带（bit-band）区域，类似 51 的位寻址（本课用库函数，库函数用 BSRR/BRR）。
  • 输出控制后接 P-MOS + N-MOS，分三种输出方式：
    • 推挽输出：两管均有效——ODR=1 上管导通、输出接 VDD 为高电平；ODR=0 下管导通、输出接 VSS 为低电平；高低电平均有驱动能力。
    • 开漏输出：P-MOS 无效——ODR=1 输出相当于断开（高阻态、无驱动能力）；ODR=0 下管导通、输出接 VSS 为低电平；只有低电平有驱动。可作 I2C 等通信驱动，也可外接上拉到 5V 输出 5V 电平；多机通信时还能避免设备相互干扰。
    • 关闭：配成输入模式时两管都无效，端口电平由外部信号控制。

图 6：输出部分——ODR、位设置/清除寄存器、输出控制与 P-MOS/N-MOS（推挽/开漏）

4. 八种工作模式

通过配置端口配置寄存器，位结构电路可变成以下 8 种模式：

模式名称 性质 特征
浮空输入 数字输入 可读取引脚电平，若引脚悬空，则电平不确定
上拉输入 数字输入 可读取引脚电平，内部连接上拉电阻，悬空时默认高电平
下拉输入 数字输入 可读取引脚电平，内部连接下拉电阻，悬空时默认低电平
模拟输入 模拟输入 GPIO 无效，引脚直接接入内部 ADC
开漏输出 数字输出 可输出引脚电平，高电平为高阻态，低电平接 VSS
推挽输出 数字输出 可输出引脚电平，高电平接 VDD，低电平接 VSS
复用开漏输出 数字输出 由片上外设控制，高电平为高阻态，低电平接 VSS
复用推挽输出 数字输出 由片上外设控制，高电平接 VDD，低电平接 VSS
  • 前三种输入电路结构基本一样，只差上拉/下拉电阻；都属数字输入，能读取高低电平。
  • 模拟输入是 ADC 专属：输出断开、施密特触发器关闭，引脚直接接 ADC，其他时候用不到。
  • 开漏/推挽都是数字输出，区别是高阻态 vs 有驱动能力；复用开漏/复用推挽由片上外设控制，通用输出部分不连接。
  • 重要结论：输出模式下输入部分仍有效（一个端口只能有一个输出，但可有多个输入）；除模拟输入关闭数字输入外，其余 7 种模式数字输入都有效。

图 7：八种工作模式表（浮空/上拉/下拉输入、模拟输入、开漏/推挽输出、复用开漏/复用推挽输出）

5. 寄存器与输出速度

本集只讲 GPIO，AFIO 以后再讲；手册里还有外设 GPIO 配置表（用片上外设引脚时按表推荐值配置）。

寄存器 偏移 作用
GPIOx_CRL 0x00 端口配置低寄存器：管理 0～7 号引脚，每个引脚 4 位（MODE[1:0] + CNF[1:0]）
GPIOx_CRH 0x04 端口配置高寄存器：管理 8～15 号引脚
GPIOx_IDR 0x08 端口输入数据寄存器：低 16 位对应 16 个引脚
GPIOx_ODR 0x0C 端口输出数据寄存器：低 16 位对应 16 个引脚
GPIOx_BSRR 0x10 位设置/清除寄存器：低 16 位 BS 置位、高 16 位 BR 清除
GPIOx_BRR 0x14 位清除寄存器：低 16 位写 1 清除对应位
GPIOx_LCKR 0x18 配置锁定寄存器：锁定端口配置，防止意外更改
  • 每个引脚由 4 位配置，16 个引脚共 64 位，所以要 CRL / CRH 两个 32 位寄存器。
  • 配置寄存器还多了输出速度（MODE）：限制引脚最大翻转速度（2/10/50MHz），目的是低功耗与稳定性；要求不高时配 50MHz 即可。
  • BSRR 高 16 位与 BRR 低 16 位功能相同：单独置位用 BSRR、单独清位用 BRR 更方便；多个端口要同时置位和清位时，用一个 BSRR 才能保证同步。
  • LCKR 锁定配置防意外更改，用得不多。

图 9：GPIOx_BSRR 位设置/清除寄存器（低 16 位 BS 置位，高 16 位 BR 清除）

6. LED、蜂鸣器与驱动电路

  • LED：发光二极管，正向通电点亮、反向通电不亮。符号左正右负；实物长脚是正极、短脚是负极；内部较小的一半是正极、较大的一半是负极。
  • 有源蜂鸣器：自带振荡源，正负极接直流即持续发声、频率固定；本课使用的就是它，模块内三极管驱动，信号脚低电平触发（接低电平响，接高电平关闭）。
  • 无源蜂鸣器：不带振荡源，需控制器给振荡脉冲，改脉冲频率可改音调（51 教程用过，本集不涉及）。

图 10：LED 与蜂鸣器介绍（LED 符号/实物、有源蜂鸣器模块与内部三极管电路）

LED 两种接法：

  • 低电平驱动：正极接 3.3V，负极经限流电阻 R1 接 PA0；PA0 低电平时两端有压差、正向导通点亮，高电平时两端都是 3.3V、熄灭。
  • 高电平驱动：负极接 GND，正极经限流电阻接 PA0；高电平点亮、低电平熄灭。
  • 限流电阻一般都要接：防 LED 电流过大烧毁，还能调亮度（太刺眼就增大阻值）；面包板演示为简化省了，自己设计电路要加上。
  • 两种接法推挽下都可用，但一般倾向低电平驱动：很多芯片高电平弱驱动、低电平强驱动，高电平驱动可能驱不动。

蜂鸣器用三极管开关驱动（直接 IO 驱动会让 STM32 负担过重）：

  • PNP（Q1 S8550，接 VCC 侧）：基极给低电平导通（响），高电平截止。
  • NPN（S8050，接 GND 侧）：基极给高电平导通，低电平断开。
  • 原因：通断需在发射极与基极间产生开启电压；PNP 接上边、NPN 接下边，负载位置接错可能无法开启。

图 11：硬件电路——左侧 LED 低电平/高电平驱动电路，右侧蜂鸣器三极管驱动（PNP 上、NPN 下）

图 12：蜂鸣器三极管驱动——PNP（上，低电平导通）与 NPN（下，高电平导通）

7. 面包板的使用

  • 正面是插孔、背面是一条条金属爪；引脚插进孔被金属爪夹住即连通。
  • 规律：中间竖排 5 个孔内部相连（一列 5 孔一组）；上下各两排供电轨整体相连，标 + / -——第一排正极、第二排负极、第三排正极、第四排负极，供电时用跳线引出。
  • 有的面包板供电轨中间是断开的，要自己用跳线连起来（视频这块恰好连通）。
  • 示例“电源直接点亮 LED”：供电轨接电源正负极 → 跳线引正极 → 限流电阻 → LED → 跳线接回负极。

图 14：面包板接线示例——红/蓝线为“电源→限流电阻→LED→负极”的电流路径

坑与易错点

  1. 5V 不能乱接：只有 FT 标记的引脚能容忍 5V 输入；输出最高 3.3V。
  2. 浮空输入不能悬空：必须接连续驱动源；不确定时优先用上拉/下拉输入。
  3. ODR 只能整体读写：单独改一个引脚要用 &= / |= 只改目标位；更推荐 BSRR 置位 / BRR 清位（一步到位，库函数也这么做）。
  4. 输出模式下输入也有效：除模拟输入外其余 7 种模式数字输入都可用（“一个输出、多个输入”）。
  5. 开漏输出高电平是高阻态：没有驱动能力；要输出 5V 需外接上拉到 5V，I2C 等通信正利用开漏。
  6. 限流电阻不能省：面包板演示省了，实际电路一定要加，否则 LED 可能烧毁。
  7. 三极管方向：PNP 接上边（基极低电平导通），NPN 接下边（基极高电平导通）；负载位置不对可能无法开启。
  8. 面包板供电轨不一定整排连通：用前先确认，必要时中间加跳线。
  9. 中文手册“肖特基触发器”是翻译错误，实际是施密特触发器。
  10. 用片上外设引脚先查配置表：外设 GPIO 配置表里写了推荐模式，别配错。
