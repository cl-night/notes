[1-2] STM32简介 — 学习笔记

  • 素材目录：vidsum_out/stm32_p2/（sheets/、frames/、transcript.txt）

一句话结论

本集是整门课的地图：讲清 STM32 是什么、ARM 与 ST 怎么分工，再用 STM32F103C8T6 串起参数、片上外设、命名规则、系统结构、引脚、启动配置与最小系统电路。

本集定位

  • 纯理论铺垫，无代码、无工程。
  • 后面所有实验都在 C8T6 上做，先把地图建好。

1. STM32 是什么

  • STM32 = ST + M + 32：ST 意法半导体（芯片厂商）；M 指微控制器（MCU、单片机），不是 Cortex-M 内核缩写；32 指 32 位。
  • 定义：ST 基于 ARM Cortex-M 内核开发的 32 位微控制器；ST 也有 8 位单片机 STM8。
  • 常见应用：智能车（循迹）、无人机（姿态控制）、机器人（舵机）、无线通信（2.4G/蓝牙/WiFi）、物联网、工业控制（PLC 主控）、娱乐电子。

2. 家族与 ARM 分工

系列 型号 特点
高性能 F2 / F4 / F7 / H7 性能最强；H7 为 M7+M4 双核
主流 F0 / F1 / F3 课程使用 F1（F103C8T6）
超低功耗 L0 / L1 / L4 / L5 电池/低功耗场景
无线 WL / WB 内置无线通信
  • 同一家族换系列再学，比换别的芯片轻松很多；F1 学通，性能不够再上 F4/F7/H7，功耗敏感看 L 系列。
  • ARM 是半导体知识产权（IP）提供商：只设计内核、不生产芯片，把设计授权给厂商收授权费。
  • ST、TI、NXP 等 买内核授权，再加存储器、外设、接口做成自己的芯片；类比 ARM 出 CPU、ST 加主板和外设。
  • 内核三大系列：Cortex-A 手机/平板等高端应用；Cortex-R 硬实时（如硬盘控制器）；Cortex-M 单片机，STM32 用的就是它。
  • M 系列对应：STM32F0 → M0；STM32F1 → Cortex-M3；STM32F3 → M4；STM32F4/F7 → M4/M7；STM32H7 → M7 + M4 双核。
  • 老型号 ARM7 / ARM9 / ARM11 属经典 ARM 处理器，新设计基本都用 Cortex。

3. F103C8T6 关键参数

项目 参数
系列 STM32F1（主流系列）
内核 ARM Cortex-M3
主频 72 MHz
Flash（程序存储器） 64 KB
SRAM（运行内存） 20 KB
供电 2.0–3.6 V（标准 3.3 V）
封装 LQFP48（48 脚）
工作温度 -40–85 ℃（型号末位 6）
  • 供电：51 常用 5V，USB 也是 5V；STM32 只吃 2.0–3.6V，5V 不能直接接，要稳压到 3.3V。

SysTick System Tick Timer 系统滴答定时器（内核内）
RCC Reset and Clock Control 复位和时钟控制；外设默认无时钟，用前必须使能
GPIO General Purpose IO 通用 IO，点灯/读按键
AFIO Alternate Function IO 复用功能重映射、中断端口配置
EXTI External Interrupt 外部中断，引脚电平变化触发
TIM Timer 定时器，最常用；分高级/通用/基本
ADC Analog-to-Digital Converter 12 位模数转换
DMA Direct Memory Access 直接存储器存取，帮 CPU 搬数据
USART Universal Synchronous/Asynchronous Receiver/Transmitter 同步/异步串口
I2C Inter-Integrated Circuit I2C 通信
SPI Serial Peripheral Interface SPI 通信
CAN Controller Area Network 汽车/工业总线
USB Universal Serial Bus USB 设备/主机

IWDG / WWDG Independent / Window Watchdog 独立/窗口看门狗，死机复位
BKP Backup Register 备份寄存器，掉电由电池保持
PWR Power Control 电源控制，睡眠/停止/待机

  • C8T6 实际数量：64 KB Flash、20 KB SRAM；3 个通用定时器、1 个高级定时器、没有基本定时器；2 个 SPI、2 个 I2C、3 个 USART、1 个 USB、1 个 CAN；37 个 GPIO；2 个 12 位 ADC。
  • 上表是 F1 全系列的外设，C8T6 没有 DAC、SDIO、FSMC、USB OTG；操作不存在的外设不会工作，用前查数据手册。

6. 系统结构

  • 内核：Cortex-M3，内含 NVIC、SysTick。
  • 内核总线：ICode 取指令、连 Flash；DCode 取数据（常量、调试参数）、连 Flash；System 连 SRAM、FSMC。
  • AHB（先进高性能总线，72MHz）：RCC、SDIO、FSMC、DMA、SRAM、Flash 接口；经两个桥接分出 APB2 和 APB1。
  • APB2（72MHz，高速）：GPIO、AFIO、EXTI、TIM1/TIM8、USART1、SPI1、ADC1/2 等“1 号/重要”外设。
  • APB1（36MHz，低速）：TIM2–7、USART2–5、I2C1/2、SPI2、CAN、USB、DAC、PWR、BKP。
  • DMA 是“CPU 的小秘书”：ADC 连续转换的数据不及时搬走会被覆盖，CPU 每毫秒搬一次太浪费；外设发 DMA 请求，DMA 经总线矩阵拿总线控制权直接搬运，全程不用 CPU。

7. 引脚定义与启动配置

  • LQFP48 共 48 个引脚，左上角小黑点对应 1 号，逆时针编号到 48。
  • 引脚表要看的列：
    • 引脚号 / 引脚名称、类型（I 输入、O 输出、IO 输入输出）
    • IO 电平：带 FT 可容忍 5V，没有 FT 只能 3.3V，接 5V 要电平转换
    • 主功能：上电默认功能，一般同引脚名，不同时以主功能为准
    • 默认复用功能：该 IO 上同时连接的外设功能
    • 重定义功能：复用功能冲突时用 AFIO 重映射，前提是表里有对应端口
  • 电源与复位脚：VBAT 备用电池（3V 纽扣）供 RTC/BKP，不用可接 3.3V 或悬空；VDD / VSS 主电源 3.3V/GND；VDDA / VSSA 模拟电源；NRST 低电平复位。
  • 功能脚：PA0 可做 WKUP 唤醒待机；PA13 / PA14 SWDIO/SWCLK 做 SWD 下载调试；PA15 / PB3 / PB4 JTAG 调试口，用 SWD 时可作普通 IO；BOOT0（44 脚）、BOOT1（PB2） 启动配置。
  • 时钟脚：PC13 / PC14 / PC15（PC13 可做 GPIO/侵入检测/RTC，PC14/15 接 32.768kHz 晶振）；PD0 / PD1 接 8MHz 主晶振（OSC_IN/OSC_OUT）。
  • 调试口警告：5 个调试脚全配成普通 IO 就没有调试口，ST-Link 下载不了；可用 BOOT0=1、BOOT1=0 的串口下载救急。
BOOT0 BOOT1（PB2） 启动模式 说明
0 x 主闪存（Main Flash） 正常运行程序，最常用
1 0 系统存储器（System Memory） 厂家 Bootloader，串口下载程序
1 1 内置 SRAM 调试用，掉电丢失
  • BOOT 引脚只在复位瞬间被采样，之后 BOOT1 恢复为 PB2 普通 GPIO。
  • 串口下载：BOOT0=1、BOOT1=0 → 复位进 Bootloader → 串口下载 → BOOT0=0 → 复位运行；没有 ST-Link 时也能用。

8. 最小系统电路

  1. 电源：所有 VDD 接 3.3V、VSS 接 GND，VDDA/VSSA 也要供电；每组电源脚加 100nF 去耦电容、总电源加 10uF，VBAT 可接 3V 纽扣电池；5V（USB）经稳压芯片（XC6204/XC6206/AMS1117）降到 3.3V。
  2. 晶振：8MHz 主晶振（HSE）+ 两个 20pF 起振电容接 OSC_IN/OSC_OUT，内部 PLL ×9 得 72MHz；需 RTC 再加 32.768kHz（LSE）+ 电容接 OSC32，32.768k = 2^15，内部 2^15 分频得 1 秒。
  3. 复位：NRST 用 10kΩ 上拉到 3.3V、100nF 到地，并联复位按键；上电瞬间电容短路拉低 NRST，随充电变高产生上电复位。
  4. 启动配置：BOOT0 用跳线/拨码开关选 GND（0）或 3.3V（1），BOOT1 同理（PB2）。
  5. 下载调试：引出 SWDIO、SWCLK、3.3V、GND 接 ST-Link；GND 必须接，3.3V 建议也引。
  6. 课程蓝色最小系统板：含 3.3V 稳压、USB 5V 输入、8MHz + 32.768kHz 晶振、复位键、BOOT 跳线、PWR 指示灯、PC13 测试灯、SWD 接口、两排排针；USB 接 PA11/PA12，可做 USB 通信并给板子供电。

坑与易错点

  1. 5V 不能直接给 STM32 供电，要 3.3V；5V 信号接非 FT 引脚也要电平转换。
  2. 别把所有调试脚都配成普通 IO，否则 ST-Link 下载不了；留 SWD，或会串口下载。
  3. C8T6 不是全外设：没有 DAC、SDIO、FSMC、USB OTG，表里是 F1 全系列。
  4. BOOT 引脚只在复位瞬间有效，之后就是普通 GPIO；改了 BOOT 要复位才生效。
  5. APB1 是 36MHz、APB2 是 72MHz，外设挂哪条总线、时钟怎么配，后面写代码会遇到。
