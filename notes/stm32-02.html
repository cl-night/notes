一句话结论

这一集是整门课的“地图”：先讲清 STM32 是什么、ARM 和 ST 怎么分工，再用 STM32F103C8T6 把型号参数、片上外设、命名规则、系统结构、引脚、启动方式和最小系统电路串一遍。

1. STM32 是什么

  • STM32 = ST + M + 32：
    • ST：意法半导体（芯片厂商）。
    • M：Microcontroller，微控制器（MCU、单片机）。
    • 32：32 位。
  • 定义：ST 公司基于 ARM Cortex-M 内核开发的 32 位微控制器。
  • 注意：M 不是“Cortex-M 内核”的缩写，而是“微控制器”；内核是 Cortex-M，但名字里的 M 指 MCU。
  • ST 也有 8 位单片机 STM8，可以了解。
  • 常见应用：智能车（循迹）、无人机（姿态控制）、机器人（舵机）、无线通信（2.4G/蓝牙/WiFi）、物联网、工业控制（PLC 主控）、娱乐电子等。

2. STM32 家族

系列 型号 特点
高性能 F2 / F4 / F7 / H7 性能最强；H7 为 M7+M4 双核
主流 F0 / F1 / F3 课程使用 F1（F103C8T6）
超低功耗 L0 / L1 / L4 / L5 电池/低功耗场景
无线 WL / WB 内置无线通信
  • 同一个家族，换系列再学习会比换别的芯片轻松很多。
  • 课程先把 F1 学通；性能不够再上 F4/F7/H7，功耗敏感看 L 系列。

3. ARM 与 Cortex 系列

  • ARM 公司是半导体知识产权（IP）提供商：只设计内核，不生产芯片；把设计授权给各大半导体厂商，收授权费。
  • ST、TI、NXP 等 买 ARM 内核授权，再加上存储器、外设、接口，做成自己的芯片。
  • 类比：ARM 出 CPU，ST 加主板和外设，最后做成 STM32。
  • ARM 内核分三大系列：
    • Cortex-A（Application）：手机/平板/高端应用，性能最高。
    • Cortex-R（Real-time）：硬实时场景，如硬盘控制器。
    • Cortex-M（Microcontroller）：单片机，STM32 用的就是 M 系列。
  • M 系列常见内核：M0 / M0+ / M3 / M4 / M7。
    • STM32F0 → Cortex-M0
    • STM32F1 → Cortex-M3
    • STM32F3 → Cortex-M4
    • STM32F4/F7 → Cortex-M4/M7
    • STM32H7 → M7 + M4 双核
  • 老型号 ARM7 / ARM9 / ARM11 属于经典 ARM 处理器，现在新设计基本都用 Cortex。

4. STM32F103C8T6 关键参数

项目 参数
系列 STM32F1（主流系列）
内核 ARM Cortex-M3
主频 72 MHz
Flash（程序存储器） 64 KB
SRAM（运行内存） 20 KB
供电 2.0–3.6 V（标准 3.3 V）

供电注意：以前 51 单片机常用 5V，USB 也是 5V；STM32 的供电范围是 2.0–3.6V，5V 不能直接接，要加稳压芯片降到 3.3V。

C8T6 的实际外设数量（数据手册）：

  • 64 KB Flash、20 KB SRAM
  • 3 个通用定时器、1 个高级定时器、没有基本定时器
  • 2 个 SPI、2 个 I2C、3 个 USART、1 个 USB、1 个 CAN
  • 37 个 GPIO
  • 2 个 12 位 ADC

表里是 F1 全系列的外设，不是每个型号都有。C8T6 没有 DAC、SDIO、FSMC、USB OTG。 操作不存在的外设不会工作，用之前查数据手册。

7. 系统结构

可以分成四块看：

  1. 内核：Cortex-M3，内含 NVIC、SysTick。
  2. 内核总线：
    • ICode：取指令，连 Flash。
    • DCode：取数据（常量、调试参数），连 Flash。
    • System：连 SRAM、FSMC 等。
  3. 总线矩阵 / AHB + 桥接：
    • AHB（先进高性能总线，72MHz）：RCC、SDIO、FSMC、DMA、SRAM、Flash 接口等。
    • 通过两个桥接分出 APB2 和 APB1。
  4. 外设：
    • APB2（72MHz，高速）：GPIO、AFIO、EXTI、TIM1/TIM8、USART1、SPI1、ADC1/2 等“1 号/重要”外设。
    • APB1（36MHz，低速）：TIM2–7、USART2–5、I2C1/2、SPI2、CAN、USB、DAC、PWR、BKP 等。

DMA 是“CPU 的小秘书”：ADC 连续转换时，数据不及时搬走就会被覆盖；让 CPU 每毫秒搬一次太浪费，DMA 通过总线矩阵获得总线控制权，外设发 DMA 请求，它就把数据搬走，全程不需要 CPU。

8. 引脚定义

  • LQFP48 共 48 个引脚；芯片左上角小黑点对应的引脚是 1 号，逆时针编号到 48。
  • 引脚表要看的列：
    • 引脚号 / 引脚名称
    • 类型：I=输入、O=输出、IO=输入输出
    • IO 电平：带 FT 的引脚可容忍 5V；没有 FT 的只能 3.3V，接 5V 信号要加电平转换
    • 主功能：上电默认功能，一般和引脚名相同；不同时以主功能为准
    • 默认复用功能：该 IO 上同时连接的外设功能
    • 重定义功能：两个复用功能冲突时，可通过 AFIO 把其中一个重映射到别的引脚（前提是表里有对应端口）
  • 关键引脚：
    • VBAT：备用电池（3V 纽扣电池），给 RTC 和 BKP 供电；不用可接 3.3V 或悬空。
    • VDD / VSS：多组主电源，VDD 接 3.3V，VSS 接 GND。
    • VDDA / VSSA：模拟部分电源，ADC 等使用。
    • NRST：低电平复位。
    • PA0：还可做 WKUP，唤醒待机。
    • PA13 / PA14：SWDIO / SWCLK，SWD 下载调试。
    • PA15 / PB3 / PB4：JTAG 调试口，用 SWD 时可配置为普通 IO。
    • BOOT0（44 脚）、BOOT1（PB2）：启动配置。
    • PC13 / PC14 / PC15：PC13 可做 GPIO/侵入检测/RTC；PC14/15 接 32.768kHz 晶振。
    • PD0 / PD1：接 8MHz 主晶振（OSC_IN/OSC_OUT）。
  • 调试口警告：如果把 5 个调试引脚全部配置成普通 IO，芯片就没有调试口，ST-Link 下载不了；此时可用 BOOT0=1、BOOT1=0 的串口下载救急。所以不要把所有调试脚都关掉。

9. 启动配置

BOOT0 BOOT1（PB2） 启动模式 说明
0 x 主闪存（Main Flash） 正常运行程序，最常用
1 0 系统存储器（System Memory） 厂家 Bootloader，串口下载程序
1 1 内置 SRAM 调试用，掉电丢失
  • BOOT 引脚只在复位瞬间被采样；之后 BOOT1 引脚就恢复为 PB2 普通 GPIO。
  • 串口下载流程：BOOT0=1、BOOT1=0 → 复位进入 Bootloader → 串口下载 → BOOT0=0 → 复位运行。
  • 没有 ST-Link 时，串口下载也是一种下载方式；调试脚被占用时也能救急。

10. 最小系统电路

单片机只有芯片不能工作，需要最基本的“最小系统”：

  1. 电源
    • 所有 VDD 接 3.3V，VSS 接 GND；VDDA/VSSA 也要供电。
    • 每组电源脚附近加 100nF 去耦电容，总电源加 10uF；VBAT 可接 3V 纽扣电池给 RTC/BKP。
    • 5V（USB）经稳压芯片（XC6204/XC6206/AMS1117 等）降到 3.3V。
  2. 晶振
    • 8MHz 主晶振（HSE）+ 两个 20pF 起振电容，接 OSC_IN/OSC_OUT；内部 PLL ×9 得到 72MHz。
    • 需要 RTC 时再加 32.768kHz 晶振（LSE）+ 电容，接 OSC32；32.768k = 2^15，内部 2^15 分频得到 1 秒。
  3. 复位
    • NRST 用 10kΩ 上拉到 3.3V，100nF 电容到地，并联复位按键。
    • 上电瞬间电容短路 → NRST 低 → 随充电变高，产生上电复位；按键手动拉低复位。
  4. 启动配置
    • BOOT0 用跳线/拨码开关选择 GND（0）或 3.3V（1）；BOOT1 同理（PB2）。
  5. 下载调试
    • 引出 SWDIO、SWCLK、3.3V、GND，接 ST-Link；GND 必须接，3.3V 建议也引。
  6. 课程用的蓝色最小系统板
    • 已包含：3.3V 稳压、USB 5V 输入、8MHz + 32.768kHz 晶振、复位键、BOOT 跳线、PWR 指示灯、PC13 测试灯、SWD 接口、两排排针。
    • USB 接 PA11/PA12，可做 USB 通信，也给板子供电。

11. 五个容易踩的坑

  1. 5V 不能直接给 STM32 供电，要 3.3V；5V 信号接非 FT 引脚也要电平转换。
  2. 不要把所有调试脚都配成普通 IO，否则 ST-Link 下载不了；留 SWD，或会用串口下载。
  3. C8T6 不是全外设：没有 DAC、SDIO、FSMC、USB OTG；表里是 F1 全系列。
  4. BOOT 引脚只在复位瞬间有效，之后就是普通 GPIO；改了 BOOT 要复位才生效。
  5. APB1 是 36MHz、APB2 是 72MHz；外设挂在哪条总线、时钟怎么配，后面写代码会遇到。
