一句话结论

W25Q64 是 W25Qxx 系列里的一颗 SPI 接口 NOR Flash 存储器：低成本、小型化、使用简单、非易失性（掉电不丢失），常用于数据存储、字库存储、固件程序存储——尤其固件程序存储支持 XIP（eXecute In Place，就地执行），就像电脑的 BIOS 固件存在这类芯片里，单片机可以直接从 Flash 取指令运行。存储介质是 NOR Flash（闪存）（闪存分 NOR 与 NAND 两类，各有优劣，本芯片是 NOR）。时钟频率：普通 SPI 的 SCK 最大 80MHz、160MHz（Dual SPI 等效）/320MHz（Quad SPI 等效）——Dual SPI 让 MOSI 和 MISO 同时收发（两根线并行）、Quad SPI 再把 WP 和 HOLD 也当数据线 IO2/IO3（4 位并行），本课程不用，但 80MHz 已经远高于 GPIO 翻转速度，所以用软件 SPI 时完全不用加延时。容量（24 位地址）：W25Q40 4Mbit/512KB、W25Q80 8Mbit/1MB、W25Q16 16Mbit/2MB、W25Q32 32Mbit/4MB、W25Q64 64Mbit/8MB、W25Q128 128Mbit/16MB、W25Q256 256Mbit/32MB——Mbit÷8＝MByte；24 位地址最多寻址 2 的 24 次方＝16MB，所以 W25Q256（32MB）用 3 字节地址只能访问前 16MB（访问完整容量要用 4 字节地址模式）。引脚：VCC/GND 电源（2.7～3.6V，典型 3.3V，不能接 5V）、CS(SS)＝SPI 片选、低电平有效、CLK(SCK)＝SPI 时钟、DI(MOSI)＝主机输出从机输入、DO(MISO)＝主机输入从机输出、WP＝写保护（配合状态寄存器，接低保护/接高正常）、HOLD＝数据保持、低有效（可暂停当前时序去忙别的）；引脚编号：1=/CS、2=DO(IO1)、3=/WP(IO2)、4=GND、5=DI(IO0)、6=CLK、7=/HOLD(IO3)、8=VCC（括号里的 IO0～IO3 供 Dual/Quad 使用）。存储结构：8MB＝128 块（Block 0～127）×64KB；每块 16 个扇区（Sector）×4KB；每扇区 16 页（Page）×256B；地址范围 0x000000～0x7FFFFF（块 0＝0x000000～0x00FFFF，块 31＝0x1F0000～0x1FFFFF）。Flash 的写入注意事项（核心，6 条）：① 写入前必须先「写使能」（一种保护措施，防误操作，像手机锁屏）② 每个数据位只能由 1 改写为 0，不能由 0 改写为 1（所以 0xAA 覆盖写 0x55 实际得到 0x00）③ 写入数据前必须先擦除（擦除后所有位变 1，即 0xFF＝空白，读到 FF 说明该处没写过数据）④ 擦除必须按最小擦除单元（扇区 4KB / 块 64KB / 整片），所以只想改一个字节也要「读出整扇区→改→擦除→写回」（或用备份扇区机制缓解）⑤ 连续写多字节时最多写一页（256 字节），超过页尾的数据会回到页首覆盖写入，所以不能跨页写 ⑥ 写入结束后芯片进入忙状态（BUSY），不响应新的读写操作。读取注意事项（1 条）：直接调用读取时序，无需使能、无页限制、读完后不进入忙状态，但芯片忙时不能读。为什么会这样：Flash 为了掉电不丢失 + 大容量，牺牲了 RAM 那样的「直接覆盖改写」能力，写入靠页缓存（256 字节 RAM）+ 高压擦写电路完成（先把数据放进缓存区、芯片再慢慢搬进 Flash，搬运期间置 BUSY）；这些不方便都可以用软件弥补，而容量大是它相对其他非易失性存储器的最大优势。手册重点：状态寄存器 1——S0 = BUSY（只读；页编程/扇区擦除/块擦除/整片擦除/写状态寄存器期间置 1，完成后清 0）、S1 = WEL 写使能锁存位（执行写使能指令后置 1；写失能、上电、以及写/擦除操作完成后自动清 0——所以写操作后会「顺手关门」，不用手动写失能），其余 BP2/BP1/BP0、TB、SEC 属写保护位「了解即可」；指令集：0x06 写使能、0x04 写失能、0x05 读状态寄存器 1、0x01 写状态寄存器、0x02 页编程（+24 位地址+数据）、0x32 Quad 页编程、0xD8 块擦除 64KB、0x52 块擦除 32KB、0x20 扇区擦除 4KB、0xC7/0x60 整片擦除、0xB9 掉电、0x90 读厂商/设备 ID、0x9F 读 JEDEC ID、0x4B 读唯一 ID、0x03 读数据（+24 位地址+连续读取、无页限制）；写使能时序：/CS 拉低 → DI 上升沿发送 0x06 → /CS 拉高，DO 全程保持高阻（High Impedance）；该芯片兼容 SPI 1. W25Q64 是什么

1.1 系列与用途

  • W25Qxx 系列：一种低成本、小型化、使用简单的非易失性存储器；
  • W25Q64：该系列中 64Mbit=8MB 的那一颗（觉得太大可以换 W25Q32 等，操作方法都一样）；
  • 应用场景：数据存储（STM32 里需要掉电保存的数据）、字库存储（字库存 Flash 里，用 SPI 读取芯片查询字模）、固件程序存储；
  • 固件程序存储 = XIP（eXecute In Place，就地执行）：把程序文件下载到外挂 Flash 里，芯片直接从 Flash 取指令运行，就像电脑的 BIOS 固件就存在 W25Q 系列芯片里；
  • 非易失性：数据掉电不丢失（关机重启数据还在）——对比易失性的 RAM、以及同为非易失性的 E2PROM（如 AT24C02，容量小）；
  • 硬件接线简单：使用 SPI 串行通信，引脚少、协议简单，除了 VCC/GND 都是 GPIO，基本不需要其他电路。

1.2 存储介质：NOR Flash

  • 存储介质是 NOR Flash（闪存）——Flash 就是闪存存储器；
  • 闪存分 NOR Flash 和 NAND Flash 两类，各有优势劣势、适用领域不同；本芯片是 NOR Flash。

1.3 时钟频率与 Dual/Quad SPI

  • 普通 SPI 下 SCK 最大 80MHz；
  • 另外两个频率：160MHz 是「双重 SPI（Dual SPI）」的等效频率、320MHz 是「四重 SPI（Quad SPI）」的等效频率（本课程不用，了解即可）；
  • 为什么能翻倍：SPI 是全双工的，只发或只收时有一根数据线闲着（资源浪费）——Dual SPI 让 MOSI 和 MISO 同时用于发送（或同时用于接收），相当于一个时钟收发 2 位；Quad SPI 再把 WP、HOLD 也拉来当数据线（IO2、IO3），4 根线一起收发，相当于 4 位并行——这就是「等效频率 80×2 / 80×4」的来历（实际 SCK 最大还是 80MHz）；
  • 代码层面的意义：80MHz 远高于 GPIO 翻转能达到的速度，所以本课程用软件 SPI 时，翻转引脚完全不需要加延时。

1.4 容量换算与 24 位地址

  • 1 字节＝8 位，所以 Mbit ÷ 8 ＝ MByte：4Mbit÷8=512KB、8Mbit÷8=1MB、16Mbit÷8=2MB、64Mbit÷8=8MB……
  • 括号里的「24 位地址」＝3 个字节的地址——因为读写时要一次性指定 3 个字节的地址，才能找到每个字节单元；
  • 24 位地址最大寻址 2 的 24 次方＝16MB（计算：2^24 / 1024 / 1024 = 16MB）；
  • 所以：W25Q64（8MB）用 3 字节地址是够的；W25Q256（32MB）如果只用 3 字节地址，就只能访问前 16MB，后 16MB 要改用 4 字节地址模式。

3. 存储结构（框图）

3.1 空间划分

  • 8MB 空间太大，不划分不利于管理，所以按层级划分：
    • 块（Block）：128 块 × 64KB（Block 0～127）；
    • 扇区（Sector）：每块 16 个扇区 × 4KB（Sector 0～15）；
    • 页（Page）：每扇区 16 页 × 256B；
  • 地址范围 0x000000～0x7FFFFF（8MB，最高字节是 7F 而不是 FF，因为 24 位地址只寻址 16MB、本芯片只用到前 8MB）；
  • 块/扇区地址：块 0＝0x000000～0x00FFFF、块 31＝0x1F0000～0x1FFFFF；（块 n 起始＝n×0x10000）；
  • 页是直接对整个存储空间划分的（不是按扇区独立编号）；页大小 256 字节。

3.2 框图内部模块

  • 左侧：SPI 通信引脚（CLK、/CS、DI、DO）+ /HOLD、/WP → SPI Control & Logic（SPI 控制逻辑）：自动操作内部电路；
  • Write Control Logic（写控制逻辑）+ Status Register（状态寄存器）：状态寄存器里体现当前芯片状态（BUSY/WEL 等）；
  • High Voltage Generators（高电压生成器）：Flash 擦写需要高压——用「LED 烧坏」的比喻理解：烧坏的 LED 永远坏（相当于写 1），没烧坏的可以继续烧（相当于写 0），且不受是否供电影响（掉电不丢失）；
  • Page Address Latch/Counter（页地址锁存/计数器）、Byte Address Latch/Counter（字节地址锁存/计数器）：接收主机发来的 24 位地址（前两个字节进页地址计数器、剩下的做字节地址）；
  • Column Decode And 256-Byte Page Buffer（列解码 + 256 字节页缓存）：读写最终都经过这 256 字节的 RAM 缓存——因为 SPI 写入频率非常高，而 Flash 写入速度跟不上，所以数据先放缓存区，芯片再慢慢把它搬到 Flash 里（搬运期间置 BUSY）；读取时也经过缓存区。

3.3 为什么要有页缓存

  • 直接往 Flash 里写不行，因为 SPI 总线的写入频率非常高、Flash 的写入速度跟不上；
  • 所以先把数据放进 256 字节页缓存（RAM），芯片再慢慢从缓存区转移到 Flash；
  • 数据从缓存区转到 Flash 需要时间，这段时间给状态寄存器的 BUSY 位置 1——「表示芯片正在搬砖、很忙」，此时不响应新的读写；
  • 读取数据也经过缓存区（W25Q64 内部有 256 字节 RAM 缓冲）。

4. Flash 操作注意事项（核心）

先想一个问题：不就是个存储器吗，直接指定地址读写不就行了，为什么这么多注意事项？——因为 Flash 为了「掉电不丢失」这个特性 + 大容量，在电路上做了取舍：读写不像 RAM 那样简单直接（RAM 可以直接覆盖改写：原来 0xAA，再写 0x55 就变成 0x55）。

4.1 写入操作的 6 条规定

  1. 写入操作前，必须先进行「写使能」——一种保护措施，防止误操作（就像手机锁屏，防止在兜里乱点）；
  2. 每个数据位只能由 1 改写为 0，不能由 0 改写为 1——举例：存了 0xAA（10101010），再覆盖写 0x55（01010101），由于只能 1→0，实际写入结果是 0x00（8 位全 0）；「为什么有这种限制？只能说是成本原因」；
  3. 写入数据前必须先擦除——擦除后所有数据位变为 1（0xFF）；有了擦除，才能把 0 改回 1（擦除是「专门的擦除电路」加高压完成）；
  4. 擦除必须按最小擦除单元进行——不能只擦某一位/某一字节；最小擦除单元是扇区（4KB），也可选择块擦除（64KB）或整片擦除；所以只想改写一个字节，也要「读出整个扇区（4KB）→ 改 → 擦除扇区 → 再把 4096 字节全写回去」（或者用「备份扇区/频繁使用扇区先在 RAM 里缓存、使用频率降低时再整体备份」的机制来缓解）；
  5. 连续写入多字节时，最多写入一页（256 字节）的数据——超过页尾位置的数据会回到页首覆盖写入；所以多字节写入不能跨越页的边沿，否则会地址错乱；
  6. 写入操作结束后，芯片进入忙状态，不响应新的读写操作——因为写入是对缓存区进行的，时序结束后芯片还要「搬砖」（把数据搬进 Flash），要等 BUSY 位变为 0（不忙）才能继续。

4.2 读取操作的 1 条规定

  • 直接调用读取时序，无需使能、无需额外操作、没有页的限制、读取结束后不会进入忙状态；
  • 唯一的限制：不能在忙状态时读取（要先等 BUSY=0）；
  • 结论：Flash 这些「不方便」都可以用软件来弥补，而容量大是它相对其他非易失性存储器的最大优势——「尽管慢，但在非易失性存储器中 Flash 是非常快的」。

5.2 11.1 状态寄存器

  • 状态寄存器有两个（SR1、SR2），重点看状态寄存器 1；
  • 11.1.1 BUSY（S0，只读）：页编程、扇区擦除、块擦除、整片擦除、写状态寄存器这些指令执行期间，BUSY 置 1，此时设备忽略进一步指令（只响应读状态寄存器等少数指令）；指令执行完成后 BUSY 清 0，表示设备准备好；
  • 11.1.2 WEL（Write Enable Latch，写使能锁存位，S1）：只读；执行写使能指令后置 1——代表芯片可以进行写入操作了；以下情况清 0：写失能（Write Disable）指令、上电、以及写状态寄存器/页编程/扇区擦除/块擦除/整片擦除这些操作完成之后；
    • 所以写操作后会「顺手关门」：不需要手动发写失能，因为写操作结束 WEL 自动清 0；
    • 我们在进行任何写入（含擦除）操作前，都要先发一次写使能；
  • 11.1.3 BP2/BP1/BP0（块保护位）、11.1.4 TB（Top/Bottom 保护方向）、11.1.5 SEC（扇区/块保护）——写保护相关，了解即可（本课程不用）；
  • 状态寄存器示意图里主要掌握最低的两位（BUSY、WEL），其余自行查看。

  • JEDEC ID 0x9F：返回 厂商 ID + 设备 ID（下一节写代码时先用它验证芯片在不在）。

5.4 时序图：DO 高阻与模式 0/3 兼容

  • 手册的指令时序图和上一集讲的 SPI 时序基本一致，区别是：
    • DO（MISO）在「只写指令」阶段始终是高阻态（High Impedance）——因为从机没有数据要回传，主机读到的就是高阻（上拉后为高）；

坑与易错点

  1. 写之前必须先发 0x06 写使能：否则写入/擦除操作直接无效；每次写/擦都要重新发一次（WEL 写操作完成后会自动清 0）。
  2. 只能 1→0，不能 0→1：直接覆盖写不会得到你想要的值（0xAA 覆盖写 0x55 得 0x00），必须先擦除。
  3. 擦除后是 0xFF：读到 FF 说明该处是空白/已擦除，不是「数据就是 FF」这种巧合。
  4. 擦除最小单元是扇区（4KB）：不能只擦一个字节；改一个字节要「读扇区→改→擦扇区→写回」。
  5. 一次最多写一页（256B）且不能跨页：超页尾会回卷覆盖页首数据。
  6. 写入后要等 BUSY 清零：写/擦期间芯片「很忙」，不响应新的读写；忙时也不能读。
  7. 读取不需要写使能：读是只读操作、无页限制、不改变芯片状态（但要在 BUSY=0 时读）。
  8. W25Q64 容量是 8MB（64Mbit），别和 W25Q256 的 32MB 混淆；24 位地址只能寻址 16MB。
  9. 地址是 24 位＝3 个字节：0x02/0x20/0x03 后面都要跟 3 字节地址（高位在前）。
  10. VCC 只能 2.7～3.6V：不能直接接 5V。
  11. CS 低有效、HOLD 低有效：接线/软件控制别搞反。
  12. 软件 SPI 不用加延时：芯片 SCK 最高 80MHz，GPIO 翻转远达不到，加不加延时都不影响。
  13. 兼容模式 0 与模式 3：两者都是下降沿移出、上升沿移入，程序里用哪种都行（本课程用模式 0）。
  14. 写使能指令的 DO 是高阻：不要期待它返回数据。
