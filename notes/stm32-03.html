[2-1] 软件安装 — 学习笔记

  • 素材目录：vidsum_out/stm32_p3/（sheets/ 拼图、frames/ 单帧、transcript.txt）

一句话结论

这一集是“工具链安装实录”，按 Keil5 MDK（V5.24a）→ STM32F1 器件支持包 → 软件注册 → ST-LINK 驱动 → CH340 驱动 五步装完；装好后 Keil 新建工程能选到 STM32F103C8，ST-LINK 和 USB 转串口都能被电脑正常识别，下一集就可以开始新建工程写代码。

五步清单（一张表）

步骤 装什么 关键文件 / 版本 装完怎么验证
1 Keil5 MDK MDK524a.EXE = Setup MDK-ARM V5.24a uVision5 能启动
2 器件支持包 Keil.STM32F1xx_DFP.2.2.0.pack 新建工程 Device 里出现 STM32F1 → F103 → STM32F103C8
3 软件注册 keygen_new2032.zip 里的注册机 License Management 中 MDK-ARM 显示到 2032 年
4 ST-LINK 驱动 <Keil目录>\ARM\STLink\USBDriver\dpinst_amd64.exe（64 位）/ dpinst_x86.exe（32 位） 设备管理器里 ST-LINK 的感叹号消失
5 USB 转串口驱动 资料\工具软件\USB转串口CH340驱动\CH341SER.EXE 端口(COM 和 LPT) 出现 USB-SERIAL CH340 (COMx)

0. 下载与资料包

  • 软件下载链接在视频简介里：江协科技资料下载页 https://jiangxiekeji.com/download.html。
  • 下载的资料包（“资料”文件夹）里大致是：参考文档 / 工具软件 / 固件库 / 课件PPT / 模块资料 / Keil5 MDK.zip。
  • Keil5 MDK.zip 是加密压缩包：
    • 解压密码是 32（UP 主提示：有密码的压缩包就在旁边找一下密码文档，本集画面里未显示该文件；视频里口述并输入的是 32）。
    • 右键 → “解压到 Keil5 MDK”，解压后得到 MDK524a.EXE（安装器）、支持包\（7 个 pack）、keygen_new2032.zip（注册机）。

1. 安装 Keil5 MDK（MDK-ARM V5.24a）

  1. 双击 MDK524a.EXE，启动 Setup MDK-ARM V5.24a（发布版 7/2017）。
  2. 欢迎页 → Next；勾选 “I agree to all the terms…” → Next。
  3. 选择安装目录（全流程最关键的一步）：
    • 默认装 C 盘（如 C:\Keil_v5）；C 盘空间够就直接 Next，也可以点 Browse 换盘。
    • 如果之前装过 Keil C51：可以直接选 C51 的安装目录，让 C51 和 MDK 共存；以后在 Device 下拉列表里切到 Legacy Device 就能看到 51 型号。
    • 如果以前没装过 Keil：一定要新建一个目录（最好建在根目录下，视频示例 D:\Keil5），不要直接往已有目录里装。
    • 路径不要有中文和特殊字符（国外软件对中文路径支持差，容易出各种问题）。
  4. 选好目录后，下面的 Pack 路径会自动跟随成 <Keil目录>\ARM\PACK，直接 Next。
  5. 个人信息页（姓名 / 公司 / 邮箱）随便填 → Next → 开始安装，需要等几分钟。
  6. 安装过程中会弹窗询问是否安装 ULINK 驱动（ULINK 是 Keil 自家的调试器）→ 点“是”。
  7. 完成页取消勾选“显示发布说明文档”→ Finish。
  8. 安装完会自动弹出 Pack Installer 窗口，先关掉，第 2 步再讲。

2. 安装器件支持包（DFP）

为什么需要：Keil5 起把“器件支持包（Device Family Pack, DFP）”独立出来了（Keil4 及更早不用）。ARM 芯片型号太多、升级换代快，软件不可能内置全部型号，全部内置也太占空间；所以“开发哪种芯片就装哪种支持包”。不装支持包，新建工程时 Device 列表里只有 ARM 一项，找不到 STM32 型号。

  • 验证“没装”的现象：打开 Keil → Project → New uVision Project → 随便起个工程名 → Target 窗口的 Device 列表只有 ARM，没有 STM32。
  • 视频演示机之前装过 C51：此时 Device 下拉可切到 Legacy Device 查看 51 型号；只装 MDK 的电脑这个下拉列表无法切换。

方式 A：离线安装（课程使用，推荐）

  1. 打开 Keil5 MDK\支持包\，资料包预置了 7 个常见系列：F0 2.0.0、F1 2.2.0、F4 1.0.8、L0 1.6.0、L1 1.2.0、L4 1.4.0、W1 1.0.0。
  2. 本课程用 F1 系列 → 双击 Keil.STM32F1xx_DFP.2.2.0.pack。
  3. 目标路径会自动指向 Keil 安装目录下的 PACK，直接 Next，等待一小会 → Finish。
  4. 重新打开 Keil 新建工程：Device 里出现 STM32F1 Series，展开后是 F103 → STM32F103C8，说明能正常建工程了。

方式 B：在线安装（拓展，按需用）

  1. 打开 Keil，点工具栏上的绿色 Pack Installer 按钮（需要联网）。
  2. 它会自动从 Keil 官网获取最新支持包列表（网速慢，要等；如果没有自动获取，点一下更新按钮）。
  3. 加载完能看到很多公司，包含 Keil 支持的全部 ARM 芯片。其中也能看到国产兼容芯片：GigaDevice GD32F103C8、MindMotion MM32F103C8T，UP 主介绍它们基本和 STM32F103C8T6 兼容（当时 STM32 涨价，国产替代也发展起来了）。
  4. 展开 STMicroelectronics → 选需要的系列（视频用 STM32F2 演示）→ 在右侧找后缀为 DFP 的文件 → 点 Install，Keil 会自动从官网下载并安装。
  5. 关闭后 Keil 提示“支持包目录已更改，是否重新加载” → 选“是”，再新建工程就能看到刚装的系列。
  6. 也可以自己用浏览器到 Keil 官网下载 pack，下完按离线方式安装，效果一样。

3. 软件注册

  • Keil 是付费软件，不注册功能受限。UP 主大意：个人用户学习用盗版问题也不大，公司使用就要考虑版权问题（合规提醒：商业项目请购买正版 License）。
  • 操作步骤：
    1. 关闭 Keil；在 Keil uVision5 图标上 右键 → 以管理员身份运行（这一步必须，否则后面 Add LIC 会提示“权限不够”）。
    2. 打开后点 File → License Management，复制右上角的 CID（Computer ID）。
    3. 打开 Keil5 MDK\keygen_new2032.zip 解压得到注册机；如果杀毒软件把文件删了，需要先关杀毒软件再重新解压。
    4. 双击打开注册机，把刚复制的 CID 粘贴进去；Target 选 ARM（注册 MDK 用；要注册 C51 才选 C51）。
    5. 点 Generate 生成注册码，选中并复制。
    6. 回到 License Management，把注册码粘贴到 New License ID Code，点 Add LIC。
    7. 看到 *** LIC Added Successfully ***，且列表里 MDK-ARM Plus 的使用期限显示到 2032 年（演示机里 PK51 到 2031 年），就代表注册成功。
    8. 如果点 Add LIC 后弹出报错窗口，基本就是启动时没有以管理员身份运行；注册完成后，以后双击打开即可，不需要再右键管理员。

4. 安装 ST-LINK 驱动

  1. 把 ST-LINK 插到电脑 USB 口。
  2. 此电脑 → 右键 → 属性 → 设备管理器；在“其他设备”里能看到 ST-LINK 且图标带黄色感叹号 → 说明驱动没装。
  3. 如果设备管理器里 ST-LINK 没有感叹号 → 已装过驱动，跳过这一步。
  4. 驱动就在 Keil 安装目录里：<Keil安装目录>\ARM\STLink\USBDriver\
    • dpinst_amd64.exe：64 位系统用
    • dpinst_x86.exe：32 位系统用
  5. 双击对应位数的程序 → 下一步 → 完成；设备管理器会自动刷新，ST-LINK 的感叹号消失即成功。
  6. Keil 安装目录的 ARM 文件夹下还有 Segger 文件夹，里面是 J-Link 驱动：J-Link 也是常用调试器，用 J-Link 的话可以顺手装，本课程用 ST-LINK。

5. 安装 USB 转串口驱动

  • 本课程串口模块用 CH340 芯片（和 51 开发板上的芯片一样）；玩过 51 的话大概率已经装过。
  • 把 USB 转串口模块插到电脑上，设备管理器“其他设备”里会出现 USB Serial 并带感叹号 → 需要装驱动；能正常识别就不用装。
  • 驱动位置：资料包 工具软件\USB转串口CH340驱动\CH341SER.EXE（WCH 的自解压安装器，解压到 C:\WCH.CN\CH341SER）。
  • 双击 CH341SER.EXE → 先弹出 WinRAR 自解压窗口（Destination folder: C:\WCH.CN\CH341SER），点 Install → 继续弹出“驱动安装(X64)”（INF 为 CH341SER.INF），点“安装” → 出现“驱动安装成功”；
  • 设备管理器 → 端口(COM 和 LPT) 下出现 USB-SERIAL CH340 (COM3) 且没有感叹号，即安装完成。

6. 装完自检与下一步

  • 五步装完，本集结束；从下一集 [2-2] 新建工程 开始正式写代码。
  • 自检清单：
    • Keil uVision5 能正常打开，License Management 里 MDK-ARM 不是 Evaluation 版。
    • 新建工程，Device 能选到 STM32F103C8。
    • 插 ST-LINK，设备管理器里没有感叹号。
    • 插 USB 转串口，端口里出现 CH340 的 COM 号。

7. 坑与易错点

  1. 解压密码：Keil5 MDK.zip 需要密码 32；UP 主提示密码文档就在压缩包旁边，别去第三方网站乱下。
  2. 路径中文/特殊字符：Keil 安装目录、工程目录都尽量用纯英文；中文路径容易引发奇怪问题。
  3. C51 共存：装 MDK 时选 C51 的安装目录可共存；之后在 Device 下拉选 Legacy Device 才能看到 51 型号。
  4. 不装 DFP 就看不到芯片：新建工程 Device 只有 ARM 时，先装 Keil.STM32F1xx_DFP。
  5. 注册必须以管理员身份运行：否则 Add LIC 提示权限不够；注册成功一次之后就不用了。
  6. 注册机被杀毒软件删掉：解压前先关杀毒或加白名单，否则解压出来找不到文件。
  7. Pack Installer 需要联网且慢：在线安装只是拓展用法；课程主线用离线 pack，速度快且不受网络影响。
  8. ST-LINK 驱动别装错位数：64 位系统用 dpinst_amd64.exe，32 位系统用 dpinst_x86.exe。
  9. CH340 要看 COM 号：设备管理器“端口”里出现 COM 号才说明真正可用，只有“驱动安装成功”弹窗还不够。
