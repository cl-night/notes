[2-1] 软件安装 — 学习笔记

  • 素材目录：vidsum_out/stm32_p3/（sheets/、frames/、transcript.txt）

一句话结论

按 Keil5 MDK（V5.24a）→ 器件支持包 → 注册 → ST-LINK 驱动 → CH340 驱动 五步装完；装好后 Keil 能选 STM32F103C8，ST-LINK 与串口都被识别，下一集即可写代码。

本集定位

  • 只装工具链，不写代码。
  • 是后续所有实验的前提：Keil、器件包、驱动齐了才能建工程。

五步清单（一张表）

步骤 装什么 关键文件 / 版本 装完怎么验证
1 Keil5 MDK MDK524a.EXE = Setup MDK-ARM V5.24a uVision5 能启动
2 器件支持包 Keil.STM32F1xx_DFP.2.2.0.pack 新建工程 Device 里出现 STM32F1 → F103 → STM32F103C8
3 软件注册 keygen_new2032.zip 里的注册机 License Management 中 MDK-ARM 显示到 2032 年
4 ST-LINK 驱动 <Keil目录>\ARM\STLink\USBDriver\dpinst_amd64.exe（64 位）/ dpinst_x86.exe（32 位） 设备管理器里 ST-LINK 的感叹号消失
5 USB 转串口驱动 资料\工具软件\USB转串口CH340驱动\CH341SER.EXE 端口(COM 和 LPT) 出现 USB-SERIAL CH340 (COMx)

0. 下载与资料包

  • 下载链接在视频简介：江协科技资料下载页 https://jiangxiekeji.com/download.html。
  • 资料包内容：参考文档 / 工具软件 / 固件库 / 课件PPT / 模块资料 / Keil5 MDK.zip。
  • Keil5 MDK.zip 是加密包，解压密码 32；密码文档就在压缩包旁边，别去第三方网站乱下。
  • 右键 → “解压到 Keil5 MDK”，得到 MDK524a.EXE（安装器）、支持包\（7 个 pack）、keygen_new2032.zip（注册机）。

1. 安装 Keil5 MDK

  1. 双击 MDK524a.EXE 启动 Setup MDK-ARM V5.24a（发布版 7/2017）；欢迎页勾选协议 → Next。
  2. 选安装目录（全流程最关键）：
    • 默认装 C 盘（如 C:\Keil_v5），空间够就 Next，也可 Browse 换盘。
    • 装过 Keil C51：直接选 C51 目录即可共存，之后 Device 下拉切到 Legacy Device 才看得到 51 型号。
    • 没装过 Keil：一定要新建目录（最好在根目录，视频示例 D:\Keil5），不要往已有目录里装。
    • 路径不要有中文和特殊字符。
  3. Pack 路径自动跟随为 <Keil目录>\ARM\PACK，直接 Next。
  4. 个人信息页随便填 → Next → 安装，等几分钟。
  5. 弹窗问是否装 ULINK 驱动（Keil 自家调试器）→ 点“是”。
  6. 完成页取消“显示发布说明文档”→ Finish；随后弹出的 Pack Installer 先关掉。

2. 安装器件支持包（DFP）

  • Keil5 起把器件支持包（Device Family Pack, DFP）独立出来（Keil4 及更早不用）：芯片型号太多、升级换代快，全内置太占空间，开发哪种芯片就装哪种包。
  • 不装支持包：新建工程 Device 列表只有 ARM，找不到 STM32；用 Project → New uVision Project 即可验证。
  • 演示机装过 C51，Device 下拉可切到 Legacy Device；只装 MDK 的电脑切不了。

方式 A：离线安装（课程使用，推荐）

  1. Keil5 MDK\支持包\ 预置 7 个常见系列：F0 2.0.0、F1 2.2.0、F4 1.0.8、L0 1.6.0、L1 1.2.0、L4 1.4.0、W1 1.0.0。
  2. 本课程用 F1 → 双击 Keil.STM32F1xx_DFP.2.2.0.pack，路径自动指向 PACK → Next → Finish。
  3. 重开 Keil 新建工程：Device 出现 STM32F1 Series → F103 → STM32F103C8，说明能建工程。

方式 B：在线安装（拓展）

  1. 点工具栏绿色 Pack Installer（需要联网），它会从 Keil 官网取最新支持包列表，网速慢要等，没自动获取就点一下更新按钮。
  2. 列表含 Keil 支持的全部 ARM 芯片，也有国产兼容芯片：GigaDevice GD32F103C8、MindMotion MM32F103C8T，基本与 STM32F103C8T6 兼容。
  3. STMicroelectronics → 选系列（视频用 STM32F2 演示）→ 右侧找后缀 DFP 的文件 → Install。
  4. 关闭后 Keil 提示“支持包目录已更改，是否重新加载” → 选“是”，再新建工程就能看到刚装的系列；也可官网下 pack 按离线方式装。

3. 软件注册

  • Keil 是付费软件，不注册功能受限；公司使用要考虑版权，商业项目请购买正版 License。
  1. 关闭 Keil，右键 uVision5 图标 → 以管理员身份运行（否则 Add LIC 提示“权限不够”）。
  2. File → License Management，复制右上角 CID。
  3. 解压 Keil5 MDK\keygen_new2032.zip 得注册机；杀毒软件删了文件就先关杀毒再解压。
  4. 粘贴 CID，Target 选 ARM（注册 C51 才选 C51）→ Generate → 复制注册码。
  5. 回 License Management，粘到 New License ID Code → Add LIC。
  6. 出现 *** LIC Added Successfully ***，且 MDK-ARM Plus 期限到 2032 年（演示机 PK51 到 2031 年）即成功；之后双击打开即可，不用再管理员运行。

4. 驱动安装（ST-LINK / CH340）

  • ST-LINK：插入 USB → 此电脑 → 右键 → 属性 → 设备管理器；“其他设备”里带黄色感叹号说明没装驱动；没有感叹号就跳过。
  • 驱动在 <Keil安装目录>\ARM\STLink\USBDriver\：dpinst_amd64.exe 给 64 位、dpinst_x86.exe 给 32 位。
  • 双击对应程序 → 下一步 → 完成，感叹号消失即成功。
  • 同目录下的 Segger 文件夹是 J-Link 驱动，用 J-Link 才装，本课程用 ST-LINK。
  • CH340：串口模块用 CH340（和 51 开发板一样），玩过 51 大概率已装；插入后“其他设备”出现 USB Serial 带感叹号才要装。
  • 驱动：工具软件\USB转串口CH340驱动\CH341SER.EXE（WCH 自解压安装器，解到 C:\WCH.CN\CH341SER）。
  • 双击 CH341SER.EXE → 自解压窗口点 Install → “驱动安装(X64)”（INF 为 CH341SER.INF）点“安装” → 提示“驱动安装成功”。
  • 设备管理器 → 端口(COM 和 LPT) 出现 USB-SERIAL CH340 (COM3) 且无感叹号才算完成。

5. 自检与下一步

  • 五步装完，下一集 [2-2] 新建工程 开始写代码。
  • 自检：uVision5 能开且 MDK-ARM 不是 Evaluation 版；Device 能选 STM32F103C8；插 ST-LINK 无感叹号；插 USB 转串口出现 CH340 的 COM 号。

坑与易错点

  1. 解压密码：Keil5 MDK.zip 密码 32；密码文档就在压缩包旁边，别去第三方网站乱下。
  2. 路径中文/特殊字符：Keil 安装目录、工程目录都尽量纯英文，中文路径容易出怪问题。
  3. C51 共存：装 MDK 时选 C51 目录可共存；之后 Device 下拉选 Legacy Device 才看得到 51 型号。
  4. 不装 DFP 就看不到芯片：Device 只有 ARM 时，先装 Keil.STM32F1xx_DFP。
  5. 注册必须以管理员身份运行，否则 Add LIC 提示权限不够；成功一次之后就不用了。
  6. 注册机被杀毒软件删掉：解压前先关杀毒或加白名单。
  7. Pack Installer 需要联网且慢：在线只是拓展，主线用离线 pack，快且不受网络影响。
  8. ST-LINK 驱动别装错位数：64 位用 dpinst_amd64.exe，32 位用 dpinst_x86.exe。
  9. CH340 要看 COM 号：端口里出现 COM 号才真正可用，只有“驱动安装成功”弹窗不够。
