[6-5] TIM输入捕获 — 学习笔记

一句话结论

输入捕获即「引脚出现指定跳变时，把当前 CNT 锁存进 CCR」。配主从触发（TI1FP1 + 从模式 Reset）可硬件自动清零 CNT，读 CCR1 就得周期；PWMI 用两个通道分捕上升/下降沿，一次得频率与占空比。

本集定位

  • 定时器大节第三部分（输入捕获）的理论课：00:00 就是 PPT 标题页，00:09–03:45 演示两个写好的工程，03:45 起回 PPT，之后到 38:54 全是原理、结构图、手册寄存器（约 35 分钟）。
  • 片头两个工程就是 P18 要写的：6-6 输入捕获模式测频率、6-7 PWMI模式测频率占空比；代码只一闪而过，只看到 IC_Init()、IC_GetFreq() 的调用。
  • 本集不写 TIM_ICInit 等配置，代码在 P18 [6-6]；片头 IC.c 是怎么写的本集没讲，片尾原话是「下一小节学习输入捕获的代码部分」。
  • 程序二的 main.c 本集没拍到，IC_GetDuty() 是按功能推断的。
  • 编号对照：视频是 [6-5]，工程目录却叫 6-6 / 6-7（按代码小节编号），两套编号不是一回事。

1. 片头两个程序的现象

1.1 程序一：输入捕获模式测频率（00:09–01:35）

2. 输入捕获是什么

2.1 核心定义

  • IC = Input Capture，输入捕获。
  • 通道输入引脚出现指定电平跳变（上升沿或下降沿，可配置）时，当前 CNT 的值被锁存到 CCR 中。
  • 「锁存到 CCR」就是把当前 CNT 读出来写进 CCR。
  • 用途：测 PWM 的频率、占空比、脉冲间隔、电平持续时间（脉冲间隔≈频率、电平持续时间≈占空比）。
  • 资源：高级定时器和通用定时器都有 4 个输入捕获通道，基本定时器没有；两者电路没有区别。
  • 配套功能：PWMI 模式可同时测频率和占空比；主从触发模式可实现硬件全自动测量——不进中断，直接读 CCR。

图 5：PPT「输入捕获简介」——跳变时 CNT 锁存到 CCR；可测频率、占空比、脉冲间隔、电平持续时间；每个高级/通用定时器 4 个通道

2.2 与输出比较的关系：共用 CCR 和引脚

  • 定时器结构图左边是输入捕获电路，右边是输出比较电路。
  • 两者共用 4 个 CCR 寄存器，CH1～CH4 四个通道引脚也共用。
  • 所以同一个定时器上输入捕获和输出比较只能二选一，不能同时用。

2.3 与输出比较、外部中断的对比

对比项 输出比较 输入捕获 外部中断
引脚方向 输出端 输入端 输入
触发来源 CNT 与 CCR 的大小关系 输入引脚的电平跳变 输入引脚的电平跳变
触发后做什么 根据比较结果输出高低电平 把当前 CNT 锁存到 CCR（并产生捕获事件） 向 CPU 请求中断
  • 执行流程：引脚出现跳变 → 输入滤波和边沿检测电路检测到 → 捕获电路动作 → CNT 锁存进 CCR → 同时产生捕获事件（状态寄存器置标志位，也可产生中断）。
  • 作用和外部中断类似，都是检测跳变再执行动作；区别是外部中断向 CPU 请求中断，这里是把 CNT 锁存进 CCR。

2.4 一句话记住

  • 输出比较：引脚是输出端，按 CNT 与 CCR 的大小关系执行输出动作。
  • 输入捕获：引脚是输入端，收到输入信号后执行「CNT 锁存到 CCR」。

3. 频率测量基础

测 PWM 频率之前先补一点通用知识（08:35～18:35，本集重点之一）：

3.1 前提：STM32 只能测数字信号

  • 图示是频率逐渐降低的方波，都是只有高低电平的数字信号。
  • STM32 只能测数字信号：正弦波要先搭预处理电路（最简单用运放做比较器）；电压很高还要隔离（隔离放大器、电压互感器）。
  • 最终输入给 STM32 的必须是高电平 3.3V、低电平 0V 的高低电平信号。

3.2 测频法：闸门时间内数上升沿

  • 闸门时间 T 内对上升沿计次得 N，则 fx = N / T。
  • 数下降沿也行，只是极性不同；统一以上升沿为一个周期的开始。
  • 原理：1s 内来了多少个周期，频率就是多少 Hz。
  • 闸门时间不必为 1s：T=1s 时 N 直接就是频率；T=2s 要除以 2；T=0.5s 要乘以 2。

3.3 测周法：两个上升沿之间数标准频率

  • 两个上升沿内以标准频率 fc 计次得 N，则 fx = fc / N。
  • 原理：周期的倒数就是频率；没有精度无穷大的秒表，测时间也是定时器计次。
  • 用已知标准频率 fc 的时钟驱动计数器，从一个上升沿从 0 计到下一个上升沿；一个数的时间 1/fc，N 个数就是 N/fc，即周期，取倒数得 fx = fc / N。

图 6：PPT「频率测量」——「闸门时间 T / 中界频率 fm / 标准频率 fc」与两次「计次 N」；三公式 fx = N/T、fx = fc/N、fm = √(fc/T)

3.4 两法对比

对比项 测频法 fx = N/T 测周法 fx = fc/N
适合的信号 高频（闸门内上升沿多，N 大误差小） 低频（周期长，计次数多）
不适合 频率太低：1s 内只有寥寥几个沿甚至 0 个沿，误差极大 频率太高：fc=1MHz、待测 500kHz 时一个周期只能计一两个数，甚至一个数也计不到
结果更新速度 慢：闸门时间内测多个周期，1s 才出一次结果 快：只测一个周期就出一次结果（出结果速度取决于待测信号频率，一般几百几千 Hz 时更新更快）
结果平滑度 平滑：测的是多个周期，自带均值滤波，是这段时间的平均频率 波动大：只测一个周期，受噪声影响

3.5 ±1 计数误差：两法都固有，N 越大影响越小

  • 测频法：闸门到点时可能有一个周期刚出现一半，只能舍弃或当成整个周期，因为计次只有整数、不可能计 0.5 个数。
  • 测周法：fc 计次到最后可能数到一半就结束，这半个数也只能舍弃或按一个算。
  • ±1 误差是两法固有的；N 越大，±1 对 N 的相对影响越小。
  • 量级感受：5000 块的电脑卖 5001 没人计较，2 块的水卖 3 块就觉得黑心。

3.6 中界频率：两法误差相等的分界点

  • 中界频率是测频法与测周法误差相等的频率点，此时两法计次 N 相同、误差相同。
  • 推导：令测频法的 N 与测周法的 N 相等，把 f 解出来，得 fm = √(fc / T)。
  • 待测频率低于中界频率时测周法误差更小，高于时测频法误差更小。

3.7 STM32 上怎么实现这两种方法

  • 测频法：用之前学过的外设就能实现——「对射式红外传感器计次」「定时器外部时钟」都是每来一个上升沿计次 +1，再用一个定时器定 1s 中断，中断里取计次值并清零，读到的计次值直接就是频率；这段视频不演示。
  • 测周法：本集输入捕获用的就是测周法——测两个上升沿之间的时间，再取倒数。

4. 输入捕获总结构图（通用定时器框图）

  1. 最左边是四个通道引脚 TIMx_CH1～CH4，复用位置参考引脚定义表。
  2. 引脚先进三输入异或门：输入接通道 1、2、3，任何一个翻转输出就翻转一次，输出经数据选择器到通道 1。
  3. 数据选择器选上面一个，通道 1 的输入就是 3 个引脚的异或值；选下面一个，异或门没用、4 个通道各用各的引脚。这个异或门是为三相无刷电机服务的（接 3 个霍尔传感器、做换相接口），本课不涉及。
  4. 输入滤波器和边沿检测器：滤波器避免高频毛刺误触发；边沿检测器选上升沿/下降沿，出现指定电平时触发后续电路。
  5. 两套滤波和边沿检测：第一套得到 TI1FP1，第二套得到 TI1FP2；通道 2 同理得 TI2FP1、TI2FP2。TI2FP1 给上面（通道 1 后续）、TI2FP2 给下面（通道 2 后续），可各走各的，也可交叉。
  6. 交叉的目的（20:56）：① 灵活切换后续捕获电路的输入；② 把一个引脚同时映射到两个捕获单元——这就是 PWMI 模式的经典结构（一个通道捕上升沿、另一个捕下降沿）。通道 3、4 结构相同。
  7. TRC 也能作为捕获输入（来自从模式控制器），为无刷电机设计，暂时不用。
  8. 预分频器：每个通道一个，分频之后的信号才能触发捕获电路。
  9. 捕获动作：每来一个触发信号，CNT 的值向 CCR 转运一次，同时产生捕获事件（可开中断处理）。

5.2 滤波器怎么工作：连续 N 个相同才翻转

  • 手册：这几位定义 TI1 输入的采样频率及数字滤波长度；数字滤波器由事件计数器组成，记到 N 个事件后才会产生一次输出跳变。IC2F[3:0] 与 CC2S 是同一组位域。
  • 通俗理解：连续 N 个采样值都为高才输出高，都为低才输出低；高频抖动使连续 N 个值不全都一样，输出就不变。
  • 采样频率越低、N 越大，滤波效果越好；噪声大就把这个参数设大一些。

5.3 手册里的 ICF 表与 CC2S

  • ICF[3:0]（输入捕获滤波器）：0000 无滤波器、以 fDTS 采样；0001 采样频率 fCK_INT、N=2；0010 fCK_INT、N=4；0011 fCK_INT、N=8；0100 fDTS/2、N=6；0101 fDTS/2、N=8；0110 fDTS/4、N=6；0111 fDTS/4、N=8；1000 fDTS/8、N=6；1001 fDTS/8、N=8；1010 fDTS/16、N=5；1011 fDTS/16、N=6；1100 fDTS/16、N=8；1101 fDTS/32、N=5；1110 fDTS/32、N=6；1111 fDTS/32、N=8。
  • CC2S[1:0]（捕获/比较 2 选择）：00 输出；01 输入、IC2 映射在 TI2 上；10 输入、IC2 映射在 TI1 上；11 输入、IC2 映射在 TRC 上（仅内部触发器输入被选中时，由 SMCR 的 TS 位选择）。
  • IC1PSC[1:0]：输入/捕获 1 的预分频器系数。

6. 主从触发模式：硬件自动化的关键

6.1 「主从触发模式」是三个功能的简称

  • 这个名字是作者自起的，手册里并没有，它就是主模式 + 从模式 + 触发源选择的简称：
功能 作用
主模式 把定时器内部的信号映射到 TRGO 引脚，用于触发别的外设（Reset / Enable / Update / OC1 / OC1REF / OC2REF / OC3REF / OC4REF）
触发源选择 选择从模式的触发信号源，得到 TRGI（ITR0～ITR3 / TI1F_ED / TI1FP1 / TI2FP2 / ETRF）
从模式 接收其他外设或自身外设的信号，控制自身定时器的运行（被 TRGI 触发后执行操作：Closed / Encoder1～3 / Reset / Gated / Trigger / External1）
  • 串起来：主模式把内部信号映射成 TRGO 去触发别的外设；从模式被 TRGI 控制——触发源选择挑一个信号得到 TRGI，TRGI 触发从模式，从模式按列表自动执行。
  • 库函数里对应三个函数，给参数就行。

6.2 我们的任务：让 TI1FP1 自动清零 CNT

  • 触发源选 TI1FP1，从模式选 Reset：TI1FP1 的信号自动触发从模式、自动清零 CNT，实现硬件全自动测量。
  • 从模式就是完成自动化操作的利器。
  • 主从触发还能做定时器级联：一个定时器主模式输出更新信号到 TRGO，另一个从模式选外部时钟模式 1。
  • 其他高级功能也能用主从触发实现，信号含义不用特别记，知道有这功能就行。

7. 输入捕获基本结构（单通道测频率）

本集第一个重点图，对应程序一 6-6 的逻辑：

  • 只用了一个通道，所以只能测频率。
  • 右上角时基单元：启动后 CNT 在预分频之后的时钟驱动下不断自增，这是测周法计时的东西。
  • 预分频之后驱动 CNT 的时钟频率就是标准频率 fc，所以 fc = 72M / (PSC + 1)，也就是 fc = 72MHz/(PSC+1)。
  • 下面输入捕获通道 1：GPIO 输入方波 → 滤波和边沿检测 → 选 TI1FP1 上升沿 → 直连、不分频 → 上升沿到来时 CNT 转运到 CCR1。
  • 同时触发源选 TI1FP1、从模式选 Reset，这一路顺带把 CNT 清零。
  • 顺序：先转运 CNT 到 CCR，再清零，绝不会先清零再捕获，否则捕获值永远是 0。
  • 工作过程：CCR1 = CNT、CNT = 0 → CNT 从 0 自增 → 下一个上升沿再次 CCR1 = CNT、清零，所以 CCR1 始终是最新一个周期的计数值，即测周法的 N。
  • 公式：fx = fc / N，N = CCR1；读频率只需读 CCR1 再算 fc/CCR1，平时全自动、不占软件资源。

图 12：PPT「输入捕获基本结构」——右上时基单元（PSC → CNT、ARR）；通道 1：GPIO → 滤波器 → 边沿检测 → TI1FP1 → 分频器 → CCR1；TI1FP1 同时经「触发源选择 → 从模式 Reset」清零 CNT；波形标 CCR1 = CNT / CNT = 0 与 CNT ++

7.1 两个必须注意的点

  • ① ARR 一般设为最大 65535：CNT 最多计 65535 个数，频率太低一个周期就溢出。
  • ② 从模式触发源只有 TI1FP1 和 TI2FP2，没有 TI3/TI4：想硬件自动清零只能用通道 1、2；通道 3、4 只能开捕获中断手动清零，会频繁中断、耗软件资源。

8. PWMI 基本结构（同时测频率和占空比）

PWMI 用两个通道同时捕获一个引脚，可同时测周期和占空比（对应程序二 6-7）：

  • TI1FP1 配上升沿：触发捕获和清零 CNT，CCR1 = 一整个周期的计数值。
  • TI1FP2 配下降沿，通过交叉通道触发通道 2 的捕获。
  • 波形：上升沿 CCR1 = CNT、CNT = 0 → CNT 一直 CNT ++ → 下降沿触发 CCR2 = CNT（高电平期间的计数值，不清零）→ 下一次上升沿再捕周期并清零。
  • 所以 CCR1 是一整个周期、CCR2 是高电平时间，占空比 = CCR2 / CCR1。
  • 两种接法可切换：两个通道同时捕第一个引脚（TI1FP1/TI1FP2），或同时捕第二个引脚（TI2FP1/TI2FP2）。
  • 这就是「一个引脚同时映射到两个捕获单元」这个交叉设计的主要用途。

图 13：PPT「PWMI 基本结构」——上半部分同输入捕获基本结构，多一个通道：TI1FP2 经分频器 → CCR2；波形上升沿标 CCR1 = CNT / CNT = 0、下降沿标 CCR2 = CNT（不清零）

图 14：PWMI 结构图上的红笔标注——上升沿 CCR1 = CNT、CNT = 0，下降沿 CCR2 = CNT，TI1FP1（上升沿）与 TI1FP2（下降沿、交叉进通道2）两路走向

坑与易错点

  1. 输入捕获和输出比较共用 4 个 CCR 与 CH1～CH4 引脚：同一个定时器上只能二选一；要同时输出 PWM 又测频率，得换定时器或换引脚。
  2. 「锁存到 CCR」≠「清零 CNT」：捕获只把 CNT 复制进 CCR，CNT 不会自己清零；要继续测下一周期，必须用从模式 Reset 清零。
  3. 先捕获、后清零：顺序绝不能反，先清零再捕获 CCR 里永远是 0；实现上是转运与清零同时或紧接发生。
  4. 测周法公式是 fx = fc/N，N 是 CCR1 里的计数值：fc = 72M/(PSC+1) 是预分频之后驱动 CNT 的时钟，不是 72MHz 本身。
  5. 测频法与测周法别用反：高频用测频法（闸门内沿多），低频用测周法（周期长计次多），分界是中界频率 fm = √(fc/T)。
  6. ARR 要设成最大 65535：CNT 只能计 65535 个数，频率太低时一个周期的计数值会溢出。
  7. 从模式触发源只有 TI1FP1 / TI2FP2：想硬件自动清零只能用通道 1、2；CH3/CH4 只能开捕获中断手动清零、耗软件资源。
  8. 滤波器 ICF 是「连续 N 个相同才翻转」：采样越慢、N 越大，滤波越强但响应越慢；信号变化快时可能把有效边沿也滤掉。
  9. CC1S[1:0] 决定数据选择器：00 是输出模式，01 映射 TI1、10 映射 TI2、11 映射 TRC；输入捕获必须配成 01/10/11。
  10. 交叉连接的两大目的别只记一个：① 灵活切换输入；② 一个引脚同时给两个捕获单元（PWMI 的基础）。
  11. 占空比公式是 CCR2/CCR1：CCR1 是一个周期的计数值、CCR2 是高电平时间的计数值，两者用同一套标准频率，比值才是占空比。
  12. PWMI 里只有上升沿那一路清 CNT：CCR2 捕获不清零，CNT 才能从上升沿一直数到下一个上升沿。
  13. 「主从触发模式」是作者自造的名字：手册里没这个词，对应主模式（MMS）+ 触发源选择（TS）+ 从模式（SMS）三组寄存器位。
  14. TS 位只能在 SMS=000 时修改：手册写了「这几位只能在未用到时被改变」，改触发源前先把从模式关掉。
  15. 本集没有 IC 代码：TIM_ICInit、TIM_PWMIConfig、TIM_SelectInputTrigger、TIM_SelectSlaveMode 一个都没出现，全在 P18 [6-6]。
  16. 它只能测数字信号：正弦要先比较器整形、高压要隔离，最终输入必须是 0V/3.3V 高低电平，别指望直接接交流信号。
