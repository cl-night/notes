[6-3] TIM输出比较 — 学习笔记

一句话结论

输出比较就是拿 CNT 和每个通道的 CCR 比大小、按规则决定输出电平，所以天生适合出 PWM；实用模式只有 PWM模式1 + 向上计数。占空比 = CCR/(ARR+1)，分辨率 = 1/(ARR+1)。

1. 片头三个现象：这一节要解决什么

小节目的是三个程序：PWM 驱动 LED 呼吸灯、舵机、直流电机。动机开场就说了：PWM 波形是驱动电机的必要条件，所以做智能车、机器人这类带电机的项目，输出比较要好好学。

1.1 现象①：PWM 驱动 LED 呼吸灯（00:43–01:21）

  • 面包板上在 PA0 端口接了一个 LED。
  • 老师抛出的问题：GPIO 是数字输出，电平不是高就是低，按理 LED 只有完全亮和完全灭两种状态，怎么能连续调亮度？
  • 答案就是 PWM：让 LED 不断点亮、熄灭，频率足够快就看不到闪烁，只呈现中等亮度；再调点亮与熄灭的时间比例，就能得到不同亮度。

图 1：现象① LED 呼吸灯，PA0 上接的 LED 亮着（现成工程）

1.2 现象②：PWM 驱动舵机（01:21–02:03）

  • 拿一个舵机按一下按键，舵机输出轴的角度不断变换，OLED 上显示当前角度（画面是 Angle:060）。
  • 每按一下角度变量变一次，舵机随即转到指定角度并固定下来；这个角度可以任意设置，演示里只是用按键简单修改。

图 2：现象② 按键改角度，OLED 显示 Angle:060

1.3 现象③：PWM 驱动直流电机（02:03–02:59）

  • 电机转起来，OLED 显示当前速度值，一开始是 Speed:+20。
  • 一直按：+20 → +40 → +80 → +100（正向满速）；再按一下由 +100 变 -100，电机立刻反向满速；继续按是 -80、-60、-40、-20，然后回到 0，电机停止。
  • 结论是可以任意控制电机的方向和速度；三个现象共同指向一个问题：GPIO 只有高低两种状态，怎么做出连续变化的效果——这就是 PWM，也就是本集要讲的输出比较。

图 3：现象③ 直流电机反向满速，Speed:-100

2. 输出比较是什么

2.1 三个英文缩写：OC / IC / CC

  • OC = Output Compare，输出比较；IC = Input Capture，输入捕获（后面大节讲）。
  • CC = Capture/Compare，捕获/比较，一般表示输入捕获和输出比较的单元；CCR 就是 Capture/Compare Register，捕获/比较寄存器。
  • 专门讲缩写是因为库函数里经常出现，不然写个 OC 你不知道是啥意思。

图 4：输出比较简介 PPT——比较 CNT 与 CCR，输出定频定占空比的 PWM

2.2 核心功能：比较 CNT 与 CCR，输出 PWM

  • 官方描述：输出比较通过比较 CNT 与 CCR 寄存器值的关系，对输出电平进行置 1、置 0 或翻转的操作，用于输出一定频率和占空比的 PWM 波形。
  • CNT 就是时基单元里的计数器，CCR 就是捕获/比较寄存器；这个寄存器输入捕获和输出比较共用——用输入捕获时是捕获寄存器，用输出比较时是比较寄存器。
  • 工作机制：CNT 计数自增、CCR 是我们给定的值，CNT 大于、小于或等于 CCR 时输出对应地置 1、置 0，于是输出一个电平不断跳变的 PWM 波形。

2.3 4 个通道、一个 CNT、基本定时器没有

  • 每个高级定时器和通用定时器都有 4 个输出比较通道，可以同时输出 4 路 PWM。
  • 4 个通道各有自己的 CCR，但共用一个 CNT——CNT 属于时基单元，整个定时器只有一个。
  • 基本定时器（TIM6/TIM7）没有输出比较功能，从结构图就看得出，所以本小节的功能不能在基本定时器上用。
  • 高级定时器前 3 个通道还额外有死区生成和互补输出，用于驱动三相无刷电机，本课程不作为重点，主要学通用定时器的输出比较。

3. PWM 简介

3.1 PWM 是什么：数字信号 + 惯性系统

  • PWM = Pulse Width Modulation，脉冲宽度调制；它就是一个数字输出信号，由高低电平组成。
  • 用处：在具有惯性的系统中，通过对一系列脉冲的宽度进行调制，可以等效地获得所需要的模拟参量，常用于电机控速。
  • 为什么必须有惯性（08:23 起专门解释）：LED 熄灭时有余晖和人眼视觉暂留，不会立马熄灭；电机断电时转动不会立马停止。只有这样的惯性系统才能用 PWM。
  • 应用举例：让 LED 不断点亮熄灭，频率足够大就不闪烁、呈现中等亮度，调时间比例就得到不同亮度；电机同理，快速通断就能维持中等速度。
  • 老师总结：PWM 的秘诀就是「天下武功，唯快不破」——闪得足够快，就发现不了它是闪着亮还是正常亮。

3.2 三个参数：频率、占空比、分辨率

参数 定义（画面原文） 含义
频率 频率 = 1 / T_S T_S 是一个高低电平变换周期的时间，也就是一个完整周期；周期取倒数就是频率
占空比 占空比 = T_ON / T_S T_ON 是高电平的时间，T_ON/T_S 就是高电平时间相对于整个周期时间的比例，一般用百分比表示
分辨率 分辨率 = 占空比变化步距 占空比变化的最小步距，比如只能 1%、2%、3% 跳变就是 1% 分辨率
  • 占空比的极端值：50% 是高低电平时间相等的方波；20% 是高电平占 20%、低电平占 80%；100% 就是一直高电平；0% 就是一直低电平。
  • 占空比决定等效出来的模拟电压：占空比越小，等效电压越趋近低电平；一般是线性的——高电平 5V、低电平 0V 时，50% 占空比等效 2.5V，20% 等效 1/5 处的 1V。
  • 频率：PWM 频率越快，等效出来的模拟信号越平稳，但性能开销也越大；一般 PWM 频率在几 K 到几十 KHz 就足够快。
  • 分辨率：要多高看项目需求，要求不高时 1% 的分辨率已经够用。

图 5：PWM 简介 PPT，频率、占空比、分辨率三个参数

3.3 用 PWM 就能在数字系统里「输出模拟量」

  • 使用 PWM 波形就可以在数字系统等效输出模拟量，从而实现 LED 控制亮度、电机控速等功能。
  • 这也回答了片头的问题：数字端口只有高低电平，靠「足够快的通断 + 惯性系统」就能表现出连续变化的亮度或速度。

4.1 信号通路：从比较结果到引脚

按图125（捕获/比较通道的输出部分（通道1））从左往右：

  1. 左边是 CNT 与 CCR1 比较的结果：CNT > CCR1 和 CNT = CCR1 两路信号（还有隐含的小于）送给输出模式控制器；
  2. 输出模式控制器由寄存器位 OC1M[2:0]（属于 TIMx_CCMR1）配置，它改变输出 OC1REF 的高低电平；REF 是 reference（参考信号）的缩写；
  3. OC1REF 有两个去向：往上可映射到主模式控制器的 TRGO（可触发别的定时器/DAC/ADC）；往下进入极性选择电路——寄存器位 CC1P（在 TIMx_CCER 里），写 0 直通、写 1 过非门取反；
  4. 然后是输出使能电路（CC1E，也在 TIMx_CCER），选择要不要输出；
  5. 最后是 OC1 引脚，也就是 CH1 通道的引脚，对应哪个 GPIO 查引脚定义表。
  • 图里上方那个 ETRF 输入是定时器的小功能，一般不用。
  • 下面还有三个同样的单元，分别输出到 CH2、CH3、CH4。

5. 输出比较的 8 种模式

5.1 模式总表

输出模式控制器什么时候给 REF 高、什么时候给低，由这 8 种模式决定，模式可通过寄存器配置。

模式 描述（画面原文） 怎么理解
冻结 CNT=CCR 时，REF 保持为原状态 等于CNT、CCR 根本没用：不管谁大谁小，REF 保持上一个状态
匹配时置有效电平 CNT=CCR 时，REF 置有效电平 相等那一刻把 REF 置有效（≈高）
匹配时置无效电平 CNT=CCR 时，REF 置无效电平 相等那一刻把 REF 置无效（≈低）
匹配时电平翻转 CNT=CCR 时，REF 电平翻转 每匹配一次翻转一次
强制为无效电平 CNT 与 CCR 无效，REF 强制为无效电平 不看 CNT/CCR，直接强制成无效（≈低）
强制为有效电平 CNT 与 CCR 无效，REF 强制为有效电平 不看 CNT/CCR，直接强制成有效（≈高）
PWM模式1 向上计数：CNT<CCR 时，REF 置有效电平，CNT≥CCR 时，REF 置无效电平
向下计数：CNT>CCR 时，REF 置无效电平，CNT≤CCR 时，REF 置有效电平		 最常用：向上计数时「小于 CCR 为高、大于等于 CCR 为低」
PWM模式2 向上计数：CNT<CCR 时，REF 置无效电平，CNT≥CCR 时，REF 置有效电平
向下计数：CNT>CCR 时，REF 置有效电平，CNT≤CCR 时，REF 置无效电平		 大小比较关系和 PWM1 一样，只是高低反过来 = PWM1 取反

图 7：8 种输出模式全表

5.2 逐个看：哪些有实际用途

  • ① 冻结：CNT=CCR 时维持原状态，CNT 和 CCR 根本没用到。用处是切到冻结后输出暂停、高低电平维持暂停那一刻的状态（比如正输出 PWM 想停一下）。
  • ②③④ 匹配时置有效/置无效/电平翻转：都是 CNT=CCR 时执行操作。
  • 前提：「有效电平」和「无效电平」是高级定时器的说法，这里可直接理解成置有效就是置高、置无效就是置低。
  • 匹配时电平翻转：每匹配一次翻转，每更新两次才是一个周期，所以高低电平时间始终相等、占空比恒为 50%，输出频率 = 更新频率 / 2；这是三个里唯一比较像波形输出的模式。
  • 匹配时置有效/置无效：不适合输出连续变化的波形，想定时输出一次性信号时可以考虑。
  • ⑤⑥ 强制无效/强制有效：和冻结差不多（不看 CNT/CCR、REF 被强制），可用于紧急急停或强制输出。
  • ⑦⑧ PWM模式1/PWM模式2：非常重要，能输出频率和占空比都可调的 PWM，也是主要使用的模式。
  • PWM模式1 向上计数：CNT<CCR 置有效、CNT≥CCR 置无效；向下计数：CNT>CCR 置无效、CNT≤CCR 置有效，一般只用向上计数。
  • PWM模式2：比较关系和 PWM模式1 一样，只是高低反过来，实际就是 PWM1 的取反。
  • 另外 REF 输出之后还有极性配置（CC1P）：输出模式里可设极性、最终输出前也可设极性，所以 PWM1 与 PWM2 可以互相等效，没必要两个都用。

5.3 结论：实际只用 PWM模式1 + 向上计数

  • 使用时只用 PWM模式1 并向上计数这一种模式就够了，后面第 6、7 章的分析都以它为例。

6. PWM 基本结构：本节重点图

6.1 结构组成

20:24 起给出「输出 PWM 的基本结构」，这是本节重点：

  • 左上角是时基单元和运行控制，再左边的时钟源选择图里省略了——都是 [6-1]/[6-2] 的内容，还要继续用。

  • 时基单元里是 PSC 预分频器、CNT 计数器、ARR 自动重装器；配置好时基单元，CNT 就开始不断自增。
  • 下面是输出比较单元，总共 4 路：最前面是 CCR 捕获/比较寄存器（CCR 自己设定，CNT 不断自增、两者不断比较），后面是输出模式控制器，以 PWM模式1 为例讲解执行逻辑（图里直接写了两行：CNT<CCR 时，REF 置有效电平、CNT≥CCR 时，REF 置无效电平）。
  • REF 再经过极性选择、输出使能，最终通向 GPIO 口。

图 8：PWM 基本结构，右上波形 CNT 0～99、ARR=99、CCR=30

6.2 波形图怎么读：CNT、ARR、CCR 三条线

  • 看右上角波形：蓝线是 CNT，黄线是 ARR。蓝线从 0 自增到 ARR（99）后清零继续，这是一个计数溢出更新周期。
  • 再画一条红线就是 CCR，比如设 CCR = 30。
  • 于是 CNT 从 0 往上加，只要 CNT < CCR 就置有效（绿线高）；CNT ≥ CCR 就变低；计数器清零后又重新 CNT < CCR 置高，如此循环。
  • 占空比受 CCR 调控：CCR 高一些占空比变大，低一些占空比变小。
  • 这里 REF 就是一个频率可调、占空比也可调的 PWM 波形，再经极性选择、输出使能通向 GPIO。

7. PWM 的三个参数怎么算

7.1 PWM 频率 = 计数器更新频率

  • 波形图上一个 PWM 周期始终对应计数器的一个溢出更新周期，所以 PWM 频率就等于计数器的更新频率。
  • 直接套 [6-1] 的公式：
PWM 频率      Freq = CK_PSC / (PSC + 1) / (ARR + 1)
PWM 占空比    Duty = CCR / (ARR + 1)
PWM 分辨率    Reso = 1 / (ARR + 1)

7.2 占空比 = CCR / (ARR + 1)：高电平其实只有 CCR 个数

  • CNT 从 0 一直加到 ARR，比如 ARR = 99，那 CNT 总共计了 100 个数（0～99）。
  • 高电平时间：CNT 从 0 加到 CCR，比如 CCR = 30，注意等于 30 的瞬间就已跳变低电平，所以 0 到 29 是高电平，总共 30 个数（不是 31 个）。
  • 所以占空比 = 30 / 100 = 30%，公式就是 占空比 = CCR / (ARR + 1)。
  • CCR 一般取 0 ～ ARR：CCR = ARR + 1 时占空比正好 100%，再大就恒为 100%、没有意义。

7.3 分辨率 = 1 / (ARR + 1)：越小越好

  • 分辨率就是占空比变化的步距：CCR 的变化范围取决于 ARR，ARR 越大 CCR 范围越大、分辨率越高（步距越小）。
  • 公式 分辨率 = 1 / (ARR + 1)。
  • 注意这里定义的「分辨率」是占空比最小的变化步距，所以越小越好；若把 CCR 的范围定义成分辨率，那就是越大越好。

8. 高级定时器的输出比较通道（仅作了解）

25:45 起回头看高级定时器的输出比较电路（图78：捕获/比较通道的输出部分（通道1至3）），老师说「这个电路大家仅作了解即可，不需要掌握」。

8.1 多出来的部分：死区发生器与互补输出

  • 对比第 4 章的图125，高级定时器多出死区发生器和两路互补输出：
    • 输出模式控制器出来的 OC1REF 先经死区发生器（DTG[7:0]，在 TIM1_BDTR 寄存器），得到 OC1_DT 和 OC1N_DT 两路；
    • 两路各自经极性选择（CC1P / CC1NP）和输出使能（CC1E / CC1NE），分别输出 OC1 和 OC1N 两个互补引脚；
    • 图里还有 MOE、OSSR、OSSI 等位（在 TIM1_BDTR 里），是刹车/输出使能相关的控制位，本集没展开。
  • 高级定时器第四个通道和通用定时器基本一样（没有死区/互补），因为三相无刷电机只需要三路互补。

8.2 为什么要死区：先看外电路（推挽）

  • 圈出来的电路要和外电路一起理解：外面通常接一个推挽电路，上面是正极，接一个大功率开关管（一般用 MOS 管，就是大功率电子开关），再来一个 MOS 管；下面也一样，有控制极，高电平导通、低电平断开。
  • 推挽的四种状态：上管通下管断 → 输出高电平；上管断下管通 → 输出低电平；上下管都通 → 电源短路，不允许；上下管都断 → 输出高阻态。
  • 两个这样的推挽电路就构成 H 桥，可以控制直流电机正反转。

8.3 死区生成：延时一小段再导通

  • 直接用单片机控制就需要两个控制极，且电平相反（互补）——上管通下管必须断。
  • 那为什么要死区：切换上下管时，若上管关断瞬间下管立刻打开，会因器件不理想出现短暂的上下管同时导通，导致功率损耗、器件发热。
  • 所以有了死区生成电路：上管关闭时延迟一小段时间再导通下管，下管关闭时也延时再导通上管，避免同时导通。
  • 这就是死区生成和互补输出的用途，了解一下即可。

9. 舵机

到这里「STM32 内部如何产生 PWM」讲完，接下来看外部设备：舵机和直流电机，都可以用 PWM 控制。

9.1 舵机是什么：内部闭环的小电机系统

  • 舵机是一种根据输入 PWM 信号占空比来控制输出角度的装置。
  • 套件里的舵机型号是 SG90，有三根输入线：两根电源线、一根信号线，PWM 就是输入到信号线来控制舵机的。
  • 舵机有一个白色输出轴，会固定在一个指定角度不动，固定在哪个位置由信号线的 PWM 决定。
  • 拆解图能看到内部结构：舵机上盖、输出轴、减速齿轮组、直流电机、舵机控制板、电位器。所以舵机不是单独的电机，内部由直流电机驱动，还有一块控制电路板。
  • 内部闭环逻辑（29:52）：PWM 输入控制板给出目标角度；电位器检测输出轴当前角度；大于目标角度电机就反转；最终输出轴固定在指定角度。
  • 不管内部怎么闭环，我们只需要知道：输入一个 PWM 波形，输出轴就固定在一个角度。

9.2 输入要求：周期 20ms、高电平 0.5ms～2.5ms

  • 输入 PWM 的要求：周期为 20ms（对应 50Hz），高电平宽度 0.5ms～2.5ms。
  • 角度约定：这是 180° 的舵机，输出轴角度是 -90° 到 +90°（规定成 0 到 180° 也没问题）。
  • 周期 20ms 就是一个上升沿到下一个上升沿之间的时间；脉宽与角度线性对应：
输入信号脉冲宽度（周期 20ms） 舵机输出轴转角（画面） 口述
0.5ms -90° 0.5ms 对应 -90 度
1ms -45° 1ms 对应 -45 度
1.5ms -0°（应为 0°，见「存疑」） 1.5ms 对应 0 度
2ms 45°（口述为 +45°） 2ms 对应 +45 度
2.5ms 90°（口述为 +90°） 2.5ms 对应 +90 度
  • 0.5ms 对应 -90°、2.5ms 对应 +90°，中间按比例线性分配；给个 PWM，输出轴就固定在一个角度。

9.3 应用：PWM 在这里是「通信协议」

  • 应用：遥控车、遥控船可以用舵机控制方向，其它机械结构也可以考虑用舵机。
  • 这里的 PWM 其实当做一个通信协议来用，和「用 PWM 等效模拟输出」关系不大；把 PWM 当通信协议也很常见，因为很多控制器都有 PWM 输出，而且只需要一根信号线。

10. 舵机的硬件电路

10.1 引脚与线色：黑/棕=负、红=正、黄/橙/白=信号

  • 先看引脚定义图，舵机上有三根线：黑色是电源负极 GND；红色是电源正极，5V 舵机就接 +5V；黄色是信号线，接 PWM 信号。
  • 不同厂家线色可能不一样：套件里是棕、红、橙，右边那个是黑、红、白，但引脚顺序一样（黑/棕负、红正、黄/橙/白信号）；不确定就看商品页的引脚说明。

10.2 供电：5V 是电机驱动电源，独立供电要共地

  • GND 接 GND。
  • 电源正的 5V 是电机的驱动电源：电机一般是大功率设备，驱动电源也必须是大功率输出设备，能单独供电最好；不能的话要注意电源功率是否达标。
  • 如果单独供电，供电负极要和 STM32 共地，正极接在 5V 供电引脚上。
  • 这套套件可以直接从 ST-Link 的 5V 输出脚引一根线过来，就是用 USB 的 5V 供电，也带得动。

10.3 信号线：PWM 直接接 STM32 引脚（如 PA0）

  • 信号线 PWM 直接接到 STM32 引脚就行，比如 PA0。
  • 因为舵机内部有驱动电路，单片机引脚可以直接接过来；我们给的 PWM 只是通信线，不需要大功率。

11. 直流电机与驱动芯片

11.1 直流电机：大功率器件，GPIO 不能直接驱动

  • 直流电机是将电能转换为机械能的装置，通电就转。
  • 它有两个电极：电极正接电机正转，反接就反转；把正负极对调，电机就朝另一个方向转。
  • 套件里的电机型号是 130 直流电机。
  • 直流电机属于大功率器件，GPIO 口无法直接驱动，需要配合电机驱动电路。
  • 和舵机的区别：舵机内部自带驱动电路，信号线可以直接接单片机；直流电机里面没有驱动电路，必须外挂一个。

11.2 常见驱动芯片与 TB6612

  • 市面上的电机驱动芯片很多：TB6612、DRV8833、L9110、L298N 等，还有用分立元件 MOS 管搭的电路，功率可以做得更大。
  • 本课程直接用 TB6612 这款双路 H 桥型直流电机驱动芯片，可以驱动两个直流电机并控制转速和方向。
  • 它内部有两路独立驱动电路；因为是 H 桥型，一路有四个开关管，所以能控制正反转。（有些芯片如 ULN2003 一路只有一个开关管，只能单方向转。）

11.3 H 桥结构：两路推挽控制正反

  • H 桥电路由两路推挽电路组成（第 8.2 章分析过推挽）。
  • 左边这一路：上管通下管断，输出就接在 VM（电机电源正极）上；下管通上管断，就接在 PGND（电源负极）。
  • 两路推挽中间接一个电机：左上和右下导通，电流从左流向右；右上和左下导通，电流方向反过来。H 桥能控制电流方向，所以能控制电机正反转。
  • 这是电机驱动芯片内部的部分电路，了解一下即可。

12.2 三个电源脚：VM、VCC、GND

  • VM 是电机电源正极，和舵机的电源要求一样，要接能输出大电流的电源；电压一般和电机额定电压一致——5V 电机接 5V，7.2V 电机接 7.2V。
  • VCC 是逻辑电平输入端，范围 2.7 到 5.5V，要和控制器电源一致——用 STM32（3.3V 器件）接 3.3V，用 51 单片机（5V 器件）接 5V；它不需要大功率，可以和控制器共用一个电源。

12.3 控制引脚：AIN1/AIN2/PWMA 与 STBY

  • A 路控制三个脚 PWMA、AIN1、AIN2 直接接单片机 GPIO：PWMA 接 PWM 信号输出端，另外两个可以任意接普通 GPIO。
  • 这三个脚给低功率控制信号，驱动电路就从 VM 汲取电流输出到电机，实现「低功率信号控制大功率设备」。
  • B 路完全一样：BO1、BO2 是输出，控制端是 BIN1、BIN2、PWMB，两路可以各接一个电机。
  • STBY（StandBy）待机脚：接 GND 芯片待机不工作，接逻辑电源 VCC 就正常工作；不需要待机可以直接接 VCC（3.3V）。

13. 控制真值表与调速

13.1 真值表（画面原文）

三个脚（IN1、IN2、PWM，再加 STBY）怎么控制正反转和速度，看右下角的表：

IN1 IN2 PWM STBY O1 O2 模式状态
H H H/L H L L 制动
L H H H L H 反转
L H L H L L 制动
H L H H H L 正转
H L L H L L 制动
L L H H OFF — 停止
H/L H/L H/L L OFF — 待机
  • STBY 低电平待机、高电平正常工作，这个不用看（表里除了最后一行 STBY 都是 H）。
  • IN1 和 IN2 都接高电平：两个输出都是低电平、没有电压差，电机不转，状态是制动。
  • IN1 和 IN2 都接低电平：输出直接关闭，电机也不转，状态是停止。全高或全低都不能转。
  • 剩下就一高一低：IN1 低、IN2 高 → 反转状态，转不转取决于 PWM——PWM 高就是一低一高、有电压差、电机转；PWM 低就两个低电平、不转。
  • IN1 高、IN2 低 → 正转状态，同样 PWM 高就正转、PWM 低就停止。

13.2 调速：PWM 频率够快 = 连续稳定旋转

  • 如果 PWM 是不断翻转的电平信号，电机就是快速「反转、停止、反转、停止」；PWM 频率足够快，电机就连续稳定地反转，速度取决于占空比。
  • 正转也一样：频率足够快就是连续稳定正转，速度取决于占空比。
  • 这里的 PWM 就是前面讲的「等效一个模拟量」：IN1/IN2 决定方向（把电流通路定下来），PWM 负责以多快频率、多大比例通断，等效出加在电机上的平均电压，占空比越大平均电压越高、转速越快。

坑与易错点

  1. 本集没有代码，TIM_OCInit、TIM_OCMode_PWM1、TIM_SetCompare1 的用法都在 [6-4]。
  2. 占空比是 CCR/(ARR+1) 不是 CCR/ARR，分母 ARR+1 来自 CNT 从 0 数到 ARR 共 ARR+1 个数。
  3. 高电平只有 CCR 个数、不是 CCR+1 个：CNT 等于 CCR 的瞬间已跳低，CCR=30 时高电平是 0～29。
  4. 分辨率 = 1/(ARR+1) 是占空比最小变化步距，越小越好；按 CCR 范围定义则越大越好。
  5. CCR 一般取 0～ARR，CCR = ARR+1 时占空比正好 100%，再大就没意义。
  6. PWM模式2 就是 PWM模式1 输出取反，实际只用 PWM模式1 + 向上计数。
  7. 「有效电平/无效电平」在这里就当高低电平，真正的电平还能被 CC1P 极性位反一次。
  8. 8 种模式里只有 PWM1/PWM2 能同时调频率和占空比，其余不是用来输出连续波形的。
  9. 基本定时器没有输出比较，TIM6/TIM7 用不了；4 个通道各有各的 CCR 但共用一个 CNT。
  10. PWM 只能用在惯性系统（LED 余晖、电机惯性），频率要够快，否则会看到闪烁或抖动。
  11. 高级定时器的死区/互补是为了驱动推挽和 H 桥：上下管同时导通就是电源短路，死区就是切换时延时避免。
  12. 舵机的 PWM 是通信协议不是等效模拟量：周期必须 20ms（50Hz），高电平 0.5～2.5ms 对应 -90°～+90°。
  13. 舵机三根线颜色不能记死，黑/棕负、红正、黄/橙/白信号，顺序一致；独立供电时负极要和 STM32 共地。
  14. 直流电机 GPIO 不能直接驱动，必须加驱动电路；PWMA 必须接 PWM 输出端，AIN1/AIN2 可接普通 GPIO。
  15. TB6612 的 VM 和 VCC 别接反：VM 是电机电源 4.5～10V，VCC 是逻辑电源 2.7～5.5V；STBY 接 GND 会待机。
  16. 真值表记两条就够：IN1=IN2 全高是制动、全低是停止，一高一低才可能转且 PWM 高才转。
