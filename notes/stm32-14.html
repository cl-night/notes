[6-2] 定时器定时中断 / 定时器外部时钟 — 学习笔记

一句话结论

定时器初始化的七步是：开时钟、选时钟源、配时基、开更新中断、配 NVIC、启动计数器、写中断函数，PSC=7200-1 与 ARR=10000-1 让 72MHz 变成 1Hz 即 1s。

本集定位

  • [6-1] 的代码课：定时器类型、时基单元、计数模式、时钟源、结构图、时序公式、时钟树都在上一集（笔记 stm32-13），本集只写代码。
  • 七步依次是 RCC_APB1PeriphClockCmd → TIM_InternalClockConfig → TIM_TimeBaseInit → TIM_ITConfig → NVIC_PriorityGroupConfig(2) + NVIC_Init → TIM_Cmd → TIM2_IRQHandler。
  • 两个程序：① 6-1 定时器定时中断（内部时钟定 1s，每秒中断一次 Num++）；② 6-2 定时器外部时钟（挡光片产生方波驱动计数器，CNT 到 9 清零并 Num++）。
  • 全程流程：复制工程改名 → 新建 Timer 模块 → 写 Timer_Init() → 编译下载 → 看现象 → 改参数做实验，没有新的理论章节。
  • 直接沿用上一集结论：时基单元 = PSC + CNT + ARR，溢出频率 CK_CNT_OV = 72MHz/(PSC+1)/(ARR+1)；中断流向是时钟源 → 时基单元 → 更新事件/中断 → 中断输出控制 → NVIC。
  • TIM2 是 APB1 上的通用定时器，但内部基准时钟仍是 72MHz；PA0 复用 TIM2_CH1_ETR，就是外部时钟模式 2 的 ETR 引脚。

2. 写代码前先认函数：定时器库函数地图

先打开 Library\stm32f10x_tim.h 拖到最后，把常用库函数过一遍。

2.1 初始化相关

函数 作用 说明
TIM_DeInit 恢复缺省配置 复位外设
TIM_TimeBaseInit(TIMx, &结构体) 时基单元初始化 最重要；结构体里配 PSC/ARR/计数模式等
TIM_TimeBaseStructInit(&结构体) 给结构体赋默认值 类似 GPIO_StructInit
TIM_Cmd(TIMx, NewState) 使能/失能计数器 对应结构图里的「运行控制」；不使能计数器不运行
TIM_ITConfig(TIMx, TIM_IT, NewState) 使能中断输出信号 对应「中断输出控制」，TIM_IT 可选 Update/CC1～CC4/COM/Trigger/Break

2.2 时钟源选择的 6 个函数

函数 选择的时钟源
TIM_InternalClockConfig(TIMx) 内部时钟（RCC 的 TIMxCLK，72MHz）
TIM_ITRxExternalClockConfig(TIMx, InputTriggerSource) 其他定时器（ITRx，用于级联）
TIM_TIxExternalClockConfig(TIMx, TIM_TIxExternalCLKSource, Polarity, Filter) TIx 捕获通道（某一引脚的边沿）
TIM_ETRClockMode1Config(TIMx, ExtTRGPrescaler, ExtTRGPolarity, ExtTRGFilter) ETR 经外部时钟模式 1 输入的时钟
TIM_ETRClockMode2Config(TIMx, ExtTRGPrescaler, ExtTRGPolarity, ExtTRGFilter) ETR 经外部时钟模式 2 输入的时钟（程序二用这个）
TIM_ETRConfig(...) 注意：这个不是用来选择时钟的，是配置 ETR 的预分频/极性/滤波器本身
  • 对 ETR 输入的外部时钟，模式 1 和模式 2 这两个函数是等效的、参数也一样；不需要触发输入功能时两者可以互换。

图 4：stm32f10x_tim.h 末尾的时钟源选择 6 个函数

2.3 单独改关键参数、读写计数器

  • TIM_PrescalerConfig(TIMx, Prescaler, TIM_PSCReloadMode)：单独写预分频值，第二个参数是预分频值、第三个 TIM_PSCReloadMode 才是写入模式（PSC 有缓冲器，写入要等更新事件才生效）。
  • TIM_CounterModeConfig(TIMx, CounterMode) 改计数模式；TIM_ARRPreloadConfig(TIMx, NewState) 使能/失能 ARR 预装（ARPE）。
  • TIM_SetCounter(TIMx, Counter) 给计数器写值；TIM_SetAutoreload(TIMx, Autoreload) 给自动重装寄存器写值。
  • TIM_GetCounter(TIMx) 读当前计数值（程序二用来显示 CNT）；TIM_GetPrescaler(TIMx) 读当前预分频值。

2.4 标志位 / 中断标志位

  • 最后 4 个：TIM_GetFlagStatus / TIM_ClearFlag / TIM_GetITStatus / TIM_ClearITPendingBit，获取和清除标志位，写中断函数要用。

3. Timer_Init() 七步

3.1 步骤总览

对照 [6-1] 的定时中断基本结构图，初始化大体分七步：

  1. RCC 开启时钟（基本每段代码的第一步）；
  2. 选时基单元的时钟源（定时中断选内部时钟）；
  3. 配时基单元（预分频器、自动重装器、计数模式，用一个结构体）；
  4. 配中断输出控制，允许更新中断输出到 NVIC；
  5. 配 NVIC；
  6. 运行控制：使能计数器，否则计数器不运行；
  7. 写定时器中断函数，让它每隔一段时间自动执行一次。

3.2 ① RCC 开启时钟

RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);   // 注意用 APB1！TIM2 是 APB1 总线的外设
  • 要用 APB1 的开启时钟函数，因为 TIM2 是 APB1 总线外设（[6-1] 的表：TIM2～TIM5 挂 APB1，只有 TIM1/TIM8 用 APB2）。
  • 打开时钟后，定时器的基准时钟和外设的工作时钟就都打开了。

图 5：第一步用 APB1 的时钟函数开 TIM2

3.3 ② 选择时基单元的时钟源

TIM_InternalClockConfig(TIM2);   // 选择内部时钟（72MHz）；这行不写也行，定时器上电默认就是内部时钟
  • 参数只有一个 TIMx，写 TIM2，时基单元就由内部时钟驱动。
  • 很多人的代码都不写这个函数，因为定时器上电默认就是内部时钟，为了步骤完整还是写上。

3.4 ③ 配置时基单元（TIM_TimeBaseInit）

TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;        // 时钟分频（给输入滤波器用，跟定时无关）
TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;    // 向上计数
TIM_TimeBaseInitStructure.TIM_Period = 10000 - 1;                  // ARR 自动重装值
TIM_TimeBaseInitStructure.TIM_Prescaler = 7200 - 1;                // PSC 预分频值
TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;              // 重复计数器（高级定时器才用）
TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);
  • 结构体类型名从 TIM_TimeBaseInit 函数定义上面的注释里找，变量名起 TIM_TimeBaseInitStructure。
  • 参数 TIM_ClockDivision（时钟分频）：跟时基关系不大——外部信号输入引脚上一般有滤波器，滤波器要在固定采样频率下采样 N 个点、全都相同才输出；采样频率可由内部时钟直接来，也可加一个分频，就由它决定。可选 1 分频 TIM_CKD_DIV1、2 分频、4 分频，这里随便配一个、选 1 分频。
  • 参数 TIM_CounterMode：可选向上、向下和三种中央对齐模式，这里选向上计数 TIM_CounterMode_Up。
  • 后三个参数：TIM_Period 是 ARR 自动重装值，TIM_Prescaler 是 PSC 预分频值，TIM_RepetitionCounter 是重复计数器（高级定时器才有，这里直接给 0）。
  • 这里没有 CNT 的参数，需要的话用 TIM_SetCounter / TIM_GetCounter 单独操作。

1 秒是怎么算出来的（用 [6-1] 的公式）：

定时频率 = 72MHz / (PSC + 1) / (ARR + 1)
  • 要定时 1s 就是定时频率 1Hz：给 PSC = 7200、ARR = 10000，两个参数都再减 1（预分频器和计数器都差 1 个数）：
72M / 7200 = 10kHz  →  10k / 10000 = 1Hz  →  1s
  • PSC 和 ARR 的取值都要在 0～65535 之间（16 位），不要超范围。
  • 两者的取值不唯一：预分频给少、自动重装给多，就是「以较高频率计较多的数」，反过来也行——要么记公式，要么理解工作流程。

图 6：TIM_TimeBaseInit 五个参数，即 72MHz/7200/10000 = 1s

3.5 ④ 使能更新中断（TIM_ITConfig）

TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);   // 开启更新中断到 NVIC 的通路
  • 参数 TIMx 写 TIM2；TIM_IT 选要配置哪个中断输出，可任意组合，第一个就是 TIM_IT_Update 更新中断；NewState 写 ENABLE。
  • 这样就开启了更新中断到 NVIC 的通路，对应结构图里的「中断输出控制」。

3.6 ⑤ 配置 NVIC

NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);   // 优先级分组选分组 2

NVIC_InitTypeDef NVIC_InitStructure;
NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;                    // 定时器 2 在 NVIC 里的通道
NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;          // 抢占优先级
NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;                 // 响应优先级
NVIC_Init(&NVIC_InitStructure);
  • 先 NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2) 选分组 2，再用 NVIC_InitTypeDef NVIC_InitStructure 配通道。
  • 通道从 IRQn_Type 枚举里找 TIM2_IRQn，抢占/响应优先级给 2 和 1。

3.7 ⑥ 启动定时器（TIM_Cmd）

TIM_Cmd(TIM2, ENABLE);   // 使能计数器
  • 第一个参数 TIM2、第二个 ENABLE，这样定时器才开始工作，产生更新时就会触发中断。

图 7：开更新中断、配 NVIC、TIM_Cmd 启动

3.8 ⑦ 中断函数 TIM2_IRQHandler

void TIM2_IRQHandler(void)
{
	if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)   // 检查更新中断标志位
	{
		Num ++;                                        // 用户代码
		TIM_ClearITPendingBit(TIM2, TIM_IT_Update);    // 清除更新中断标志位（画面里在 if 内）
	}
}
  • 函数名从启动文件 startup_stm32f10x_md.s 里找，定时器 2 的就是 TIM2_IRQHandler，产生更新中断时会自动执行（这版先写在 Timer.c 里，4.3 再挪到 main.c）。
  • 进函数先 TIM_GetITStatus 检查中断标志位（参数 TIM2 和 TIM_IT_Update），等于 SET 就执行用户代码，最后别忘了 TIM_ClearITPendingBit(TIM2, TIM_IT_Update) 清标志位。
  • 写完把初始化函数声明放进 Timer.h：void Timer_Init(void);。

4. 中断函数与跨文件变量

4.1 主函数：调用初始化 + 显示 Num

#include "stm32f10x.h"
#include "Delay.h"
#include "OLED.h"
#include "Timer.h"

uint16_t Num;                 // 16 位全局变量，中断里 ++，主循环里显示

int main(void)
{
	OLED_Init();
	Timer_Init();             // 初始化定时器

	OLED_ShowString(1, 1, "Num:");

	while (1)
	{
		OLED_ShowNum(1, 5, Num, 5);   // 循环刷新 Num
	}
}
  • 主循环里只做 OLED_ShowNum(1,5,Num,5) 这一件事（源码里写成带空格的形式），计数全交给定时中断。

4.2 跨文件变量：直接写会报错

  • 中断函数在 Timer 模块里，Num 定义在 main.c 里，成了跨 .c 文件的变量，直接写 Num++ 编译会报错：
System\Timer.c(35): error:  #20: identifier "Num" is undefined
  • 方案一：在使用变量的那个文件（Timer.c）开头用 extern 声明：
extern uint16_t Num;   // 告诉编译器：Num 这个变量在别的文件里定义，你自己去找
  • extern 声明变量就是告诉编译器「这个变量在别的文件里定义了，你自己去找」。
  • 顺带一提：头文件里的函数声明其实也是用 extern 实现的，只是函数前的 extern 可以省略，所以一般不写。

4.3 方案二：把中断函数复制到 main.c（视频最终采用）

  • 直接把中断函数复制到主函数后面，这样就在一个文件里了，extern 声明也不需要了。
  • 于是把 Timer.c 里的中断函数注释掉、留作「中断函数模板」，哪个文件想用就复制过去：
void TIM2_IRQHandler(void)      // 主函数每秒自动把 Num++
{
	if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
	{
		Num ++;
		TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
	}
}
  • 对定时中断而言，这个中断函数就是为别的文件服务的，放在使用它的地方更方便。

5. 现象验证：一个经典坑

5.1 现象①：Num 每秒 +1

  • 编译下载后，Num 每秒加 1。

图 10：现象①，OLED 显示 Num:00006

5.2 坑：复位后 Num 从 1 开始

  • 按复位键复位一下，会发现 Num 是从 1 开始计数的；多复位几次，每次程序一开始 Num 就立刻变成 1。
  • 初始值应是 0，一上电就变 1，说明中断函数在初始化之后就立刻进了一次。

5.3 原因：TimeBaseInit 末尾的 EGR 手动更新事件

  • 打开 TIM_TimeBaseInit 函数，最后有一句 TIMX->EGR = TIM_PSCReloadMode_Immediate，即手动产生一个更新事件：
/* Generate an update event to reload the Prescaler and the Repetition counter
   values immediately */
TIMX->EGR = TIM_PSCReloadMode_Immediate;
  • 因为预分频器有缓冲寄存器，写的值要等更新事件才起作用，所以这里手动生成一个更新事件让值立刻生效。
  • 副作用是更新事件和更新中断同时发生，更新中断会置标志位——这就是上电立刻进中断的原因。

图 11：坑的根源是 TIMX->EGR = TIM_PSCReloadMode_Immediate;

5.4 修复：TimeBaseInit 之后、ITConfig 之前清一次标志

TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

TIM_ClearFlag(TIM2, TIM_FLAG_Update);      // ★ 手动清除更新标志位，避免刚初始化完就进中断
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE); //   然后再开启更新中断
  • 在 TIM_TimeBaseInit 之后、开启中断之前调用 TIM_ClearFlag(TIM2, TIM_FLAG_Update) 清除更新标志位，就能避免刚初始化完就进中断。
  • 修复后再下载，上电后数字从 0 开始增加。

图 12：TimeBaseInit 后、ITConfig 前加一句 TIM_ClearFlag

5.5 观察 CNT：计数器值在 0～9999 之间飞速变化

OLED_ShowNum(2, 5, TIM_GetCounter(TIM2), 5);   // 在主循环里读 CNT 并显示
  • 加这行后下载，计数器的值在飞速变化，范围从 0 一直到自动重装值：ARR 写的是 10000-1，所以从 0 自增到 9999，共 10000 个数，计 10000 次就是 1s。

图 13：CNT 在 0～9999 之间飞速循环

5.6 改 PSC/ARR 的实验：中断频率怎么变

  • 实验一：TIM_Period 从 10000 - 1 改成 1000 - 1，中断周期变 0.1s，CNT 在 0～999 之间循环，Num++ 速度比原来快 10 倍。
  • 实验二：TIM_Prescaler 从 7200 - 1 改成 720 - 1、Period 仍是 10000 - 1，就是以原来 10 倍的计数频率计 10000 个数，Num++ 同样快 10 倍。
  • 这就是预分频值和自动重装值对中断频率的影响；实验完记得把值改回来。

6. 程序二：定时器外部时钟

6.1 接线：对射式红外传感器 DO → PA0

  • 接线图 6-2 定时器外部时钟.jpg：右下角是 OLED，上面接对射式红外传感器，DO（数字输出）接到 PA0。
  • PA0 就是 TIM2 的 ETR 引脚（[6-1] 引脚定义表里 PA0 = TIM2_CH1_ETR），我们在这个引脚上输入外部时钟。
  • 接线：传感器三根杜邦线，VCC → 正极、GND → 负极、DO → PA0。

图 14：程序二接线，DO 接 PA0（TIM2 的 ETR）

6.2 复制工程并改配置

  • 复制 6-1 定时器定时中断 工程，改名 6-2 定时器外部时钟：基本任务仍是定时中断，只是时钟不再用内部时钟。
  • 把 TIM_InternalClockConfig(TIM2) 这一行删掉，换成 TIM_ETRClockMode2Config（通过 ETR 引脚的外部时钟模式 2）。
TIM_ETRClockMode2Config(TIM2, TIM_ExtTRGPSC_OFF, TIM_ExtTRGPolarity_NonInverted, 0x00);
  • 参数一：TIM2。
  • 参数二 TIM_ExtTRGPrescaler：TIM_ExtTRGPSC_OFF 关闭预分频，另有 DIV2、DIV4、DIV8，即对 ETR 时钟再提前分频；这里不需要分频，选 TIM_ExtTRGPSC_OFF。
  • 参数三 TIM_ExtTRGPolarity：TIM_ExtTRGPolarity_Inverted 反向（低电平或下降沿有效），TIM_ExtTRGPolarity_NonInverted 不反向（高电平或上升沿有效），这里选不反向。
  • 参数四 ExtTRGFilter：必须是 0x00～0x0F 之间的值，决定滤波器采样频率 f 和采样点数 N——手册里 ETF[3:0] 给了对应表（0000 无滤波器、按 f_DTS 采样），ETPS[1:0] 决定 ETRP 预分频；这里不用滤波器，写 0x00。

图 15：程序二的 Timer_Init，选外部时钟模式 2

6.3 别忘了配 GPIO：PA0 上拉输入

  • 引脚要用到 GPIO，所以还要先配置 GPIO：
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);   // 开启 GPIOA 时钟（GPIO 挂 APB2）

GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;           // 上拉输入
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;               // PA0
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &GPIO_InitStructure);
  • GPIO_Mode 查配置表：TIMx 的 ETR 输入推荐浮空输入，这里给上拉输入也是可以的。
  • 什么时候用浮空输入：外部输入信号功率很小时，内部上拉电阻可能影响输入信号，这时用浮空输入防止影响电平。

6.4 改小 PSC/ARR，封装读 CNT 的函数

TIM_TimeBaseInitStructure.TIM_Period = 10 - 1;     // ARR = 9：从 0 计到 9
TIM_TimeBaseInitStructure.TIM_Prescaler = 1 - 1;   // PSC = 0：不分频
  • 手动模拟的外部时钟没那么快，所以预分频给 1 - 1（即 PSC=1-1、也就是 0，不分频），自动重装给 10 - 1（即 ARR=10-1、也就是 9，从 0 计到 9）。
  • 想实时看 CNT，把读计数器封装成函数，并在 Timer.h 里声明：
uint16_t Timer_GetCounter(void)
{
	return TIM_GetCounter(TIM2);
}

uint16_t Num;

int main(void)

6.6 现象②：挡光一次 CNT+1，到 9 清零并 Num++

  • 挡一下光，CNT 加 1：现在时基单元没有预分频，每次遮挡（产生一个方波边沿）CNT 就加 1；有预分频就要遮挡几次才加一次。
  • CNT 加到 9 之后自动清零，同时申请中断执行 Num++。

图 16：现象②，挡光一次 CNT 加 1，到 9 清零并 Num++

  • 预分频器、极性这些参数都可以自己换一换看现象；stm32f10x_tim.h 里其它时钟输入（ITRx 级联、TIx 捕获通道等）也可以自己试。

坑与易错点

  1. TIM2 要用 RCC_APB1PeriphClockCmd 开时钟，写成 APB2 开不了（只有 TIM1/TIM8 在 APB2）。
  2. PSC/ARR 都要减 1：寄存器值 = 分频系数 − 1、周期数 − 1，写 7200 是 7201 分频，范围 0～65535。
  3. TIM_InternalClockConfig 可以省，上电默认就是内部时钟；写上也没问题。
  4. TIM_RepetitionCounter 是高级定时器才用的，基本/通用定时器给 0。
  5. TIM_ClockDivision 跟定时时间无关，只决定输入滤波器的采样频率。
  6. 上电 Num 从 1 开始是 EGR 更新事件的副作用，在 TimeBaseInit 后、ITConfig 前清一次标志。
  7. 跨文件用变量要 extern，或干脆把中断函数复制到 main.c（本集最终采用）。
  8. 中断函数名必须和启动文件里的向量名一致，定时器 2 是 TIM2_IRQHandler，写错不报错但不进中断。
  9. 中断里必须 TIM_ClearITPendingBit(TIM2, TIM_IT_Update) 清标志，否则反复进中断。
  10. 程序二删了内部时钟后必须补外部时钟模式 2 的配置，还要先开 GPIOA 时钟、把 PA0 配成输入。
  11. TIM_ETRClockMode2Config 的第四个参数（滤波器）只能是 0x00～0x0F。
  12. 外部时钟下 PSC=0 就是每个边沿计一次，开了预分频就变成挡 N 次才加一次。
  13. TIM_ETRClockMode1Config 与 TIM_ETRClockMode2Config 对 ETR 时钟等效，不用触发输入时可互换。
  14. 实验完记得把改过的 PSC/ARR 改回来，否则下一个程序的现象会莫名变快变慢。
