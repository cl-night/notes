[13-1] PWR电源控制 — 学习笔记

一句话结论

PWR 管电源：PVD 监控 VDD，越限时走 EXTI 申请中断。三种低功耗模式按睡眠→停机→待机排列，关得越来越多、越来越省电、也越来越难唤醒；待机只剩 4 个唤醒源，唤醒后程序从头运行。

1. 本集定位

  • 模块 13 的理论课，重点是三种低功耗模式与 PVD。
  • 13-1 修改主频、13-2 睡眠模式+串口发送+接收、13-3 停止模式+对射式红外传感器计次、13-4 待机模式+实时时钟 是 4 个已写好的工程，本集只演示现象。
  • 00:00–07:23 看现象，07:23–45:00 全是 PPT，45:00–45:52 查数据手册与参考手册。
  • 本集没有写一行代码；45:49「我们下小节来学习低功耗模式的相关代码」→ 代码在 [13-2]。
程序 现象
13-1 修改主频 主频 36MHz，Running 周期变 2s
13-2 睡眠模式+串口发送+接收 只在发送数据时闪一次 Running
13-3 停止模式+对射式红外传感器计次 遮挡一次红外计一次
13-4 待机模式+实时时钟 RTC 闹钟每 10 秒唤醒一次

1. 四个成品程序的现象

1.1 修改主频（13-1 修改主频）

  • 初始化显示 SystemCoreClock（指示当前主频），主循环以 1s 为周期显示 Running 再清除。
  • 现象：OLED 显示 SYSCLK:36000000，Running 闪烁周期变成 2s——主频从 72MHz 降到了 36MHz，同样的 Delay 跑得慢一倍。
  • 改法：system_stm32f10x.c 约 110 行处预留了配置时钟的宏，解除哪个频率的宏注释，主频就是多少。
  • 把 36M 的宏注释、72M 解除注释就恢复 72MHz（Running 周期恢复 1s）。
  • system 文件的详细解释与更多改主频玩法，写程序时再介绍。

图 2：程序①现象——OLED 显示 SYSCLK:36000000（主频 36MHz）与 Running，闪烁周期变成 2s，因为降频后同样的延时慢一倍

1.2 睡眠模式 + 串口收发（13-2）

  • 直接复制串口那一节的工程：收到一个字节触发中断，主循环查到标志位后读数据再用串口发回去。
  • 新增的关键代码只有主循环末尾的 __WFI();，执行这句芯片就进入睡眠模式。
  • 为什么要睡：没数据时主循环一直查标志位是无意义耗电，睡眠后收到数据自动退出、执行一遍任务再睡。
  • 现象：串口收发功能与之前一样，但 Running 只在发送数据时刻才闪一次——不在收发时芯片一直在睡。
  • __WFI() 是 CMSIS 提供的内核指令（Wait For Interrupt），不是 PWR 库函数。
  • 开头是 OLED_ShowString(1, 1, "RxData:");、Serial_Init();。
  • 主循环原文：while (1) { if (Serial_GetRxFlag() == 1) { RxData = Serial_GetRxData(); Serial_SendByte(RxData); OLED_ShowHexNum(1, 8, RxData, 2); } OLED_ShowString(2, 1, "Running"); Delay_ms(100); OLED_ShowString(2, 1, " "); Delay_ms(100); **__WFI();** }

图 3：程序②的 main.c——OLED_ShowString(1, 1, "RxData:");、Serial_Init();、主循环里查 Serial_GetRxFlag()、末尾 __WFI();

1.3 停止模式 + 对射式红外传感器计次（13-3）

  • 在外部中断那一节的代码基础上修改，加了 Running 指示和最后进入停止模式的代码。
  • 现象：每遮挡一次红外对射管就计次一次并显示 Running；不遮挡时芯片处于停止模式。

1.4 待机模式 + 实时时钟（13-4）

  • 用 RTC，时钟源 LSE，没晶振可用 LSI——LSI 在待机下仍可工作。
  • 进待机前先把 OLED 等外部模块关掉/清屏省电，示例用 OLED_Clear() 模拟。
  • 进入待机：PWR_EnterSTANDBYMode();，这是本集唯一出现的 PWR 库函数。
  • 唤醒用 RTC 闹钟每 10 秒自动唤醒一次：while (1) 里显示 Running、显示 STANDBY、清屏，然后进待机。
  • 现象：先 Running 再 STANDBY 并清屏，每 10 秒重复一次（唤醒后程序从头开始运行）。
  • 主循环原文（截图里带加粗标记）：while (1) { OLED_ShowNum(1, 6, RTC_GetCounter(), 10); OLED_ShowNum(3, 6, RTC_GetFlagStatus(RTC_FLAG_ALR), 1); OLED_ShowString(4, 1, "Running"); Delay_ms(100); OLED_ShowString(4, 1, " "); Delay_ms(100); OLED_ShowString(4, 9, "STANDBY"); Delay_ms(1000); OLED_ShowString(4, 9, " "); Delay_ms(100); OLED_Clear(); **PWR_EnterSTANDBYMode();** }
  • 同一段代码去掉加粗标记后：while (1) { OLED_ShowNum(1, 6, RTC_GetCounter(), 10); OLED_ShowNum(3, 6, RTC_GetFlagStatus(RTC_FLAG_ALR), 1); OLED_ShowString(4, 1, "Running"); Delay_ms(100); OLED_ShowString(4, 1, " "); Delay_ms(100); OLED_ShowString(4, 9, "STANDBY"); Delay_ms(1000); OLED_ShowString(4, 9, " "); Delay_ms(100); OLED_Clear(); PWR_EnterSTANDBYMode(); }

图 4：程序④的 main.c——主循环显示 RTC_GetCounter() 与 RTC_GetFlagStatus(RTC_FLAG_ALR)、Running/STANDBY 闪烁后 OLED_Clear()，最后 PWR_EnterSTANDBYMode();

1.5 低功耗模式下无法直接下载程序

  • 芯片在 3 种低功耗模式下不响应调试端口，直接点下载会失败。
  • 解决三步：① 按住复位键 ② 点下载按钮 ③ 及时松开复位键；三种模式都要这样。

1.6 停止模式唤醒后要重配主频

  • 从停止模式唤醒后 HSI（8MHz）被选为系统时钟，HSE 和 PLL 不会自动恢复，主频掉到 8MHz。
  • 必须在唤醒后第一时间调用 SystemInit() 把时钟配回 72MHz，否则串口波特率不对、定时器变慢。
  • 待机唤醒相当于复位，启动文件会自动调用 SystemInit()；睡眠模式时钟没停，通常不用处理。

2. 电源框图、复位与 PVD

2.1 图4 电源框图

  • VDDA 供电区域：A/D 转换器、温度传感器、复位模块、PLL；多引脚型号单独引出 VREF+/VREF−（C8T6 内部已短接到 VDDA/VSSA）。
  • VDD 供电区域：IO 电路、待机电路（含唤醒逻辑、IWDG）。
  • 1.8V 供电区域：CPU 核心、存储器、内置数字外设，由电压调节器从 VDD 降压得到。
  • 后备供电区域（VBAT）：LSE 32K 晶体振荡器、后备寄存器、RCC_BDCR、RTC。
  • 低电压检测器控制供电切换：VDD 有电用 VDD、没电用 VBAT；所以内核其实只吃 1.8V。

图 5：PPT「电源框图」图4——VDDA 区域（A/D 转换器、温度传感器、复位模块、PLL）、VDD 区域（IO 电路、待机电路/唤醒逻辑/IWDG）、1.8V 区域（CPU 核心、存储器、数字外设）、后备区域（LSE、后备寄存器、RCC BDCR、RTC）

2.2 上电复位与掉电复位

  • VDD/VDDA 过低时，内部会直接复位。
  • POR（上电复位，阈值上限）：电压升到 POR 以上才解除复位；PDR（掉电复位，下限）：掉到 PDR 以下触发复位。
  • POR 与 PDR 之间有 40mV 迟滞（典型 1.92V / 1.88V），用滞回比较器防止阈值附近抖动。
  • 复位信号低有效，还有 tRSTTEMPO（复位持续时间）。

图 6：PPT「上电复位和掉电复位」图5——VDD/VDDA 曲线、POR（上限，解除复位）、PDR（下限，触发复位）、40mV 迟滞、滞后时间 tRSTTEMPO、复位信号低有效

2.3 可编程电压监测器 PVD

  • PVD 也监测 VDD/VDDA，但阈值可以用程序指定：PLS 3 位选阈值，范围约 2.2V～2.9V，迟滞 100mV。
  • PVD 输出是正逻辑：电压过低输出 1、正常输出 0（与复位信号相反），可申请中断。
  • 用途：掉到阈值（如 2.9V）说明供电开始不稳，可紧急保存数据、关闭外设。
  • PVD 中断借道外部中断 EXTI，所以用 PVD 必须配置外部中断。
  • 同理 RTC 闹钟、USB 唤醒、ETH 唤醒也都借道 EXTI——只有外部中断能唤醒停止模式。

图 7：PPT「可编程电压监测器」图6——PVD 阈值可用 PLS 编程（2.2～2.9V）、100mV 迟滞、PVD 输出为正逻辑（过低为 1、正常为 0）

3.2 睡眠模式（＝浅睡眠/打盹）

  • 执行 WFI/WFE 后进入，程序暂停运行、唤醒后从暂停的地方继续。
  • SLEEPONEXIT 位决定：立刻睡眠，还是等最低优先级中断处理程序退出后再睡。
  • 所有 I/O 引脚保持运行模式时的状态（点亮的 LED 仍然亮）。
  • WFI 可被任一 NVIC 响应的中断唤醒，WFE 可被唤醒事件唤醒。
  • 对 1.8V 区域只关 CPU 时钟，电压调节器保持开——寄存器和存储器数据全部保留。
  • WFE 唤醒事件：① 外设使能中断但不在 NVIC 使能 + 内核 SEVONPEND 置 1 ② EXTI 配置为事件模式；建议直接用中断唤醒。

图 11：PPT「睡眠模式」——执行完 WFI/WFE 进入睡眠、程序暂停、唤醒后从暂停处继续；SLEEPONEXIT 位选立刻睡眠或等最低优先级中断退出；所有 I/O 保持运行模式状态；WFI 被任意 NVIC 中断唤醒、WFE 被唤醒事件唤醒

3.3 停机模式（＝整人罢工）

  • 进入条件：SLEEPDEEP=1 + PDDS=0 + WFI/WFE，LPDS 决定电压调节器开（0）还是低功耗（1）。
  • 唤醒：只能被外部中断（EXTI）唤醒——WFI 用中断模式、WFE 用事件模式。
  • PVD、RTC 闹钟、USB 唤醒、ETH 唤醒都借道 EXTI，所以这 4 个信号也能唤醒停止模式。
  • 关闭所有 1.8V 区域时钟（定时器暂停、串口暂停），但没关电源，SRAM/寄存器内容保留。
  • HSI/HSE 关闭，LSI/LSE 不会被动关闭；电压调节器开或低功耗，两者都能保住数据。
  • 低功耗更省电但唤醒有额外启动延时，开启更耗电但唤醒更快。

图 12：PPT「停止模式」——1.8V 区域所有时钟停止，PLL、HSI、HSE 被禁止，SRAM 和寄存器内容保留；所有 I/O 保持运行状态；退出停止模式时 HSI 被选为系统时钟；电压调节器低功耗时退出有额外启动延时

3.4 待机模式（＝下班回家）

  • 进入条件：SLEEPDEEP=1 + PDDS=1 + WFI/WFE。
  • 唤醒源只有 4 个：PA0-WKUP 引脚（即 PA0）上升沿、RTC 闹钟事件、NRST 外部复位、IWDG 独立看门狗复位。
  • 关 1.8V 区域时钟、关两个高速时钟、关电压调节器（＝1.8V 区域断电），存储器与寄存器数据全部丢失。
  • LSI/LSE 不主动关闭，要维持 RTC 与独立看门狗运行。
  • 所有 I/O 变为高阻态（浮空输入）：点亮的 LED 会熄灭、也不流电流。
  • 唤醒后程序从头开始运行，但备份区域的数据还在。

3.5 模式选择流程图

  • 执行 WFI/WFE 后：SLEEPDEEP=0 → 睡眠模式，再由 SLEEPONEXIT 分立刻睡眠/等中断退出后睡眠。
  • SLEEPDEEP=1 → 深度睡眠（停机与待机统称深度睡眠）。
  • PDDS=0 → 停机模式，再由 LPDS 分电压调节器开启/低功耗；PDDS=1 → 待机模式。

图 13：PPT「模式选择」流程图——WFI/WFE → SLEEPDEEP=0 睡眠（SLEEPONEXIT 分立刻睡/等中断退出）→ SLEEPDEEP=1 深度睡眠 → PDDS=0 停机（LPDS=0 调节器开启、LPDS=1 低功耗）/ PDDS=1 待机

5. 参考手册第 4 章：PWR 寄存器

  • PWR 只有两个寄存器。
  • PWR_CR：DBP（取消后备区域写保护）、PLS（选 PVD 电平，3 位）、PDDS（选停机还是待机）、LPDS（电压调节器开/低功耗）、CWUF（清除唤醒标志）。
  • PWR_CSR：WUF（唤醒标志）、SBF（待机标志）、EWUP（使能 WKUP 引脚）、PVDO（PVD 输出状态）。
  • PWR_CSR 的某些位在待机唤醒后或复位后、直到设置 PVDE 位之前会保持特定状态。
  • 手册第 4 章还有电源框图、上电/掉电复位、PVD、低功耗模式、低功耗模式下的自动唤醒（RTC 定期唤醒，即程序④现象）、寄存器描述。

坑与易错点

  1. 三种低功耗模式下无法直接下载：按住复位键 → 点下载 → 松开。
  2. __WFI() 是 CMSIS 内核指令，不是 PWR 库函数；本集只有 PWR_EnterSTANDBYMode()。
  3. 睡眠只关 CPU 时钟；停机关所有 1.8V 时钟 + HSI/HSE；待机连 1.8V 电源都关。
  4. PDDS 决定停机/待机：PDDS=0 停机、PDDS=1 待机，进停机前要确保 PDDS=0。
  5. LPDS 决定电压调节器：0 开启（唤醒快、更耗电）、1 低功耗（省电、唤醒慢），两者都保数据。
  6. 待机唤醒源只有 4 个：PA0-WKUP 上升沿、RTC 闹钟、NRST、IWDG 复位。
  7. 待机唤醒后程序从头运行，SRAM/寄存器数据丢失，只有备份区域数据还在。
  8. 待机时 I/O 变高阻态：点亮的 LED 会熄灭、不流电流。
  9. LSI/LSE 在停机和待机下不会主动关闭，否则 RTC 与 IWDG 没法工作。
  10. PVD 借道 EXTI：用 PVD 必须配置外部中断；RTC 闹钟/USB/ETH 唤醒也借道 EXTI。
  11. PVD 阈值比复位阈值高：2.2～2.9V（100mV 迟滞）对 POR/PDR 约 1.92/1.88V（40mV）。
  12. PVD 输出是正逻辑（电压低＝1），与低有效的复位信号相反。
  13. 表13/14 是最大值，典型值查表17；30mA/30µA/3µA 是估算。
  14. PC13～PC15 不能驱动 LED：输出速度 ≤2MHz、负载 ≤30pF、不能当电流源。
  15. 进低功耗前要关掉不必要的外设（如 OLED），否则它们还在耗电。
