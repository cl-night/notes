[6-8] 编码器接口测速 — 学习笔记

一句话结论

A→PA6、B→PA7；Encoder_Init 六步：上拉输入、ARR 满量程、不分频、TIM_EncoderInterfaceConfig 配极性。读数转 int16_t 得负数，测速先读后清零、闸门用 1s 中断。

本集定位

  • 代码课，理论全在 P19 [6-7]：0:02「接下来我们就来写一下编码器接口测速的代码」，0:12 看接线图，全程 Keil——看接线 → 复制工程 → 新建 Encoder.c/Encoder.h → 逐行写 Encoder_Init → 写 Encoder_Get → 编译下载 → OLED 看 CNT/Speed。
  • 全片一个工程：6-8 编码器接口测速，就是 P19 片头演示的成品工程，由 6-1 定时器定时中断 复制改名。
  • 理论不重复：正交编码器 A/B 90°、两张真值表、表77 三种模式、编码器模式下「极性=高低电平反相」都在 notes/stm32-19-编码器接口.md，本集只用结论。
  • 片尾无预告（模块 6 最后一集）：20:56「我们编码器接口测速的代码就写完了」直接结束。

1. 接线与工程准备

1.1 接线：A→PA6、B→PA7

  • 和 P12「外部中断旋转编码器计次」类似：编码器插在面包板左边，VCC、GND 接电源正负极。
  • 下面的 A 相输出接 PA6、B 相接 PA7。
  • 两根线可以交换（A→PA7、B→PA6），只改变正反转极性；但 PA6/PA7 本身不能换：查引脚定义表，PA6 就是 TIM3_CH1、PA7 就是 TIM3_CH2，本程序用 TIM3。
  • 其他定时器同理，都要按这张表接到对应 TIM 的 CH1、CH2。

图 2：引脚定义表——第 16 行 PA6 的复用功能里有 TIM3_CH1、第 17 行 PA7 有 TIM3_CH2（红圈）；字幕「其他定时器的话，也都需要参考这个表」

2. 写代码前先理清六步

步 做什么 本集要点
① RCC 开启时钟（GPIO + 定时器） TIM3 在 APB1、GPIOA 在 APB2
② 配置 GPIO 为输入模式 PA6/PA7 上拉输入
③ 配置时基单元 预分频一般选不分频；ARR 给最大 65535——只需要 CNT 执行计数
④ 配置输入捕获单元 只有「滤波器」和「极性」这两个参数有用，后面的分频器、数据选择器与编码器无关
⑤ 配置编码器接口模式 直接调一个库函数
⑥ TIM_Cmd 启动定时器 电路初始化完成
  • 初始化完成后 CNT 随编码器旋转自增自减；测位置直接读 CNT。
  • 测速度和方向：每隔一段固定的闸门时间取出一次 CNT 再清零，这就是测频法测速（P17 思路 + 方向）。
  • 本小节新学的库函数只有一个 TIM_EncoderInterfaceConfig，参数依次是定时器、编码器模式、通道 1 极性、通道 2 极性。

图 4：PPT「编码器接口基本结构」——红圈圈出「时基单元」里的 PSC 预分频器与 CNT 计数器、以及两路 GPIO；字幕「第三步，配置时基单元，这里预分频器我们一般选择不分频」

3. Encoder_Init 完整代码

#include "stm32f10x.h"

void Encoder_Init(void)
{
    /* ① 时钟：TIM3 在 APB1、GPIOA 在 APB2 */
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    /* ② GPIO：PA6、PA7 上拉输入 */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6 | GPIO_Pin_7;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    /* ③ 时基单元：ARR 满量程、PSC 不分频 */
    TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
    TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;   // 编码器模式下无作用
    TIM_TimeBaseInitStructure.TIM_Period = 65536 - 1;                 // ARR
    TIM_TimeBaseInitStructure.TIM_Prescaler = 1 - 1;                  // PSC
    TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseInitStructure);

    /* ④ 输入捕获单元：两个通道只配滤波器（极性删掉，由编码器接口函数统一配） */
    TIM_ICInitTypeDef TIM_ICInitStructure;
    TIM_ICStructInit(&TIM_ICInitStructure);

    TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
    TIM_ICInitStructure.TIM_ICFilter = 0xF;
    TIM_ICInit(TIM3, &TIM_ICInitStructure);

    TIM_ICInitStructure.TIM_Channel = TIM_Channel_2;
    TIM_ICInitStructure.TIM_ICFilter = 0xF;
    TIM_ICInit(TIM3, &TIM_ICInitStructure);

    /* ⑤ 编码器接口模式：TI1、TI2 都计数，两个通道都不反相 */
    TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, TIM_ICPolarity_Rising, TIM_ICPolarity_Rising);

    /* ⑥ 启动定时器 */
    TIM_Cmd(TIM3, ENABLE);
}

3.1 时钟与 GPIO：上拉输入的选择原则

  • 开时钟：RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);、RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);——TIM3 是 APB1 外设（RCC_APB1Periph_TIM3），所以开头用 RCC_APB1PeriphClockCmd；GPIOA 在 APB2（RCC_APB2Periph_GPIOA）。
  • GPIO：PA6/PA7 配 GPIO_Mode_IPU（上拉输入），GPIO_Pin = GPIO_Pin_6 | GPIO_Pin_7，GPIO_Speed_50MHz，初始化 GPIOA。
  • 三种输入模式怎么选：看外部模块空闲时的默认电平——默认高就上拉输入、默认低就下拉输入，与外部模块保持一致，防止默认电平「打架」。
  • 默认高电平是习惯状态，所以上拉输入用得比较多。
  • 不确定外部默认状态、或外部信号输出功率很小时，选浮空输入：没有上拉/下拉电阻去影响外部信号（但信号弱时容易受噪声干扰、来回跳变）。

3.2 时基单元：ARR 满量程、PSC 不分频

  • TIM_InternalClockConfig 没用了（最终代码里已删）：编码器接口托管时钟，它本身就是带方向控制的外部时钟。
  • TIM_CounterMode 同样没有作用：计数方向也被编码器接口托管了。
  • ARR 给 65536 - 1（满量程，即 65536-1）：计数范围最大，且方便换算负数（见 4.3/4.4 的补码）。
  • PSC 改成 1 - 1（不分频，即 1-1）：编码器时钟直接驱动计数器，再来一个边沿就计一个数。

3.3 输入捕获单元：只留滤波器

  • 编码器接口只用通道 1、2 的滤波器与极性，后面的分频器、数据选择器与编码器无关（留着也行，目前没作用）。
  • 参数删掉后结构体不完整，先用 TIM_ICStructInit 赋初值，防止结构体里出现不确定值。
  • 通道 1：TIM_Channel_1 + TIM_ICFilter = 0xF + TIM_ICInit；再把通道号改成 TIM_Channel_2 调一次——TIM_ICInit 已把值写进寄存器，同一个结构体改个值就能继续用。
  • 极性参数：这里的「上升沿」不代表上升沿有效（编码器接口上下沿都有效），而是高低电平不反转；给上升沿=不反相、给下降沿=反相。
  • 这个极性参数在编码器接口函数里也有（重复配置），所以最终代码把 TIM_ICPolarity 行删掉，只留滤波器和通道号。

图 5：Encoder.c 时基与输入捕获部分——TIM_Period = 65536 - 1; //ARR、TIM_Prescaler = 1 - 1; //PSC；两个通道 TIM_Channel_1 / TIM_Channel_2 都只配 TIM_ICFilter = 0xF，TIM_ICPolarity 行此时还在、后面会被删掉；字幕「把下面这些参数写入到通道2」

3.4 编码器接口模式：TIM_EncoderInterfaceConfig

TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, TIM_ICPolarity_Rising, TIM_ICPolarity_Rising);
  • 四个参数依次是 TIM3、编码器模式、通道 1 极性、通道 2 极性（图 6 完整可见）。
参数 取值 含义
第 1 个：定时器 TIM3 用哪个定时器的编码器接口
第 2 个：编码器模式 TIM_EncoderMode_TI1 / TIM_EncoderMode_TI2 / TIM_EncoderMode_TI12 仅在 TI1 计数 / 仅在 TI2 计数 / TI1、TI2 都计数（对应 P19 表77 三种模式）；一般用 TI12，两个边沿都计数、精度最高
第 3 个：通道 1 极性 TIM_ICPolarity_Rising / TIM_ICPolarity_Falling Rising = 不反相；Falling = 反相
第 4 个：通道 2 极性 同上 同上，可按实际情况配置
  • 极性在这个函数里也有，属于重复配置，所以统一用这个函数来配。
  • 完整一行就是 TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, TIM_ICPolarity_Rising, TIM_ICPolarity_Rising)。

图 6：编码器接口配置——TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, TIM_ICPolarity_Rising, TIM_ICPolarity_Rising); 四参数完整可见（高亮），上方是 TIM_ICInit 两通道；字幕「这两个地方的参数，其实都配置的是同一个寄存器」

3.5 坑：极性重复配置与函数顺序

  • TIM_ICInit 的极性与 TIM_EncoderInterfaceConfig 后两个参数配的是同一个寄存器，后配置覆盖前配置。
  • 所以删掉 TIM_ICInit 的极性行，只用 TIM_EncoderInterfaceConfig 配极性。
  • 顺序：TIM_EncoderInterfaceConfig 必须写在 TIM_ICInit 下面，否则方向配置被 TIM_ICInit 覆盖、白配。
  • 改完之后 TIM_ICInit 只剩滤波器还有用。

3.6 启动定时器

  • TIM_Cmd(TIM3, ENABLE); 收尾，初始化结束；调用 Encoder_Init() 后旋转编码器就能控制 CNT 自增自减。

图 7：Encoder.c 开头（Encoder_Init 前半）——两个开时钟调用、GPIO_Mode_IPU、GPIO_Pin_6 | GPIO_Pin_7、GPIO_Speed_50MHz、TIM_Period = 65536 - 1; //ARR、TIM_Prescaler = 1 - 1; //PSC；字幕「调用一下这个 Encoder_Init 函数」

4. 读计数：初版 Encoder_Get

4.1 初版 Get 与主函数

uint16_t Encoder_Get(void)
{
    return TIM_GetCounter(TIM3);
}
  • Encoder_Init 和 Encoder_Get 都要放到头文件声明。
  • 初版一行就够：uint16_t Encoder_Get(void){ return TIM_GetCounter(TIM3); }。
  • main.c 里显示字符串改成 "CNT:"，主循环解除注释、不断显示 Encoder_Get() 的值：
OLED_Init();
Encoder_Init();
OLED_ShowString(1, 1, "CNT:");

while (1)
{
    OLED_ShowNum(1, 5, Encoder_Get(), 5);
}

4.2 现象：向右转一格 CNT 变 4

  • 下载后显示 CNT 是 0，向右转一下变成 4。
  • 原因：这个编码器有「段落感」（机械触点式），每转一格 A 相产生一个低电平脉冲、B 相产生一个相位差 90° 的脉冲。
  • 所以转一格，A、B 相各出现一个下降沿和一个上升沿，计次共加了 4 次。
  • 换成电机的霍尔/光栅编码器就没有段落感，计数取决于实际脉冲。
  • 继续右转 CNT 自增，左转 CNT 自减。

图 8：初版现象——OLED 显示 CNT:00004（向右转一格、计次加了 4 次），右侧红笔画的是 A/B 两相的波形（各一个上升沿+下降沿）；字幕「所以计次总共加了4次」

图 9：初版 Encoder_Get——uint16_t Encoder_Get(void) { return TIM_GetCounter(TIM3); }（高亮），上方是 TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, ...) 与 TIM_Cmd(TIM3, ENABLE)；字幕「这样来测试一下」

4.3 现象：向左转到 0 再减，会溢出到 65535

  • 左转到 0 之后再减，计数器反向溢出、回到自动重装值 65535，再继续往下减：65535、65534……
  • 原因：Encoder_Get 返回的是 uint16_t，0 减 1 就变成 65535。

图 10：反向溢出——OLED 显示 CNT:65520（左转到 0 后再减，回到 65535 附近继续往下减）；字幕「回到自动重装值，65535，然后继续往下减」

4.4 转有符号：把 uint16_t 转成 int16_t

  • 想让 0 之后显示 -1，直接把返回类型改成 int16_t，函数声明也要跟着改。
  • 也可以把 OLED_ShowNum 改成 OLED_ShowSignedNum，它内部也做了类型强转；主循环里就是改成 ShowSignedNum。
  • 现象：向右转自增、向左转自减，负数继续减小（实测 CNT:-0013）。
  • 原理：借补码把 65535 当 -1、65534 当 -2（P19 讲过）。
int16_t Encoder_Get(void)
{
    return TIM_GetCounter(TIM3);
}

图 11：转有符号后的现象——OLED 显示 CNT:-0013（0 以下正常显示负数）；此时字幕「目前向右转是增，向左转是减」

4.5 方向反了怎么办

  • 硬件：把 A、B 两根线换一下，增减方向就反过来。
  • 软件：把任一通道极性反转即可；两个极性都反则方向不变。
  • 演示：把第一个 TIM_ICPolarity_Rising 改成 TIM_ICPolarity_Falling，方向就反过来了。
  • 到这一步代码是「编码器测量位置」：直接 TIM_GetCounter 读 CNT。

5. 测速：闸门时间 + 读后清零

5.1 测速版 Encoder_Get

  • 在固定闸门时间读一次 CNT 再清零，所以要先定义临时变量 Temp 缓存。
int16_t Encoder_Get(void)
{
    int16_t Temp;
    Temp = TIM_GetCounter(TIM3);   // 先读
    TIM_SetCounter(TIM3, 0);       // 后清零
    return Temp;
}
  • 顺序要点：Temp = TIM_GetCounter(TIM3); TIM_SetCounter(TIM3, 0); return Temp;——先读后清零，用 Temp 缓存一下。

5.2 闸门 1s：先用的 Delay_ms(1000)

  • 主循环里每隔一段时间 Get 一次：人手转得慢，闸门时间就给 1s；电机飞速旋转时就可以给短点。
  • 此时 CNT 的值就代表速度，单位是「脉冲个数 / s」。
  • 现象：右转慢是较小的正数、快是较大的正数；左转慢是较小的负数、快是较大的负数。
  • 本集没有换算 RPM、也没讲编码器每圈多少个脉冲；接编码电机可以自己试（现象一样，闸门要短点）。

图 12：测速版 Encoder_Get——int16_t Temp; Temp = TIM_GetCounter(TIM3); TIM_SetCounter(TIM3, 0); return ...（TIM_SetCounter 那行高亮）；字幕「之后 TIM_SetCounter(TIM3, 0)，给 CNT 清零」

图 13：Delay 闸门版主函数——OLED_ShowString(1, 1, "CNT:")、主循环里 OLED_ShowSignedNum(1, 5, Encoder_Get(), 5);，下面 Delay_ms(1000);（高亮）；字幕「防止计数器溢出」

5.3 改进：改用现成的 1s 定时中断（最终版）

  • 缺点：Delay 实现闸门时间会阻塞主循环，主程序还有别的事就不该这么写。
  • 改用 main.c 里留了这么久的定时中断（从 6-1 带过来的）：
    1. Timer_Init() 解除注释，目前每 1s 进一次中断，可改中断时间来调闸门；
    2. 定义全局 int16_t Speed;；
    3. 在 TIM2_IRQHandler 里 Speed = Encoder_Get();，把每秒读到的值存进 int16_t Speed；
    4. 主循环快速刷新 Speed，Delay 可以删掉，显示就是 OLED_ShowSignedNum(1, 7, Speed, 5) 这一句；
    5. 字符串改成 "Speed:"，数字位置往后挪两格到第 7 列。
  • 改造前的 Delay 版主循环是 OLED_ShowSignedNum(1, 5, Encoder_Get(), 5); 加 Delay_ms(1000);。
  • 定时中断版的骨架就是 OLED_Init(); Timer_Init(); Encoder_Init();，中断里 if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET) { Speed = Encoder_Get(); TIM_ClearITPendingBit(TIM2, TIM_IT_Update); }。
int16_t Speed;

int main(void)
{

坑与易错点

  1. 引脚只能用所选定时器的 CH1/CH2：本程序用 TIM3，所以 PA6（TIM3_CH1）、PA7（TIM3_CH2）；换定时器要按引脚定义表接，PA6/PA7 本身不能随便换。
  2. A/B 两根线可以交换（A→PA7、B→PA6 也行），只改变正反转极性；VCC/GND 不能接反。
  3. TIM_InternalClockConfig 在编码器模式下没用（编码器接口托管时钟），最终代码里已删掉；TIM_CounterMode 也没有作用，留着不报错但别以为它管用。
  4. ARR = 65536-1（满量程）：一是计数范围最大，二是方便把 16 位无符号数当有符号数、直接得到负数。
  5. PSC = 1-1（不分频）：编码器时钟直接驱动计数器，来一个边沿计一次；分频会降低分辨率。
  6. TIM_ICInit 里只保留 TIM_Channel 和 TIM_ICFilter：编码器接口只用通道 1/2 的滤波器和极性，其余参数与编码器无关。
  7. 极性重复配置大坑：TIM_ICInit 的极性与 TIM_EncoderInterfaceConfig 后两个参数是同一个寄存器，后配置覆盖前配置——所以要删掉 TIM_ICInit 的极性行，并保证 TIM_EncoderInterfaceConfig 写在 TIM_ICInit 之后。
  8. 模式参数一般用 TIM_EncoderMode_TI12：TI1、TI2 都计数、两个边沿都计入、精度最高；TI1/TI2 只在一个通道的边沿计数。
  9. 编码器模式下 Rising/Falling 不是「上升沿/下降沿有效」：而是「不反相 / 反相」（高低电平极性），P19 讲过、本集用来调方向。
  10. 改方向的三种办法：①A/B 两根线对调；②把任一通道极性从 Rising 改成 Falling；③换引脚——注意两个极性都反则方向不变。
  11. Encoder_Get 初版返回 uint16_t：左转到 0 再减会溢出到 65535；要显示负数就改成 int16_t 配合 OLED_ShowSignedNum，这是借补码强转的技巧。
  12. 测速必须先读后清零：int16_t Temp; Temp = TIM_GetCounter(TIM3); TIM_SetCounter(TIM3, 0); return Temp;——顺序反了就永远是 0，所以需要 Temp 缓存。
  13. 闸门时间决定速度单位：Delay_ms(1000) 时单位是脉冲个数/s；本集没有 RPM/每圈脉冲数换算，想要 RPM 得自己乘系数。
  14. 不要在主循环放长 Delay：会阻塞主循环；最终版改用 1s 定时中断，在 TIM2_IRQHandler 里读速度、主循环只刷新显示。
  15. 中断里必须清标志位：TIM_ClearITPendingBit(TIM2, TIM_IT_Update)，否则会反复进中断（P14 讲过）。
  16. 「一格=4 次计数」只对机械触点式编码器成立：霍尔/光栅编码器没有段落感，计数取决于实际脉冲数。
  17. 本集无示波器：所有现象都是 OLED 数值加口述。
  18. Timer_Init() 的 1s 配置本集没展示：直接沿用 6-1 定时器定时中断 模板，别自己编它的 PSC/ARR。
