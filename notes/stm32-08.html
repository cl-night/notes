[3-4] 按键控制LED / 光敏传感器控制蜂鸣器 — 学习笔记

一句话结论

本集是 GPIO 输入的程序课：先写「按键控制 LED」走通模块化封装（LED.c/h、Key.c/h）、消抖和状态取反，再写「光敏控制蜂鸣器」练 Buzzer.c/h、LightSensor.c/h，最后是 GPIO 使用三步。

0. 本集定位：两个工程与现象

  • 代码课，接 [3-3] 的 GPIO 输入理论；套路都是「开时钟 → 填结构体 → GPIO_Init」。
  • 工程 1 练按键输入 + 封装 + 消抖 + 状态取反；工程 2 换成光敏模块 + 蜂鸣器。
工程 硬件 现象
3-4 按键控制LED 按键 PB1、PB11（一端接 GND）+ LED PA1、PA2（一端接 VCC，低电平点亮） 按键 1 点亮 LED1、按键 2 熄灭 LED1；演示程序用状态取反（按一下翻转一次）
3-5 光敏传感器控制蜂鸣器 蜂鸣器（VCC/GND + PB12）+ 光敏模块（VCC/GND + DO 接 PB13） 遮住光敏电阻 → 蜂鸣器响；拿开 → 不响

1. 工程 1：硬件接线

  • 两个按键接 PB1、PB11，一端接 GPIO、另一端接 GND → 要配置上拉输入，按下读到 0。
  • 两个 LED 接 PA1、PA2，一端接 GPIO、另一端接 VCC → 低电平点亮。
  • 数量和端口都是随意的，看需求接。

2. 模块化编程：把驱动搬出主函数

  • 问题：驱动混在主函数里，乱、不好管理、不好移植。
  • 做法：驱动单独封装到 .c / .h 文件，即模块化编程（51 教程讲过）。
  • 步骤：
    1. 新建 Hardware 文件夹存放驱动；
    2. Keil 工程管理（三个箱子按钮）新建 Hardware 组并挪好位置；
    3. 魔术棒 → C/C++ → Include Paths，把 Hardware 文件夹加进头文件路径；
    4. Hardware 组右键 → Add New Item：先建 LED.c（C File）、再建 LED.h（Header File），路径选 Hardware（路径栏可直接写 \Hardware）。
  • .c 第一行 include stm32f10x.h；.h 加防重复包含的固定框架：
#ifndef __LED_H
#define __LED_H

/* 函数声明放这里 */

#endif
  • 说明：#ifndef __LED_H 是“如果没有定义”，#define __LED_H 就定义它，#endif 与 #ifndef 配对；声明放在这一对之间；文件最后要以空行结尾。

图 3：Keil 新建 Hardware 组与 LED.c / LED.h

3. LED 驱动模块（LED.c / LED.h）

LED_Init 初始化函数：

void LED_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);   // 开启 GPIOA 时钟
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;        // 推挽输出
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1 | GPIO_Pin_2;   // 同时选中 PA1、PA2
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOA, &GPIO_InitStructure);
}
  • 不出代码提示时按 Ctrl+Alt+空格 调出提示（选 GPIO_InitTypeDef 等）。
  • 下载后两个 LED 都亮——GPIO 配置好后默认就是低电平，LED 低电平点亮，所以在 Init 最后加一句：
GPIO_SetBits(GPIOA, GPIO_Pin_1 | GPIO_Pin_2);   // 初始化后默认熄灭
  • 本笔记代码块为简化写法（省略了部分 #include），实际以视频画面为准。

点亮/熄灭函数（4 个；也可以合并成 LED_Set(哪个灯, 开/关)，灯少就直接写 4 个）：

void LED1_ON(void)  { GPIO_ResetBits(GPIOA, GPIO_Pin_1); }   // 低电平点亮
void LED1_OFF(void) { GPIO_SetBits(GPIOA, GPIO_Pin_1); }     // 高电平熄灭
void LED2_ON(void)  { GPIO_ResetBits(GPIOA, GPIO_Pin_2); }
void LED2_OFF(void) { GPIO_SetBits(GPIOA, GPIO_Pin_2); }
  • 这 5 个函数的第一行复制到 LED.h 声明（加分号），模块外才能调用。
  • 主函数测试：
#include "LED.h"

int main(void)
{
	LED_Init();
	while (1)
	{
		LED1_ON();  LED2_OFF();  Delay_ms(500);
		LED1_OFF(); LED2_ON();   Delay_ms(500);
	}
}
  • 现象：两个 LED 交替闪烁；主函数只关心初始化/开灯，不管底层参数。

4. Key 驱动模块（Key.c / Key.h）

Key_Init：把两个按键端口（PB1、PB11）初始化为上拉输入：

void Key_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;             // 上拉输入
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1 | GPIO_Pin_11;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;         // 输入模式下无用，但还是要填
	GPIO_Init(GPIOB, &GPIO_InitStructure);
}

gpio.h 的 4 个读函数（打开 gpio.h 看函数说明）：

函数 作用
GPIO_ReadInputDataBit(GPIOx, GPIO_Pin) 读取输入数据寄存器某一位，返回 uint8_t 高低电平 → 读按键用这个
GPIO_ReadInputData(GPIOx) 读取整个输入数据寄存器，返回 uint16_t，每一位对应一个端口
GPIO_ReadOutputDataBit(GPIOx, GPIO_Pin) 读取输出数据寄存器某一位，看“自己输出了什么”
GPIO_ReadOutputData(GPIOx) 读取整个输出数据寄存器

Key_GetNum 读取键码 + 消抖：

uint8_t Key_GetNum(void)
{
	uint8_t KeyNum = 0;   // 默认 0：没有按键按下
	if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)   // PB1 按下（低电平）
	{
		Delay_ms(20);                                    // 按下消抖
		while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0);  // 等待松手
		Delay_ms(20);                                    // 松手消抖
		KeyNum = 1;
	}
	if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0)  // PB11 同理
	{
		Delay_ms(20);
		while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_11) == 0);
		Delay_ms(20);
		KeyNum = 2;
	}
	return KeyNum;
}
  • 按键一般松手后才动作，用 while 卡住等松手，保证一次按下只触发一次。
  • Key.c 用到 Delay_ms 要 #include "Delay.h"（否则报 fatal error: Delay file not found）。
  • 两个函数第一行复制到 Key.h 声明。

图 7：Key_GetNum 最终代码——PB1/PB11 两段消抖，返回键码 1/2

5. 按键控制 LED（main.c）

  • 主函数用全局变量 KeyNum 接键码。
  • 注意：main 里是全局变量，Key_GetNum 里是局部变量，作用域不同、不是同一个变量。

写法①（直接控制）：

KeyNum = Key_GetNum();
if (KeyNum == 1) LED1_ON();     // 按右边按键 1 → LED1 点亮
if (KeyNum == 2) LED1_OFF();    // 按左边按键 2 → LED1 熄灭

写法②（状态取反，演示程序采用）：

void LED1_Turn(void)
{
	if (GPIO_ReadOutputDataBit(GPIOA, GPIO_Pin_1) == 0)   // 当前输出 0（低=亮）
		GPIO_SetBits(GPIOA, GPIO_Pin_1);                  // 置 1 熄灭
	else
		GPIO_ResetBits(GPIOA, GPIO_Pin_1);                // 置 0 点亮
}

主循环：

while (1)
{
	KeyNum = Key_GetNum();
	if (KeyNum == 1) LED1_Turn();
	if (KeyNum == 2) LED2_Turn();
}
  • LED1_Turn / LED2_Turn 的第一行也要复制到 LED.h 声明（否则隐式声明警告）。
  • 现象：按一下翻转一次——LED_Init 末尾已设默认熄灭，第一次按下是点亮，再按熄灭。
  • 驱动函数写好尽量加注释（用途、参数、返回值）。

6. 工程 2：光敏传感器控制蜂鸣器

接线：蜂鸣器 VCC/GND 接电源、控制脚接 PB12；光敏模块 VCC/GND 接电源、DO 接 PB13。

光敏模块：4 针（VCC、GND、DO、AO），只用 DO 数字输出：

  • 上电后指示灯亮；
  • 遮住光线时输出指示灯灭，代表 DO 输出高电平（1）；
  • 有光时输出指示灯亮，代表 DO 输出低电平（0）；
  • 蓝色电位器可调判断阈值。

图 10：遮光时输出指示灯灭（DO 输出高电平）

图 11：蓝色电位器可调判断阈值

封装 Buzzer 驱动：复制 3-4 工程改名为 3-5 光敏传感器控制蜂鸣器，Hardware 下新建 Buzzer.c/h：

void Buzzer_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;   // 推挽输出
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_12;         // PB12
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOB, &GPIO_InitStructure);
	GPIO_SetBits(GPIOB, GPIO_Pin_12);                  // 默认高电平，蜂鸣器不响
}
void Buzzer_ON(void)  { GPIO_ResetBits(GPIOB, GPIO_Pin_12); }  // 低电平触发响
void Buzzer_OFF(void) { GPIO_SetBits(GPIOB, GPIO_Pin_12); }
  • 从 LED.c 复制时会带上 Buzzer_Turn（Buzzer.h 声明），同样读输出寄存器再翻转；用 while (1) { Buzzer_Turn(); Delay_ms(500); } 测试会不断鸣响。

封装 LightSensor 驱动：

void LightSensor_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;      // 上拉输入（模块常接也可用浮空输入）
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_13;         // PB13
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOB, &GPIO_InitStructure);
}
uint8_t LightSensor_Get(void)
{
	return GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_13);   // 直接返回端口电平
}
  • 模块始终连在端口上时也可用浮空输入，只要引脚不悬空。

main.c：

#include "Buzzer.h"
#include "LightSensor.h"

int main(void)
{
	Buzzer_Init();
	LightSensor_Init();
	while (1)
	{
		if (LightSensor_Get() == 1) Buzzer_ON();   // 遮光（高电平）→ 响
		else Buzzer_OFF();                          // 有光（低电平）→ 不响
	}
}
  • 现象：遮住 → 响；拿开 → 不响。

7. 本集总结：GPIO 使用三步

  1. 初始化时钟（RCC_APB2PeriphClockCmd）；
  2. 定义并赋值结构体：GPIO_Mode 选 8 种模式之一，GPIO_Pin 可按位或同时选多个引脚，GPIO_Speed 选输出速度（要求不高直接 50MHz）；
  3. 调用 GPIO_Init 初始化指定的 GPIO 外设。
  • 读写 GPIO 主要用 gpio.h 里的 8 个读写函数（4 个读 + 4 个写：GPIO_SetBits/ResetBits/WriteBit/Write、GPIO_ReadInputDataBit/ReadInputData/ReadOutputDataBit/ReadOutputData）。
  • 模块化：驱动单独提取到 .c/.h，简化主函数、方便移植与分工。
  • 函数注释：既然要封装，就写清用途/参数/返回值。

8. 坑与易错点

  1. 按键接 GND 就用上拉输入：按下读到 0，配 GPIO_Mode_IPU。
  2. 消抖必须做：Delay_ms(20) → while 等松手 → Delay_ms(20)，否则一次按下触发多次。
  3. 按键一般“松手后才动作”：用 while 等松手，保证一次按下只触发一次。
  4. LED 默认低电平：GPIO 配置好后默认输出低，低电平点亮的 LED 会直接亮 → Init 末尾 GPIO_SetBits 设默认状态。
  5. 输入模式下 GPIO_Speed 没用但仍要填：三个成员都要赋值，填 50MHz 即可。
  6. .h 防重复包含：#ifndef/#define/#endif 三件套，声明放里面；.c 第一行 include stm32f10x.h；文件最后留空行。
  7. 模块内用到 Delay 要 include：Key.c 用 Delay_ms 要 #include "Delay.h"，否则报找不到文件。
  8. 全局/局部变量同名不同变量：main 的 KeyNum（全局）≠ Key.c 里的 KeyNum（局部）。
  9. 光敏 DO 电平别记反：遮光 → 高电平(1)（指示灯灭）；有光 → 低电平(0)（指示灯亮）；阈值用蓝色电位器调。
  10. Keil 实时语法检查会滞后：偶尔的报错直接编译看结果；Ctrl+Alt+空格 调代码提示。
