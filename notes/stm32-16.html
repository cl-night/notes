[6-4] PWM驱动LED呼吸灯 / PWM驱动舵机 / PWM驱动直流电机 — 学习笔记

一句话结论

三个工程共用一套 PWM 模板：选时钟源 → 配时基（PSC/ARR）→ 配输出比较（TIM_OCxInit）→ GPIO 配 GPIO_Mode_AF_PP → TIM_Cmd 启动。

本集定位

  • [6-3] 输出比较的代码课：8 种输出模式、图125 通道电路、三个公式、舵机 20ms、TB6612 真值表全部在 P15。
  • 三个工程依次从零改写：6-3 PWM驱动LED呼吸灯、6-4 PWM驱动舵机、6-5 PWM驱动直流电机，正是 P15 片头演示的三个现成工程。
  • 片尾还有一段 PA0 → PA15 重映射，是程序一的延伸，不是独立程序。
  • 翻 PPT 只有几处：02:44 讲五步流程、17:11 与 20:59 算公式、39:25 与 41:38 讲多通道；翻手册是查引脚定义表与重映射表。
  • 编号注意：视频是 [6-4]，工程目录却叫 6-3 / 6-4 / 6-5，两套编号不是一回事。公式推导见 notes/stm32-15-输出比较.md。

2.3 写代码前先理清五步

2.5 PWM_Init 完整代码（程序一最终版）

#include "stm32f10x.h"

void PWM_Init(void)
{
    /* 时钟：TIM2 在 APB1，GPIOA 在 APB2 */
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    /* GPIO：复用推挽输出（引脚控制权交给片上外设） */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    /* 时钟源：选内部时钟（默认就是内部时钟，写上更完整） */
    TIM_InternalClockConfig(TIM2);

    /* 时基单元：PSC 定频率、ARR 定周期 */
    TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
    TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInitStructure.TIM_Period = 100 - 1;      // ARR
    TIM_TimeBaseInitStructure.TIM_Prescaler = 720 - 1;   // PSC
    TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0; // 高级定时器才用
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

    /* 输出比较单元：PWM模式1、高电平有效、使能输出、CCR 初值 50 */
    TIM_OCInitTypeDef TIM_OCInitStructure;
    TIM_OCStructInit(&TIM_OCInitStructure);
    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStructure.TIM_Pulse = 0;                   // CCR 初值（参数计算阶段曾用 50，27:00 后按口述改为 0）
    TIM_OC1Init(TIM2, &TIM_OCInitStructure);

    /* 运行控制：启动计数器 */
    TIM_Cmd(TIM2, ENABLE);
}

几个要点：

  • 先 TIM_OCStructInit 赋默认值：不赋初值时成员值不确定，作者遇到过「高级定时器输出 4 路 PWM、初始化函数位置一换就只输出 3 路」的怪问题。
  • TIM_OCMode 可选：TIM_OCMode_Timing（冻结）、_Active（相等时置有效）、_Inactive（相等时置无效）、_Toggle（相等时翻转）、TIM_OCMode_PWM1 / _PWM2、_ForcedAction_Active / _Inactive（强制输出，初始化时不让用）；这里选 TIM_OCMode_PWM1。
  • TIM_OCPolarity 选 TIM_OCPolarity_High：有效电平是高电平，REF 有效时输出高电平。
  • TIM_OutputState：Disable 失能 / Enable 使能，这里选 TIM_OutputState_Enable，肯定得使能。
  • TIM_Pulse 就是 CCR 的值（注释写「指定的 Pulse 值会被加载到 Capture Compare Register」）；PSC 定预分频、ARR 定周期、CCR 定占空比。
  • GPIO 必须配 GPIO_Mode_AF_PP：普通开漏/推挽输出的引脚由 ODR（输出数据寄存器）控制，复用模式下 ODR 被断开、控制权交给片上外设，而该引脚连的正是 TIM2 的 CH1。

图 3：stm32f10x_gpio.h 里 GPIO_Mode_AF_PP = 0x18 高亮——复用推挽输出

图 4：程序一参数计算完成时（23:15，TIM_Pulse = 50，27:00 后改为 0）——TIM_Period = 100 - 1; //ARR、TIM_Prescaler = 720 - 1; //PSC、TIM_Pulse = 50; //CCR、TIM_OC1Init(TIM2, ...)

2.6 参数推导：1kHz / 50% / 分辨率 1%

要求：频率 1kHz、占空比 50%、分辨率 1%（P15 结尾留的那道题）。代入三公式：

72M / (PSC+1) / (ARR+1) = 1000
CCR / (ARR+1)          = 50%
1 / (ARR+1)            = 1%
  • 三公式记法：Freq = CK_PSC/(PSC+1)/(ARR+1)、Duty = CCR/(ARR+1)、Reso = 1/(ARR+1)。
  • 分辨率 1% ⇒ 1/(ARR+1)=1%、ARR+1 = 100；占空比 50% ⇒ CCR=50；频率 1000 ⇒ PSC+1 = 720。
  • 所以 ARR = 100 - 1、PSC = 720 - 1、CCR = 50（写进代码时 PSC/ARR 都要减 1）。
  • ARR+1 = 100 还有个好处：CCR 的值恰好直接等于占空比的百分数（CCR=50 → 50%，CCR=10 → 10%），这也是 ARR 取成 99 的方便之处。

2.7 示波器验证：周期 1ms、F=1.000kHz

  • 主函数里 #include "PWM.h"、OLED_Init(); PWM_Init();，下载后 LED 已经点亮，只是 1kHz 闪烁看不出来。
  • 用虚拟示波器（ISDS205B + 电脑软件）：探头 GND 与 STM32 共地，探头接 LED 正极即 PA0。
  • 实测一个周期 1ms，读数 F = 1.001kHz，高低电平时间相等 → 占空比 50%。
  • 改 CCR 实验：TIM_Pulse = 10 → 占空比 10%、LED 变暗；TIM_Pulse = 90 → 90%、变亮。

2.8 封装 PWM_SetCompare1 与呼吸灯主循环

  • 运行中改 CCR 要用 TIM_SetCompare1 这类函数，在 PWM.c 里封装一层：
void PWM_SetCompare1(uint16_t Compare)
{
    TIM_SetCompare1(TIM2, Compare);
}
  • 头文件里声明 void PWM_SetCompare1(uint16_t Compare);。
  • 主函数定义 uint8_t i;，while(1) 里用两个 for 循环不断改 CCR：
int main(void)
{
    OLED_Init();
    PWM_Init();

    while (1)
    {
        for (i = 0; i <= 100; i++)
        {
            PWM_SetCompare1(i);       // 占空比 0→100，逐渐变亮
            Delay_ms(10);
        }
        for (i = 0; i <= 100; i++)
        {
            PWM_SetCompare1(100 - i); // 占空比 100→0，逐渐变暗
            Delay_ms(10);
        }
    }
}
  • 现在 ARR+1 等于 100，CCR 的值直接等于占空比，所以 0～100 的循环变量可以直接当占空比传进去。
  • 现象：LED 不断变亮变暗，呈呼吸灯效果；示波器上占空比同步变化，实物与波形对照非常直观。

2.9 扩展：把 PA0 重映射到 PA15

TIM2 的重映射有四种方式（引脚定义表）：

重映射方式 引脚变化
无重映射 PA0 / PA1 / PA2 / PA3
部分重映射 1 PA15 / PB3 / PA2 / PA3（前两个变了，后两个没变）
部分重映射 2 PA0 / PA1 / PB10 / PB11（后两个变了，前两个没变）
完全重映射 四个引脚都换位置

操作步骤（写在 PWM_Init 最前面）：先开 AFIO 时钟，再选 GPIO_PartialRemap1_TIM2（部分重映射 1）。

RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);              // ① 开 AFIO 时钟（APB2 设备）
GPIO_PinRemapConfig(GPIO_PartialRemap1_TIM2, ENABLE);             // ② 选部分重映射 1：CH1 → PA15
GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);          // ③ 解除 JTAG 复用，保留 SWD
  • 第③行必须有：PA15 上电后默认复用为 JTAG 调试端口，要当普通 GPIO 或定时器通道，先关闭调试端口复用。
  • 同一个 GPIO_PinRemapConfig 有三个可选参数：
    • GPIO_Remap_SWJ_NoJTRST：只解除 TRST（PB4），其余四个仍是调试端口。
    • GPIO_Remap_SWJ_JTAGDisable：解除 JTAG，PA15 / PB3 / PB4 变回 GPIO，PA13 / PA14 仍为 SWD 调试端口（推荐）。
    • GPIO_Remap_SWJ_Disable（即 SWJ_Disable）：SWD 和 JTAG 全部解除，5 个引脚全变 GPIO——千万别随便调用，调完 ST-Link 就下载不进程序，只能用串口下载一个没解除调试端口的程序救回来。
  • GPIO 初始化也要跟着改：GPIO_InitStructure.GPIO_Pin 从 GPIO_Pin_0 改成 GPIO_Pin_15。
  • 验证：下载后 PA0 的呼吸灯不亮；PA15 上插 LED（正极接 PA15、负极接 GND）能亮，说明通道 1 已挪到 PA15。
  • 收尾：这三行先注释掉、保留在代码里；39:15 画面里还能看到 f_00158 这三行注释，39:52 后已删，需要时再解除注释。

图 9：重映射代码——RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);、GPIO_PinRemapConfig(GPIO_PartialRemap1_TIM2, ENABLE);、GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);，以及 GPIO_InitStructure.GPIO_Pin = GPIO_Pin_15;

3.2 从程序一改：通道 1 → 通道 2

  • 复制上一个工程，改名 6-4 PWM驱动舵机。
  • 驱动舵机的关键就是输出周期 20ms、高电平 0.5～2.5ms 的 PWM 波形，波形对了驱动就很简单。

  • 编译报错/警告（如 function "PWM_SetCompare1" declared implicitly）多是主函数里旧函数名还没改，改完就没了。

3.3 参数：50Hz（20ms），CCR 500～2500 对应 0.5～2.5ms

  • 舵机要求周期 20ms ⇒ 频率 50Hz，代公式 72M/(PSC+1)/(ARR+1) = 50。
  • PSC 和 ARR 不固定，挑一组好算的：PSC+1 = 72、ARR+1 = 20000 → 72M/72/20000 = 50Hz。
  • 同时 20K 个计数对应 20ms，于是 CCR = 500 就是 0.5ms、2500 就是 2.5ms，参数非常直观。
  • 写进代码：TIM_Period = 20000 - 1; //ARR、TIM_Prescaler = 72 - 1; //PSC、TIM_Pulse = 0; //CCR。
/* 程序二 PWM.c 改动的四处 */
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1;                    // PA1 → TIM2_CH2

TIM_TimeBaseInitStructure.TIM_Period = 20000 - 1;            // ARR：20ms
TIM_TimeBaseInitStructure.TIM_Prescaler = 72 - 1;            // PSC：50Hz

TIM_OCInitStructure.TIM_Pulse = 0;                           // CCR 初值
TIM_OC2Init(TIM2, &TIM_OCInitStructure);                     // 通道 2

void PWM_SetCompare2(uint16_t Compare)
{
    TIM_SetCompare2(TIM2, Compare);                          // 运行中改 CCR
}
  • 验证：PWM_SetCompare2(500) → 0°，2500 → 180°，1500 → 90°；示波器测得周期 20ms、高电平 0.5ms / 2.5ms / 1.5ms、F ≈ 50Hz。

3.4 同一定时器多通道的特点

视频 40:30～42:20 专门补了一段，说明同一个定时器不同通道输出 PWM 的三个特点：

特点 原因
频率必须相同 不同通道共用一个计数器（CNT）
占空比可以各自设定 每个通道有自己的 CCR
相位同步 计数器更新时，所有通道的 PWM 同时跳变
  • 所以 TIM_OC1Init～TIM_OC4Init 可以同时写、同时用：驱动多个舵机或多个电机，用同一个定时器的不同通道就够了。
  • 本程序只用通道 2，所以只调用 TIM_OC2Init。

3.5 Servo 模块：角度 → CCR 的线性映射

  • 直接调 PWM_SetCompare2(500) 参数不直观，在 Hardware 里再建 Servo.c / Servo.h，把「设置角度」封装起来：
#include "stm32f10x.h"
#include "PWM.h"

void Servo_Init(void)
{
    PWM_Init();                                  // 继承 PWM 的底层初始化
}

void Servo_SetAngle(float Angle)                 // 参数用 float，方便计算
{
    PWM_SetCompare2(Angle / 180 * 2000 + 500);   // 0～180 映射到 500～2500
}
  • 映射推导：0° 对应 500、180° 对应 2500，角度范围 180、CCR 范围 2000，所以先缩放 Angle / 180 * 2000，再加偏移 +500；也可以记成 Angle/180*2000+500。
  • Angle = 0 → 0+500 = 500；Angle = 180 → 2000+500 = 2500；中间线性一一对应。
  • 头文件声明 void Servo_Init(void); 和 void Servo_SetAngle(float Angle);；主函数改成 #include "Servo.h"、Servo_Init()、Servo_SetAngle(Angle)。

4.3 Motor 模块：方向脚 + 速度函数

在 Hardware 里建 Motor.c / Motor.h：Motor_Init 先 PWM_Init()，再额外初始化两个方向控制脚（从 LED.c 复制 GPIO 初始化代码改一改）：

#include "stm32f10x.h"
#include "PWM.h"

void Motor_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;          // 普通推挽输出
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_4 | GPIO_Pin_5;    // AIN1、AIN2
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    PWM_Init();                                               // 底层 PWM
}

/* Speed：-100～100，负数表示反转 */
void Motor_SetSpeed(int8_t Speed)
{
    if (Speed >= 0)                                           // 正转
    {
        GPIO_SetBits(GPIOA, GPIO_Pin_4);
        GPIO_ResetBits(GPIOA, GPIO_Pin_5);
        PWM_SetCompare3(Speed);
    }
    else                                                      // 反转
    {
        GPIO_ResetBits(GPIOA, GPIO_Pin_4);
        GPIO_SetBits(GPIOA, GPIO_Pin_5);
        PWM_SetCompare3(-Speed);                              // SetCompare 只能传正数
    }
}
  • 方向逻辑：哪个为高不重要，只是极性不一样——正转 PA4 高、PA5 低，反转把两个 Set/Reset 反过来（对应 TB6612 真值表：IN1/IN2 一高一低才转）。
  • 速度：最后把 Speed 传给 PWM_SetCompare3，也可以理解成把 |Speed| 写进 CCR；TIM_SetCompare3 只能传正数，所以反转分支写 -Speed。
  • 测试：Motor_SetSpeed(50) 正转、-50 反转、100 满速，每次用手试方向。

图 16：Motor.c 的 Motor_Init——GPIO_Mode_Out_PP、GPIO_Pin_4 | GPIO_Pin_5、GPIO_Speed_50MHz、GPIO_Init(GPIOA, ...)，最后 PWM_Init()

图 17：Motor_SetSpeed(int8_t Speed) 正转分支——if (Speed >= 0) { GPIO_SetBits(GPIOA, GPIO_Pin_4); GPIO_ResetBits(GPIOA, GPIO_Pin_5); PWM_SetCompare3(Speed); }，else 分支据口述还原

4.4 坑：1kHz 会让电机「唱歌」→ 把 PSC 改成 36-1（20kHz）

  • 电机转起来会发出蜂鸣器一样的响声，堵转时最明显（转起来被电机本身的声音盖住）。
  • 原因：电机里面也是线圈和磁铁，在 1kHz 的 PWM 下会振动发声，属正常现象。
  • 解法是加大 PWM 频率：人耳范围 20Hz～20kHz，1kHz 正好在范围内，超出人耳范围就听不到。
  • 加大频率靠减小预分频器（PSC），不影响占空比。把 TIM_Prescaler 从 720 - 1 改成 36 - 1：
72M / 36 / 100 = 20000Hz = 20kHz
  • 改完再堵转，就听不到声音了。

图 18：程序三最终时基——TIM_Period = 100 - 1; //ARR、TIM_Prescaler = 36 - 1; //PSC（72M/36/100 = 20kHz，超出人耳范围）、TIM_Pulse = 0、TIM_OC3Init(TIM2, ...)

#include "Delay.h"
#include "OLED.h"
#include "Motor.h"
#include "Key.h"

int8_t Speed;      // 有符号的速度变量

int main(void)
{
    OLED_Init();

    Key_Init();

    OLED_ShowString(1, 1, "Speed:");

    {
        KeyNum = Key_GetNum();

}
  • 速度循环：每按一下 Speed += 20，超过 100 就跳回 -100，所以速度在 -100～100 之间循环；主循环里交给 Motor_SetSpeed(Speed) 执行。
  • OLED：OLED_ShowString(1, 1, "Speed:") 显示字符串，OLED_ShowSignedNum(1, 7, Speed, 3) 显示有符号数、占 3 位。
  • 最终现象：OLED 显示 Speed:+100 等数值，按键改速度、电机正反转加减速。

  1. 最简单的：把电机的两根线反过来接；
  2. 把输入的 IN1 和 IN2 反过来（AIN1/AIN2 两根线对调）；
  3. 在程序里把 Set 和 Reset 反过来——换引脚时比较方便修改。

5. 三个程序的共同规律

  • 同一套模板：三个程序都复制上一个工程，只改三样——引脚（GPIO_Pin_x）、通道函数（TIM_OCxInit / PWM_SetComparex）、参数（PSC/ARR）。
  • 频率由 PSC/ARR 决定，占空比由 CCR 决定；改频率时注意别破坏 CCR 与时间/角度的对应关系（舵机的 500～2500 靠 ARR+1 = 20000 才成立）。
  • 分层封装：底层 PWM.c 只管按通道输出 PWM、设置 CCR，上层 Servo.c / Motor.c 负责把角度/速度翻译成 CCR 与方向脚电平。
  • 同一定时器多通道：频率必须相同、占空比各自、相位同步。

坑与易错点

  1. GPIO 必须配 GPIO_Mode_AF_PP：普通推挽由 ODR 控制，定时器接管不了；复用模式才把控制权交给片上外设。
  2. PSC、ARR 写进代码都要减 1：720-1、100-1、20000-1、72-1、36-1，实际分频系数是「值 + 1」。
  3. 换通道要改四处：GPIO_Pin_x、TIM_OCxInit、PWM_SetComparex、头文件声明，漏一处就没输出或编译不过。
  4. TIM_Pulse 只是 CCR 初值：运行中改占空比要用 TIM_SetComparex，本集封装成 PWM_SetComparex。
  5. 别乱抄 TIM_OC1PreloadConfig 和 TIM_CtrlPWMOutputs：后者只有高级定时器必须调；本集三个程序都是 TIM2，都没调。
  6. 先 TIM_OCStructInit 赋默认值：不赋初值成员值不确定，作者遇到过 4 路 PWM 只输出 3 路。
  7. TIM_ClockDivision 与定时时间无关：只影响输入滤波采样频率，随便配（本集都是 TIM_CKD_DIV1）；TIM_RepetitionCounter 通用定时器给 0。
  8. 同一定时器多路 PWM 频率必须相同（共用一个 CNT），只有占空比能各自设；要不同频率必须换定时器。
  9. 舵机 5V 不要接面包板正极：那里只有 3.3V、功率小，带不动；要接 ST-Link 的 5V。
  10. 舵机角度体系要与 P15 对上：P15 用 -90°～+90°，本集用 0°～180°，是同一款 180° 舵机的两种写法。
  11. Servo_SetAngle 的映射别写错：Angle / 180 * 2000 + 500，先除后乘，+500 不能漏，否则 0° 变成 0。
  12. 方向脚是普通推挽输出（GPIO_Mode_Out_PP），不是复用——只有 PWMA 才需要复用推挽。
  13. TIM_SetCompare 只能传正数：反转时 Speed 是负数，要写 PWM_SetCompare3(-Speed)。
  14. TB6612 的 VM 别接错：VM 是电机电源（ST-Link 5V、大电流），VCC 是逻辑电源（3.3V）；插面包板 VM 放左下角，插反容易烧驱动。
  15. STBY 要接高电平（3.3V）才工作：接 GND 芯片就待机、电机不动。
  16. 1kHz 的 PWM 会让电机「唱歌」：线圈振动，堵转最明显；减小 PSC 提高频率（720-1 → 36-1，20kHz）。
  17. 重映射 PA15 别用 GPIO_Remap_SWJ_Disable：会把 SWD 和 JTAG 全关掉、下载不进程序；要用 GPIO_Remap_SWJ_JTAGDisable。
  18. 重映射之后 GPIO 初始化也要改：GPIO_Pin_0 → GPIO_Pin_15，否则 PA15 没被配置、输出不了。
