2.5 PWM_Init 完整代码（程序一最终版）

#include "stm32f10x.h"

void PWM_Init(void)
{
    /* 时钟：TIM2 在 APB1，GPIOA 在 APB2 */
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    /* GPIO：复用推挽输出（引脚控制权交给片上外设） */
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    /* 时钟源：选内部时钟（默认就是内部时钟，写上更完整） */
    TIM_InternalClockConfig(TIM2);

    /* 时基单元：PSC 定频率、ARR 定周期 */
    TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
    TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInitStructure.TIM_Period = 100 - 1;      // ARR
    TIM_TimeBaseInitStructure.TIM_Prescaler = 720 - 1;   // PSC
    TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0; // 高级定时器才用
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

    /* 输出比较单元：PWM模式1、高电平有效、使能输出、CCR 初值 50 */
    TIM_OCInitTypeDef TIM_OCInitStructure;
    TIM_OCStructInit(&TIM_OCInitStructure);
    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStructure.TIM_Pulse = 0;                   // CCR 初值（参数计算阶段曾用 50，27:00 后按口述改为 0）
    TIM_OC1Init(TIM2, &TIM_OCInitStructure);

    /* 运行控制：启动计数器 */
    TIM_Cmd(TIM2, ENABLE);
}

几个要点（视频里都专门讲过）：

  • 结构体成员先 TIM_OCStructInit 赋默认值：作者遇到过一个怪问题——让高级定时器输出 4 路 PWM，初始化函数放在第一行就没问题，前面出现别的代码就只输出 3 路。「能不能输出 PWM，竟然和初始化函数在哪一行有关」——原因是没给结构体赋初值，成员值不确定。所以为了避免程序中出现不确定的因素，有用没用都先赋一遍默认值，再改自己想改的。
  • TIM_OCMode 的可选值：TIM_OCMode_Timing（冻结）、_Active（相等时置有效）、_Inactive（相等时置无效）、_Toggle（相等时翻转）、TIM_OCMode_PWM1 / _PWM2、以及 _ForcedAction_Active / _Inactive（强制输出，初始化时不让用）。这里选 TIM_OCMode_PWM1。
  • TIM_OCPolarity：选 TIM_OCPolarity_High——「有效电平是高电平，REF 有效时输出高电平，都是一个意思」。
  • TIM_OutputState：Disable 失能 / Enable 使能，这里「肯定得使能」。
  • TIM_Pulse 就是 CCR 的值：它的注释写的是「指定的 Pulse 值会被加载到 Capture Compare Register」，也就是 CCR 捕获/比较寄存器；PSC 是预分频、ARR 是周期、CCR 是占空比，三者共同决定 PWM 的周期和占空比。
  • GPIO 为什么必须配 GPIO_Mode_AF_PP：普通的开漏/推挽输出，引脚的控制权来自输出数据寄存器（ODR）；而要让定时器来控制引脚，就必须用复用开漏/推挽输出，此时输出数据寄存器被断开、输出控制权转移给片上外设——而按引脚定义表，这个片上外设引脚连的正是 TIM2 的 CH1 通道。所以只有把 GPIO 设置成复用推挽输出，PWM 波形才能通过引脚输出。

2.6 参数推导：1kHz / 50% / 分辨率 1%

要求：频率 1kHz、占空比 50%、分辨率 1%（就是 P15 结尾留的那道练习题）。代入 P15 的三个公式：

72M / (PSC+1) / (ARR+1) = 1000
CCR / (ARR+1)          = 50%
1 / (ARR+1)            = 1%
  • 由分辨率 1% ⇒ ARR+1 = 100；
  • 由占空比 50% ⇒ CCR = 50；
  • 由频率 1000 ⇒ PSC+1 = 720。
  • 所以：ARR = 100 - 1、PSC = 720 - 1、CCR = 50（写进代码时 PSC/ARR 都要减 1，见「坑与易错点」）。

另外，因为 ARR+1 = 100，所以 CCR 的值恰好直接等于占空比的百分数（CCR=50 → 50%，CCR=10 → 10%）——这也是这里把 ARR 取成 99 的方便之处。

2.7 示波器验证：周期 1ms、F=1.000kHz、占空比 50%

  • 主函数里 #include "PWM.h"，调用 OLED_Init(); PWM_Init();，编译下载——此时 LED 已经点亮了，「它现在其实是在以 1kHz 的频率闪烁，我们看不出来」。
  • 用虚拟示波器（ISDS205B + 电脑软件）看波形：探头的 GND 与 STM32 共地，探头接在 LED 的正极，也就是 PA0；电脑端打开探头通道就出波形了。
  • 实测：「这里到这里，是一个周期，时间是 1ms」，读数为 F = 1.001kHz（约 1.000kHz），高电平和低电平时间相等 → 占空比 50%，说明参数设置没问题。
  • 再改 CCR 做实验：TIM_Pulse = 10 → 占空比 10%，LED 变暗；TIM_Pulse = 90 → 占空比 90%，LED 变亮；示波器上高电平时间同步变短/变长。

2.9 扩展：把 PA0 重映射到 PA15

P15 提过「CH1 还能重映射到 PA15」，这里动手试一遍。引脚定义表里 TIM2 的重映射有四种方式：

重映射方式 引脚变化
无重映射 PA0 / PA1 / PA2 / PA3
部分重映射 1 PA15 / PB3 / PA2 / PA3（前两个变了，后两个没变）
部分重映射 2 PA0 / PA1 / PB10 / PB11（后两个变了，前两个没变）
完全重映射 四个引脚都换位置

操作步骤（代码在 PWM_Init 最前面）：

RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);              // ① 开 AFIO 时钟（APB2 设备）
GPIO_PinRemapConfig(GPIO_PartialRemap1_TIM2, ENABLE);             // ② 选部分重映射 1：CH1 → PA15
GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);          // ③ 解除 JTAG 复用，保留 SWD
  • 为什么要第③行：PA15 上电后默认复用为 JTAG 调试端口，想让它当普通 GPIO 或定时器通道，就必须先关闭调试端口的复用——用同一个 GPIO_PinRemapConfig 函数，三个可选参数：
    • GPIO_Remap_SWJ_NoJTRST：只解除 TRST（PB4），其余四个仍是调试端口；
    • GPIO_Remap_SWJ_JTAGDisable：解除 JTAG，PA15 / PB3 / PB4 变回 GPIO，PA13 / PA14 仍为 SWD 调试端口（推荐）；
    • GPIO_Remap_SWJ_Disable：SWD 和 JTAG 全部解除，5 个引脚全变 GPIO——这个参数千万不要随便调用：调了它并下载程序之后，调试端口就都没了，这之后再用 ST-Link 就下载不进程序了，只能用串口下载一个没解除调试端口的程序才能救回来。
  • GPIO 初始化也要跟着改：既然挪到了 PA15，GPIO_InitStructure.GPIO_Pin 就要从 GPIO_Pin_0 改成 GPIO_Pin_15。
  • 验证：改完下载，PA0 上的呼吸灯不亮了；往 PA15 上插一个 LED（正极接 PA15、负极接 GND），灯亮 → 说明定时器通道 1 已经成功挪到 PA15。

4.3 Motor 模块：方向脚 + 速度函数

在 Hardware 里建 Motor.c / Motor.h：Motor_Init 里先 PWM_Init() 初始化 PWM，然后额外初始化两个方向控制脚（从 LED.c 复制 GPIO 初始化代码改一改）：

#include "stm32f10x.h"
#include "PWM.h"

void Motor_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;          // 普通推挽输出
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_4 | GPIO_Pin_5;    // AIN1、AIN2
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    PWM_Init();                                               // 底层 PWM
}

/* Speed：-100～100，负数表示反转 */
void Motor_SetSpeed(int8_t Speed)
{
    if (Speed >= 0)                                           // 正转
    {
        GPIO_SetBits(GPIOA, GPIO_Pin_4);
        GPIO_ResetBits(GPIOA, GPIO_Pin_5);
        PWM_SetCompare3(Speed);
    }
    else                                                      // 反转
    {
        GPIO_ResetBits(GPIOA, GPIO_Pin_4);
        GPIO_SetBits(GPIOA, GPIO_Pin_5);
        PWM_SetCompare3(-Speed);                              // SetCompare 只能传正数
    }
}
  • 方向逻辑：「哪个为高、哪个为低不重要，就是极性不一样而已」——正转时 PA4 高、PA5 低；反转时把两个 Set/Reset 反过来即可（对应 TB6612 真值表里 IN1/IN2 一高一低才转、全高制动、全低停止，见 P15）。
  • 速度：最后把 Speed 传给 PWM_SetCompare3。注意 TIM_SetCompare3 只能传正数，所以在反转分支里要写成 -Speed（Speed 本身是负数，取反才变正）。
  • 测试：先 Motor_SetSpeed(50) → 正转；改成 -50 → 反转；改成 100 → 满速；每次都用手试一下方向。

4.4 坑：1kHz 会让电机「唱歌」→ 把 PSC 改成 36-1（20kHz）

  • 电机转起来之后发现一个问题：电机会发出「蜂鸣器」一样的响声，堵转的时候最明显（转起来时被电机本身的声音盖住，听不太清）。
  • 原因：电机里面也是线圈和磁铁，在 1kHz 的 PWM 驱动下会振动发声——这是正常现象，不介意可以不管。
  • 介意的话，解法是加大 PWM 频率：人耳听到声音的频率范围是 20Hz～20kHz，现在给的是 1kHz，正好在人耳范围内；频率足够大、超出人耳范围就听不到了。
  • 加大频率靠减小预分频器（PSC），这样不会影响占空比。把 TIM_Prescaler 从 720 - 1 改成 36 - 1：
72M / 36 / 100 = 20000Hz = 20kHz
  • 改完再堵转试，「就听不到声音了」——电机模块测试完成。

5. 三个程序的共同规律

  • 同一套模板：三个程序都是复制上一个工程，然后只改三样——引脚（GPIO_Pin_x）、通道函数（TIM_OCxInit / PWM_SetComparex）、参数（PSC/ARR）；PWM_Init 的骨架、五步流程完全一样。
程序 复制自 通道/引脚改动 其他改动

② 舵机 ① 呼吸灯 GPIO_Pin_1、TIM_OC2Init、PWM_SetCompare2 PSC=72-1、ARR=20000-1；新增 Servo.c/.h

  • 频率由 PSC/ARR 决定，占空比由 CCR 决定：想改频率就动 PSC 或 ARR（P15 公式 Freq = CK_PSC/(PSC+1)/(ARR+1)），想改占空比就动 CCR（Duty = CCR/(ARR+1)）；改频率时注意别破坏「CCR 与时间/角度的对应关系」（比如舵机的 500～2500 是靠 ARR+1=20000 才成立的）。
  • 分层封装：底层 PWM.c 只管「按通道输出 PWM、设置 CCR」，上层 Servo.c / Motor.c 负责「把角度/速度翻译成 CCR 和方向脚电平」——换外设时上层改，底层不用动。
  • 同一定时器多通道：频率必须相同、占空比各自、相位同步；本集三个程序都用 TIM2 的不同通道，理论上可以同时开三路 PWM（驱动多个舵机/电机够用）。

坑与易错点

  1. GPIO 必须配成 GPIO_Mode_AF_PP（复用推挽）：普通推挽输出的引脚由输出数据寄存器（ODR）控制，定时器根本接管不了；只有复用模式才把控制权交给片上外设，PWM 才能从引脚输出。
  2. PSC 和 ARR 写进代码时都要「减 1」：720-1、100-1、20000-1、72-1、36-1——因为实际分频系数/周期数是「值 + 1」。
  3. 换通道要改四处，漏一处就编译不过或没输出：GPIO_Pin_x、TIM_OCxInit、PWM_SetComparex（含 TIM_SetComparex）、头文件函数声明。
  4. TIM_Pulse 只是 CCR 的初值：初始化时给的 50 只决定初始占空比；运行中改占空比要用 TIM_SetComparex（本集封装成 PWM_SetComparex）。
  5. 别乱抄 TIM_OC1PreloadConfig 和 TIM_CtrlPWMOutputs：前者是 CCR 预装（影子寄存器，一般不用），后者只有高级定时器才必须调用（否则高级定时器 PWM 不输出）；本集三个程序都是通用定时器 TIM2，都没有调用这两个函数。
  6. TIM_OCStructInit 要先给结构体赋默认值：不赋初值会留下未确定的成员值，作者遇到过「高级定时器初始化函数位置不同，4 路 PWM 只输出 3 路」的怪问题。
  7. TIM_ClockDivision 与定时时间无关：它只影响输入滤波采样频率，随便配（本集都是 TIM_CKD_DIV1）；TIM_RepetitionCounter 是高级定时器才用的，通用定时器给 0。
  8. 同一个定时器的多路 PWM 频率必须相同（共用一个 CNT），只有占空比能各自设——想让两路 PWM 频率不同，必须换定时器。
  9. 舵机的 5V 不要接面包板的正极：那里只有 3.3V，功率也小，带不动舵机；要接 ST-Link 的 5V（USB 5V）。
  10. 舵机的角度体系要与 P15 对上：P15 用的是 -90°～+90°（0.5～2.5ms），本集用的是 0°～180°（CCR 500～2500）——同一款 180° 舵机的两种写法，不是矛盾：0°～180° 对应脉宽 0.5～2.5ms，也对应 -90°～+90°。
  11. Servo_SetAngle 的映射公式别写错：Angle / 180 * 2000 + 500；先除后乘（先算出比例再缩放），偏移 +500 不能漏，否则 0° 会变成 0 而不是 500。
  12. 电机方向脚是普通 GPIO 推挽输出（GPIO_Mode_Out_PP），不是复用——只有 PWM 脚（PWMA）才需要复用推挽。
  13. TIM_SetCompare 只能传正数：反转时 Speed 是负数，要写 PWM_SetCompare3(-Speed)。
  14. TB6612 的 VM 别接错：VM 是电机电源（接 ST-Link 5V、与电机额定电压一致、要大电流），VCC 是逻辑电源（3.3V）；模块插面包板时 VM 放左下角，「千万别插反，容易烧坏驱动」。
  15. STBY 要接高电平（3.3V）才工作：接 GND 芯片就待机、电机不动。
  16. 1kHz 的 PWM 会让电机「唱歌」：线圈在 PWM 下振动，堵转时最明显；解法是减小 PSC 提高频率（720-1 → 36-1，20kHz，超出人耳 20Hz～20kHz），改频率不影响占空比。
  17. 重映射 PA15 时别用 GPIO_Remap_SWJ_Disable：它会把 SWD 和 JTAG 全关掉，下载不进程序；应该用 GPIO_Remap_SWJ_JTAGDisable（保留 SWD 的 PA13/PA14）。
  18. 重映射之后 GPIO 初始化也要改：GPIO_Pin_0 → GPIO_Pin_15，否则你还在初始化 PA0，PA15 没被配置就输出不了。
